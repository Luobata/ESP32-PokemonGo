# 金银民间旧译资料

`gs_legacy.json` 保存关都 151 只的名称映射和逐条来源。显示选项是“金银民间旧译（资料版）”；默认仍用 `assets/gen1.bin` 内的官方中文名。

“肥大”对应快龙，属于早期民间汉化名。金银与水晶的表不能混用：公开分版本表中的水晶快龙是“富阿”。当前字典只整理金银列，不声称已与某一个 ROM 的全部显示字节逐项一致。

来源与覆盖范围：

- [究级硬骨头的原整理帖](https://tiebac.baidu.com/p/612037835?fr=good)：作者把多位玩家提供的材料整理成编号表。本次公开索引可交叉核对 001–088。
- [口袋妖怪中心的历史转载](https://www.pmcenter.cn/forum.php?mod=viewthread&tid=42616)：链接回上述原帖，用来追溯转载关系，不算第二份独立实机验证。
- [萌娘百科分版本资料表的公开镜像](https://moegirl.uk/index.php?title=%E5%AE%9D%E5%8F%AF%E6%A2%A6%E7%B3%BB%E5%88%97/%E4%BF%97%E7%A7%B0&variant=zh-hans)：完整覆盖 001–151，其中 089–151 本次依此表整理。镜像与原站内容可能有差异，JSON 保留实际读取的网址和日期。

不同汉化版本、图鉴和战斗显示名存在异名。#084、#085 在原帖记为“南版”“鲁风”，二手表记为“南板”“北风”；当前采用原整理帖，并在两条记录内保留差异。表内括号异名不自动拼入显示名，也不混入水晶列。

更新 JSON 后运行 `python3 tools/pipeline/generate_pokemon_names.py`。它生成 `firmware/main/pokemon_names.c`，使固件正常构建的字库扫描能收齐全部名字。`--check` 检查生成物一致性，`verify_pokemon_names.py` 检查实际资产出口、缺项回退和页面切换。

字典按物种编号索引，不改变编号、属性、招式或存档。缺条目时回退资产中的官方名。硬件偏好仅保留本次运行，重新启动用官方名；网页偏好存于浏览器 localStorage，并明确传入每个新测试场景。
