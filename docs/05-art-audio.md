# 五、美术与音频（L3）

方向已定：**直接复刻初代 Game Boy 体感的像素风格。**

这与硬件约束高度契合 —— 低分辨率、大色块、低帧率、无骨骼动画，
恰好是 DMG 时代的原生表达方式。**约束在这里不是限制而是风格来源。**

## 5.1 视觉规范

需要在动工前定稿的规范：

| 项 | 说明 | 现在能定吗 |
|---|---|---|
| 调色板 | 严格 4 级灰阶的 DMG 复古，或 GBC 式有限彩色 | ✅ 能定 |
| tile 尺寸与网格 | 8×8 或 16×16 | ✅ 能定 |
| 精灵尺寸档位 | 主宠 / 野怪 / 图标各几档 | ✅ 能定 |
| 中文点阵字体 | 取舍与 flash 占用核算（这是 8MB 预算里的大头） | ✅ 能定 |
| **240×320 版式** | 等比放大留黑边（体感更纯）vs 全屏重设版式（信息量更大） | ❌ **需上手看观感** |

最后一项是**唯一真正被硬件阻塞**的。注意屏幕比例与 GB 原生的 160×144 并不相同：
240×320 是 3:4 竖屏，而 GB 是 10:9 横屏 —— 这不是简单的缩放关系，
等比放大会留下相当大的黑边。

### 渲染约束

由 [1.1](01-constitution.md#11-硬约束清单) 推出的硬性限制：

- **无法整帧缓冲**（150KB 帧 vs 400KB SRAM），必须**分块横带渲染**
- 全屏转场特效基本放弃
- 动画按「大色块 + 局部重绘 + 低帧率」设计，不做骨骼动画

## 5.2 音频路线

因 ESP32-C3 **无内置 DAC**（区别于经典 ESP32），音频路线指向**实时 chiptune 合成**
而非采样播放。这条路几乎不占 flash，且与像素美术在风格上天然统一。

### 已核实的库与许可

| 库 | 许可 | 说明 |
|---|---|---|
| **libxmp** | MIT | 最干净的 tracker 播放选择 |
| gbsplay | GPL v1+ | GB 音频播放 |
| cardputer-studio | MIT | ESP32-S3 groovebox，可参考 |
| PixelRoot32-APU | MIT | NES 风格 APU 核，可参考 |
| ~~ChiptunesOnAnS3~~ | **GPL-3.0** | **会传染固件，避开** |

两个需要注意的事实：

**目前不存在成熟的 ESP32 XM/MOD/VGM 播放器。** 移植 libxmp 在许可上干净，
但 flash 与 RAM 是否装得下**尚未验证** —— 400KB SRAM 是很紧的。

**Furnace Tracker 没有 MCU 原生导出格式**（只有 VGM、ZSM、TIunA、SAP-R 和音频文件），
其许可为 GPLv2+，且构建时启用 ASIO SDK 会使产物变成 GPLv3。

### 推荐路径

**CC0 预渲染音频 + 自己手写的极简 APU**，而不是引入 GPL-3.0 的现成固件方案。

## 5.3 素材来源

本项目**仅供自用、不分发**，因此**几乎所有许可义务都不触发** ——
CC 系列许可、GPL 的开源要求、署名义务，触发条件都是「分发」。
自己烧进设备自己玩，法律上属于私人使用。

**以下清单因此只按实用性排序，而不按许可宽松度排序。**

| 素材源 | 内容 | 实用性评价 |
|---|---|---|
| **DawnLike 16×16**（DragonDePlatino） | 怪物、角色、tileset，原生 16 色 DawnBringer 调色板 | **首选。** 已经在正确的调色板上，省掉重新调色的工作 |
| **Tuxemon** | 411 个怪物定义、413 张战斗精灵图、258 个 ogg | 自用场景下可直接整取。**素材量最大**，且怪物定义是 YAML，可直接转成固件数据表 |
| Kenney.nl | 通用像素素材 | 补充用。没有 GB 四阶灰或怪物类包 |
| OGA「CC0 - Retro Music」 | 8-bit 音乐合集 | 音频首选，预渲染直接用 |

### Tuxemon 的 411 个 YAML 是最大的现成资产

值得单独说：自用场景下它从「许可雷区」变成了最大的现成资产 ——
**省掉的不只是美术，还有属性、种族值、进化链这些策划数据。**

建议直接拿它当**数据底座**：

1. 精灵图批量降到 2bpp 四阶灰
2. YAML 转成 flash 里的紧凑二进制表
3. 按 8MB flash 预算做容量核算

这项工作完全在 PC 上进行，**不需要目标硬件**，是当前阶段的主要工作面之一。

## 5.4 如果将来想分发

当前范围（自用、不分发）下本节不适用，保留在此仅作为**将来改变主意时的检查清单**。
**一旦分发，下列约束立刻全部生效**，而且有些是回头改不掉的。

### 会立刻生效的义务

- **Tuxemon 素材是逐文件混合许可，含 13 个非商用（NC）文件** ——
  必须逐文件比对 `ATTRIBUTIONS.md` 筛出可用子集。
  许可分布：CC BY-SA 4.0 约 169 项、CC BY-SA 3.0 约 48 项、CC BY 3.0/4.0 约 80 项、
  CC0 提及 98 次，另有 CC BY-NC-SA 3.0 共 12 项与 CC BY-NC 3.0 共 1 项。
  其中两首曲子名为 *Fake Pokemon Battle Song* 与 *Original Pokemon Battle*，
  **来源本身就有问题**。
- **DawnLike 需署名** DragonDePlatino 与 DawnBringer（CC BY 4.0）
- **ChiptunesOnAnS3 是 GPL-3.0**，会传染固件
- **CC BY-SA 4.0 含反技术措施条款** —— 若启用 flash 加密阻止素材提取可能构成违反。
  CC0 完全没有这层暴露

关于 ShareAlike 对固件的影响（法律解读，非已验证判例，商业化前应咨询专业意见）：
SA 条款**不会传染到代码**。把精灵图重新调色为 2bpp 会产生改编作品，
这些**图像**必须以 CC BY-SA 附署名发布，但固件源码可以保持闭源 ——
二者属于聚合而非派生关系。

### 回头改不掉的那一条

宝可梦的角色、名称与具体素材是任天堂的知识产权，
且「Pikachu」这类名称**同时受商标保护** —— 这是独立于著作权的另一项主张。

从原版 ROM 提取素材风险最高，**非商用与开源都不能缓解**（公开发布反而扩大分发范围）。
任天堂执法活跃：Pokémon Essentials 于 2024 年被下架，2015 与 2025 年均有 DMCA 记录。

相比之下**「Game Boy 视觉风格」本身是可以自由模仿的** ——
四阶灰调色板、8×8 tile、低分辨率属于思想/风格与功能性约束，不在著作权范围内。

> 怪物用自己起的名字。**
>
> 种族设定会渗透进数值平衡与美术资产，后期换不掉 ——
> 而改名的成本，今天几乎是零。
