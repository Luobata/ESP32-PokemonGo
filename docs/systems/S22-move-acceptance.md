# S22 · 精选二代招式与后台验收

2026-09-09：新增 25 招，连同先前的潮旋，引擎支持 **191 招**。原作常规学习范围仍有 48 种未实现；不将完整金银招式作为当前发布门槛。数据来自 S21 记录的固定提交，精选元数据存于 `data/pokemon_moves/selected_gen2.json`。

## 本批

火焰轮、细雪、音速拳、出奇一击、天使之吻、污泥炸弹、掷泥、电磁炮、冰冻之风、骨棒乱打、逆鳞、终极吸取、撒娇、点到为止、钢翼、爆裂拳、龙息、铁尾、十字劈、龙卷风、咬碎、神速、原始之力、影子球、碎岩。

优先补属性进攻选择、经典招式和明显的附加效果；机器/遗传/升级兼容性继续由原物种表控制，自动随等级学会，无需遗忘。点到为止不会击倒目标；对方只有1点体力时 AI 不再把它作为伤害选择。火焰轮可解除自身冰冻；钢翼和原始之力可提升自身能力；恶/钢攻击和小磁怪、大磁怪的钢防御属性接入战斗，咬住改为恶属性。

17×17 相克表逐项核对金银 `data/types/type_matchups.asm`，修正初代幽灵→超能、毒↔虫、冰→火差异。属性表快照为 `gold_silver_types.json`。

仍沿用项目的单一“特殊”能力值以及简化的连续攻击/回合规则；影子球和咬碎降低该共用能力值，不宣称完全复刻原作分离的特攻/特防。天气、守住、持有物、换宠链、延迟攻击等需要独立场地或跨回合状态和对应 AI，本批未半成品接入；PP 消耗类不符合当前玩法。存档 V11 / 3664 字节不变。

## 全部招式如何验收

启动 `python3 tools/inspector/server.py --port 8766`，进入 `http://127.0.0.1:8766/firmware.html`，点击顶部 **全部招式动画验收**；也可直接打开 `/moves.html`。

- 列出全部 191 招，可搜索名称/编号，筛选本批新增25招，上一招/下一招。
- 切换我方或对方出招，修改双方物种并重新载入；暂停、重播、拖动帧、逐帧、导出 PNG。
- 命中/未命中动作展示用于看位置与轨迹，展示伤害是固定夹具，不能用它验证伤害公式。
- 实际结算使用固定种子与半血出招方、睡眠目标、反击条件；免疫/未命中/蓄力仍按 C 规则发生。蓄力招式可切换“蓄力后释放”验收攻击阶段。
- 直接调用固件 `play_battle.c` 的精灵、HUD、消息、`battle_fx.c`。浏览器只显示 RGB565 字节，不另画动画。该注入入口仅在 HOST_BUILD 中编译，不进入硬件游戏或真实存档。
- 招式指定动作与属性/状态共用动画在页面标明。所有招式都有可验收的反馈，不代表191种各自独立的原作动画。影子球增强蓄能、球体飞行与命中爆开；铁尾增加金属色斩击与撞击反馈。

## 检查

`verify_selected_moves.py` 检查新效果、289个相克组合与存档兼容；`verify_gs_learning.py` 检查15100个物种等级组合；`verify_combat_fx.py` 检查全部招式双侧、不同体型、HUD保护和末帧清屏；`verify_move_acceptance.py` 检查191招×双侧×四场景×四关键帧，共6112次同源画面一致性检查。证据放在 `reports/evidence/selected-moves-2026-09-09/`。

## 重新生成

```sh
python3 tools/pipeline/convert_selected_moves.py
python3 tools/pipeline/convert_auto_moves.py
python3 tools/pipeline/convert_move_catalog.py
python3 tools/pipeline/convert_font.py --out assets
```

修改 C 代码后重启预览服务；服务启动时选择一次构建，已有会话不自动切换二进制。
