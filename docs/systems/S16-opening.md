# S16 开场剧情

大木博士的话。实现见 [`sim/opening.py`](../../sim/opening.py)。

## 16.1 中文文本的来源

**Gen 1 从未官方中文化**，所以不存在官方中文原文 ——
网上流传的版本（包括百科上看着像官方的那段）都是爱好者翻译。

做法：

1. 英文原文从 pret/pokered 一手取得（`data/text/text_2.asm:1697` 的
   `_OakSpeechText1` / `2A` / `2B` / `3`）
2. 中文取常见爱好者译法为底
3. 逐句审核改写，**每句的英文原文与改动理由都记在代码里**

## 16.2 三处审核改动

| 英文 | 常见译法 | 本项目 | 为什么 |
|---|---|---|---|
| `pets` | 宠物 | **伙伴** | 中文的「宠物」有从属意味，而这游戏的核心是并肩 |
| `Others use them for fights` | 用来打斗 | **让它们互相切磋** | 直译在中文里指向斗兽，与养成取向相悖 —— 而原版并不认为对战是残忍的事 |
| `inhabited by` | 充满了 | **生活着** | 「充满了」偏向数量多；inhabited 是「栖息」的中性说法 |

另外「大木」是官方译名（オーキド博士），不是爱好者常用的「欧金博士」。

## 16.3 删掉原版两段

| 原版 | 为什么删 |
|---|---|
| `_IntroducePlayerText`（「First, what is your name?」） | 三键设备上取 4 字名要按 840 次（[S12](S12-naming.md) 算过），自由取名在这台设备上不成立 |
| `_IntroduceRivalText`（「这是我孙子，你的对手」） | 本项目单机、没有对手角色，也没有任何地方会再提到他 —— 留着会开一个永不回收的伏笔 |

两段都记在 `OMITTED` 里，便于以后查证「为什么没有」。

## 16.4 七框台词

```
① 你好！/ 欢迎来到 / 宝可梦的世界！
② 我叫大木 / 人们都叫我 / 宝可梦博士
③ 这个世界里 / 生活着一种 / 被称为宝可梦的生物      ← 皮卡丘出场
④ 有人把它们当作伙伴 / 也有人 / 让它们互相切磋
⑤ 而我 / 把研究宝可梦 / 当作毕生的事业              ← 停顿 20 帧
⑥ 你的宝可梦传奇 / 就要开始了！
⑦ 一个充满 / 梦想与冒险的世界 / 正在等着你 / 出发吧！  ← 博士退场
```

21 行 115 字，最宽 144px / 232px。四行正好是原版文本框的容量上限。

第 ⑤ 框的「而我」单独一行 —— 原版 `Myself...` 是单独一框（一个停顿），
这里并进同框但保留那个节奏。

## 16.5 三键

| 键 | 动作 |
|---|---|
| **A** | 推进（打字中按下则**立即显示整框**，不是跳到下一框） |
| **B** | 无 |
| **C** | 跳过全部 |

A 键在打字中立即显示整框是原版行为，也是唯一合理的：
玩家想快看完这句，而不是错过它。

**B 键刻意空着**：开场只跑一次，「上一句」在这里没有意义
（玩家还没有任何信息需要回看）。空着比塞一个功能好 ——
三键设备上每个键都该有明确的期待。

打字机 3 帧一字（汉字信息密度比英文高得多，每帧一字会快到读不了）
→ 整段 **13.6 秒**。
