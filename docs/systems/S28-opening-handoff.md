# S28 · 博士开场到初始伙伴的过渡

正常看完博士介绍，或按C跳过，都先保留当前画面并淡出，再显示博士的邀请：“接下来，请选择陪你出发的伙伴。它们都在等着你！”邀请停留后淡出，初始伙伴选择页渐显。正常介绍没有删除台词。

过渡总长约3.7秒。沿用240×80横带，使用4×4有序像素淡化，不申请整屏帧缓冲；硬件和原生预览共用实现。开场过渡、选择页渐显均标记busy并锁定输入，重复A/C不会跳过承接或误选。页面退出清理计时器，已进入选择页的存档仍可直接恢复选择。

`verify_opening_transition.py`验证正常/跳过、过渡中连续按键、渐显完成后选择、896次局部重绘与完整画面对比。固件编译通过。历史录制脚本增加等待时长，新的完整故事版按实际页面状态等待，不依赖固定时间抢按。

此改动不修改存档格式；当前固件包含上一轮V12仓库修复。设备烧录状态另见交付说明。
