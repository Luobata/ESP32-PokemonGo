# S2 捕获判定

把一次遭遇结算成「捕到 / 没捕到」，用**时机判定 + 球种选择**两层决策撑起 5 秒内的交互。

## 输入 / 输出

| 方向 | 来源 / 目标 | 字段 |
|---|---|---|
| 入 | S1 队列的 `Encounter`（`sim/gameplay.py`） | `species_id`、`rarity` |
| 入 | `assets/gen1.bin` 记录 | `capture_rate`（offset 6，原版数值：皮卡丘 190、超梦 3） |
| 入 | `sim/gameplay.py` 的 `PetState` | `catch_window_bonus` —— 心情直接乘窗口宽度 |
| 入 | S3 战斗结果 | 野怪剩余 HP 比例 → 窗口加宽 |
| 入 | S9 道具 | 球种与库存 |
| 出 | S5 图鉴 | 置「已捕」位 |
| 出 | S9 道具 | 扣球（无论成败） |
| 出 | S1 队列 | 成功或逃跑则移除该条 |

## 核心逻辑

**第一层：时机判定。** 指针在 200px 宽的条上以 1.2 秒一个往复来回移动，
按 A 键时判断指针是否落在窗口内。

基础窗口宽度按 `capture_rate` 线性映射：

| capture_rate | 基础窗口 | 例 |
|---|---|---|
| 190 | 190 px | 皮卡丘 |
| 45 | 约 60 px | 妙蛙种子 |
| 3 | 3~8 px | 超梦 |

实际窗口 = 基础窗口 × `PetState.catch_window_bonus` × 球种系数 × 战斗加成。
`catch_window_bonus` 的定义已在 `sim/gameplay.py`：`1.0 + (mood - 50) / 100`，
即心情 100 给 1.5 倍、心情 0 给 0.5 倍 —— **这是「养成反哺探索」的唯一落点**
（[04-gameplay.md#433](../04-gameplay.md#433-养成如何反哺探索)）。

**第二层：球种选择。** B 键循环切换：

| 球种 | 系数 |
|---|---|
| 精灵球 | ×1.0 |
| 超级球 | ×1.5 |
| 高级球 | ×2.0 |

窗口宽度最终 clamp 到 `[3, 200]` —— 上界防止 200px 条被填满导致「必中」，
下界保证极稀有种也不是数学上不可能。

**失败后果**：消耗球，且野怪有概率逃跑。逃跑概率随稀有度递增
（★ 约 10% → ★★★★★ 约 50%，**待 Phase 0 验证**）。逃跑则该条从 S1 队列移除。

**动效复用**：命中瞬间用 `sim/effects.py` 的 `flash_sequence()`，
失败抖动用 `shake_sequence()`。捕获成功后由 S8 判定闪光。

## 数据结构

无独立持久化。球种库存归 S9；捕获结果写入 S5 的位图。
单次判定的临时状态（指针相位、当前球种）只存在于会话内存，掉电即弃 ——
一次交互 ≤5 秒，不值得存档。

## 与三键约束的关系

对应 **P4 捕获页**：**A 投球 / B 换球 / C 取消**。

指针往复 1.2 秒 = 屏幕刷新压力可控（条宽 200px，只需重绘指针所在的那一条横带，
符合[分块渲染约束](../01-constitution.md#11-硬约束清单)）。整个交互
按键次数是 1~3 次，5 秒内结束，符合 30 秒会话预算。

## 待 Phase 0 验证的参数

| 参数 | 当前值 | 依赖 |
|---|---|---|
| 指针往复周期 | 1.2 s | 实机 SPI 刷新率。若指针重绘跟不上，周期要放长 |
| capture_rate → 窗口的映射曲线 | 线性 190→190px / 3→3px | PC 端手感调参（不需要硬件） |
| 逃跑概率表 | ★10% ~ ★★★★★50% | 玩家实测挫败感 |
| 窗口 clamp 上下界 | [3, 200] px | 同上 |

映射曲线与逃跑表可以在 `sim/` 里先调（Phase A），不阻塞硬件。
08-systems.md 把 S2 标为「不依赖实测」是就**硬件**而言 —— 手感仍需调参。

## 边界情况

1. **球库存为 0** —— P4 直接不可进入，P3 的「A 捕获」置灰，提示去探索获取。
2. **`catch_window_bonus` 为极值** —— 心情 0 时系数 0.5，超梦窗口算出 1.5px；clamp 到下界 3px 保证不是零概率。
3. **窗口宽度 ≥ 条宽** —— 皮卡丘 190px × 1.5 × 2.0 = 570px 远超 200px；clamp 到 200 后仍是「必中」，可接受（原版低阶怪本就好抓），但不能出现指针越界。
4. **捕获成功但图鉴位已置** —— 重复捕获合法，不报错；S10 只计首次。
5. **判定中掉电** —— 球尚未扣、图鉴未置，重启后该条遭遇仍在 S1 队列里，等于什么都没发生。这是有意的：宁可白送一次机会，不能扣了球又没结果。
