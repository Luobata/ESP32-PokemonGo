# S15 转场与出场动画

闪光星环 / 遭遇转场 / 进化闪烁。实现见
[`sim/transitions.py`](../../sim/transitions.py)。

**参数全部来自 pret 反汇编逐行阅读，不是估的：**

| 内容 | 来源 |
|---|---|
| 闪光星环 | `pokecrystal/data/moves/animations.asm` `BattleAnim_SendOutMon.Shiny` |
| 转场 | `pokered/engine/battle/battle_transitions.asm` |
| 进化 | `pokered/engine/movie/evolution.asm` `EvolveMon` |

三处都有容易做错的地方，抄对了才有那个味道。

## 15.1 闪光：不是星星向外飞散

**8 颗星停在半径 16px 圆周的固定角度**（反汇编注释原文
"Puts object in a circle formation of radius $10"），
从正右方起顺时针每 45° 一颗、每 4 帧点亮一颗。

星星**不动** —— 偏移只在生成时算一次。每颗自己活 20 帧
（帧集 5 帧 × duration 3 → 每帧显示 4 帧）后自删。

所以圆环是「逐个亮起并各自消失」的流动感，不是 8 颗同时长亮的静态环。

| param | 偏移 | 方位（y 向下） |
|---|---|---|
| `$00` | (+16, 0) | 右 |
| `$08` | (+11, +11) | 右下 |
| `$10` | (0, +16) | 下 |
| `$18` | (-11, +11) | 左下 |
| `$20` | (-16, 0) | 左 |
| `$28` | (-11, -11) | 左上 |
| `$30` | (0, -16) | 上 |
| `$38` | (+11, -11) | 右上 |

总 **64 帧**（8×4 + 尾 32）。叠加 BGP 反相闪 3 次（每次 4 帧）
+ OBP0 黄/灰每 2 帧循环。

**时序位置**：插在「sprite 已就位」与「叫声」之间，
是独立的第二次动画调用 —— 普通遭遇这里什么都不插。

原版 Gen 2 的判定是 DV（`Atk&%0010≠0 且 Def=Spd=Spc=10` → 1/8192）。
本项目不做个体值，用 `crc32(bssid|hour|rarity)`，概率取 **1/512** ——
8192 是为几百小时流程设计的，而这台设备遭遇频率低得多。

## 15.2 转场：完全确定性，不随机

3 个 bit 查表，**没有随机数**：

| bit | 判据 |
|---|---|
| 0 | 训练师战 |
| 1 | 敌方等级 ≥ 我方首只未濒死 +3 |
| 2 | 密闭 biome（原版是「迷宫地图」） |

这是原版一个聪明的设计：**玩家会从转场认出对手强弱** ——
看到某种转场就知道这场不好打。随机化会毁掉这个信息通道。

原版 bit2 是「迷宫」，本项目换成 biome —— 我们没有迷宫但有 biome，
而「在什么地方遇到」同样该影响观感。野外/交通枢纽算「开阔」，其余算「密闭」。

| bits | 转场 | 帧数 |
|---|---|---|
| 000 | 双圆 | 102 |
| 001 | 内螺旋 | 153 |
| 010 | 圆形 | 132 |
| 011 | 外螺旋 | 120 |
| 100 | 横向百叶 | 60 |
| 101 | 向心收拢 | 64 |
| 110 | 纵向百叶 | 54 |
| 111 | 上下撕开 | 64 |

机制上全是**往 BG tilemap 写纯黑 tile**（30×40 网格），
不是 scanline 也不是调色板；只有圆形系开头那 72 帧闪屏用调色板。

百叶窗要**隔行填充**才有透光感 —— 一次填满整行就只是幕布下落。

## 15.3 进化：加速的黑色剪影

反汇编 `lb bc, $1, $10` + 循环末 `inc b / dec c / dec c`：

| 轮 | 来回次数 | 轮间等待 |
|---|---|---|
| 1 | 1 | 16 |
| 2 | 2 | 14 |
| … | … | … |
| 8 | 8 | 2 |

**加速曲线必须照抄** —— 固定间隔就不对味了。
总来回 36 次 × 2 切图 × 3 帧 = 216，加轮间等待 72 = **288 帧**。

**整段闪烁用 `PAL_BLACK`**：两个形态都是黑影在跳，不是彩色图对切。
结束时才恢复新形态的正常调色板。

切换机制是两个 pic 都在 VRAM、对 7×7 tilemap 区块的 tile id 加减 `$31`
—— 不重传图形数据，很适合照搬。

**闪烁期间没有逐次音效**，只有一段 BGM（原版复用 Safari Zone 曲）。
逐次加音效会变成噪音。

## 15.4 渲染预算

240×320 整帧 RGB565 = 150 KB，而 SRAM 只有 400 KB ——
转场不能整帧重绘，必须按 240×16 横带刷（7.5 KB × 20 条）。
