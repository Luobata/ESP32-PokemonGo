# S11 开场流程

初次启动的一次性流程：GB 启动动画 → 标题 → 选初始伙伴。
之后由 [S6 存档](S6-save.md) 的存在判定跳过。

实现见 [`sim/intro.py`](../../sim/intro.py)，验收面板在 inspector 的
「S8-S11 元系统」tab（逐帧可步进）。

## 11.1 启动动画：参数来自 boot ROM，不是估的

复刻 DMG 开机那段 logo 下滑。参数取自
[boot ROM 反汇编](https://gist.githubusercontent.com/drhelius/6063288/raw)：

| 反汇编 | 含义 | 本项目 |
|---|---|---|
| `LD D,$64` | 滚动 100 次，每次 SCY 减 1 | `SCROLL_STEPS = 100` |
| `CP $62` | H==98 → 播 sound #1 | `SOUND_STEP_1 = 98` |
| `CP $64` | H==100 → 播 sound #2 | `SOUND_STEP_2 = 100` |
| `LD D,$20` | 落定后 32 次暂停循环 | `SETTLE_PAUSE_STEPS = 32` |

**关键细节：两声音效在第 98 与 100 步响，也就是落定瞬间。**

很多复刻版把「叮」放在动画开始，那是错的 —— 原版是 logo 停住的**同时**出声，
节奏感完全不同。这一条只有读反汇编才能确认，凭记忆一定会写错。

共 132 帧，30fps ≈ 4.4 秒。logo 从 Y=220 落到 Y=120
（略高于中线，给下方标题留空间）。

### 为什么只放一次

GB 启动动画的仪式感来自「开机」。而这台设备屏幕不能常亮、点亮很频繁，
每次都放 4.4 秒会从仪式变成负担。所以只在首次启动跑，
之后按任意键也能跳过（刷固件调试时用得上）。

## 11.2 伙伴选择：三球 + 一只在球外

```
┌────────────────────────┐
│   CHOOSE  A  PARTNER   │  40
├────────────────────────┤
│                        │
│    ◉      ◉      ◉     │ 150  三球一排（御三家）
│           ☝            │ 180  手指光标在目标下方
│                        │
│              ⚡        │ 226  皮卡丘 —— 在球外
│              ☝         │ 256
│                        │
│        小火龙  火       │ 292  当前目标（球未开时显示 ???）
│      NOT IN A BALL     │ 308  仅当光标在皮卡丘上
├────────────────────────┤
│ [A]确认 [B]移动 [C]预览 │
└────────────────────────┘
```

**为什么皮卡丘在球外**：它在原版黄版里就是跟在训练家身后的，从不进球。
放在三球之外，一眼就能看出「这只不一样」—— 不需要任何文字说明。
它的位置刻意不与三球对齐（X=172 而非 120），强化这一点。

坐标：`BALL_XS = (54, 120, 186)`、`BALL_Y = 150`、`PIKA_POS = (172, 226)`。

### 手指光标为什么在下方而不是左侧

原版菜单的手指在选项左侧向右指 —— 但那是**纵向列表**。这里是三球横排，
240px 宽装不下「每球各配一个左侧手指」：

```
每格需 手指22 + 间隙30 + 球34 = 86px
三格 258px > 240px          ✗
```

这是实算出来才发现的。改成手指在目标**下方指向上**：只占垂直空间，
三球 102px + 间隙 24px = 126px 绰绰有余。

保留「手指」这个形状而不换成箭头 —— 那是初代菜单最认得出的符号，
换成箭头功能一样但味道就没了。

### C 键预览：对原版的一处刻意偏离

原版是选了才知道球里是什么。但对**三键无触摸**的设备那太苛刻 ——
玩家看不到球里是什么，选择就是纯赌博，而这是整个存档的起点。

所以允许 C 键开球预览，但保留「开球」的动作感：球会打开、sprite 弹出。
预览过的球保持打开状态，方便对比。

## 11.3 初始状态

| 字段 | 值 | 理由 |
|---|---|---|
| `pet_level` | 5 | 原版御三家等级 |
| `satiety` | 80 | 不给满，留出「照料能提升」的空间 |
| `mood` | 70 | 同上 |
| `stamina` | 90 | |
| `intimacy` / `explore_value` | **0** | 初始伙伴也要靠养成推进，不白送进度 |
| 道具 | 精灵球 ×5、浆果 ×3 | 够起步，不够挥霍 |
| 图鉴 | 该只标记为已捕获 | |

**等级 5 与野怪 ★ 档同级**（见 [S3](S3-battle.md) 的 `WILD_LEVEL_BAND`），
所以第一场战斗是五五开。而新手第一场应该赢 —— 靠送的 5 个球先捕获起步，
而不是靠调高初始等级。这样「练级」从第一分钟就有意义。

## 11.4 状态机

```
PHASE_BOOT ──tick() 132 帧──▶ PHASE_TITLE ──任意键──▶ PHASE_CHOOSE
     │                                                     │
     └──任意键（跳过）───────────────────────────────┘   A 键
                                                            ▼
                                                       PHASE_DONE
                                                     result() → 初始存档
```

`IntroFlow.tick()` 每帧返回一个 `BootFrame`（含 `logo_y` 与 `sound`），
`press(key)` 处理三键。`result()` 只在 `PHASE_DONE` 返回存档字段。

## 11.5 固件注意

- 132 帧是**逻辑帧**，不是定时器 tick。固件按实测帧率调 `SCROLL_STEPS`
  的插值步长，而不是改帧数 —— 改帧数会破坏「音效落在第 98/100 步」这个比例
- logo 位图不复用 GB 的原始压缩数据（那是任天堂的），
  用等比放大的自绘版本：72×12，1bpp = 108 字节
- 两声音效待 [5.2 音频路线](../05-art-audio.md#52-音频路线) 落地
