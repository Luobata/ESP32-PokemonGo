# 成就与奖励

菜单 → 成就（P14）。A 领取、B 下一项、长 B 上一项、C 返回。每项奖励只能领取一次；背包不足以容纳整份奖励时保留领取资格。存档失败也不会扣除资格或发放部分道具。

| 条件 | 奖励 |
|---|---|
| 图鉴捕获 2 种 | 超级球 ×5 |
| 图鉴捕获 5 / 10 / 25 种 | 雷之石 / 水之石 / 叶之石 ×1 |
| 图鉴捕获 50 / 100 / 151 种 | 通讯机器 ×1 / 成长机器 ×2 / 大师球 ×1 |
| 捕获 1 / 3 种闪光 | 月之石 ×1 / 大师球 ×1 |
| 完成 1 / 5 次进化 | 火之石 ×1 / 通讯机器 ×1 |
| 获得 1 / 4 / 8 枚徽章 | 牛奶 ×5 / 月之石 ×1 / 成长机器 ×1 |
| 战胜青绿 | 大师球 ×1 |
| 战胜赤红 | 通讯机器 ×2 |

图鉴以物种计数，包含初始伙伴和进化形态；闪光同样按物种去重。旧版图鉴和挑战记录可直接达成对应成就；旧版没有进化事件计数，所以进化次数从更新后累计。

V8 存档在完整 V7 的 2688 字节之后追加进化次数与已领取位图，含结构体尾部对齐共 2696 字节。V5/V6/V7 均支持迁移。奖励库存和领取位在同一次 NVS blob 提交中持久化，成功后才发布到世界状态。进化计数同样与进化结果一起提交。
