# S20 路线探索（V11）

入口：待机 → 菜单 → 探索。四条路线均可选择，长按 B 上一项；选择路线不消耗机会。

## 机会来源

沿用 Wi-Fi 环境变化感知，每累计 1024 Q10 信用兑换一次探索机会，一次扫描最多兑换四次。基地四小时补充也改为机会，需要有符合冷却条件的扫描结果，按设备累计运行时间计，不补算关机时间。同一 AP 一小时冷却，最多保留 64 条最近历史，满表不淘汰仍在冷却的 AP。

机会最多 24 次；满额不消费 AP 冷却或兑换信用，信用自身最多 4096 Q10。首次启用探索系统赠送三次机会，仅一次，新游戏和 V5–V10 升级均适用。Wi-Fi 不再直接生成宝可梦；真正发现宝可梦时才发送普通、稀有或闪光声音提示。

这是环境变化感知，不是计步或 GPS。四条路线是虚拟玩法选择。本次未增加诱饵、队伍探索加成或手机传感器接入。

每次成功探索消耗一次机会和 5 点体力；体力不足、候选冲突或保存失败均不扣除。体力白天每小时恢复 12 点，仅随运行时间恢复，熄屏有效，完全关机不补算。普通遭遇与线索交替，每两次探索取得一条线索，三条线索后的下一次探索必定出现目标：遭遇 → 线索 → 遭遇 → 线索 → 遭遇 → 第三条线索 → 目标。

各路线分别保存线索与交替进度，切换路线和重启不清空。目标出现后开启新一轮。若目标或所抽稀有度的全部候选已在待处理列表，提示先处理同类，不扣机会或线索。

151 只宝可梦均分配到至少一个路线池。稀有度基础概率从五星到一星为 1%、5%、19%、40%、35%，环境发现进度及养成状态可有限提高高稀有概率；养成最高将三星以上累计概率提高 5 个百分点，见 S4。最多每八次宝可梦发现保证一次四星以上，每三十次保证一次五星；线索不计入次数。目标至少三星，同样参与保底。闪光独立判定：五星 1/256，其余 1/512。

## 遭遇和保存

- 新发现进入原有五格 FIFO 队列；已满则替换最早的一只，总览提前提示。
- 发现后 A 查看，进入原有捕捉、战斗、逃跑选择。B 继续回总览，不自动扣下一次机会。
- 直接捕捉失败反击一次，仍可再次选择；主动战斗继续自动对战。捕获或逃跑结束返回探索页。
- 600 ms 发现动画锁定玩法输入；自动熄屏不会打断，长按 C 手动熄屏仍可使用。
- 路线、机会、线索、保底、队列和图鉴通过候选快照一次提交 NVS，成功后才发布。失败不扣次数、不提示虚假的发现。
- V11 在完整 V10 的 3648 字节前缀后追加 16 字节探索状态，总计 3664 字节。既有队伍、仓库、图鉴、道具、挑战、成就和刷新冷却保留，音量/静音仍使用独立设置键。

`tools/pipeline/verify_exploration_preview.py` 验证同源页面、长按 B、保存失败、线索、目标、捕获成功/失败、逃跑、熄屏及横带重绘。网页 P15 与硬件共用页面和规则代码；浏览器的 NVS/Wi-Fi 边界为隔离夹具，真实保存逻辑由前一组测试覆盖。

四条基础路线保持开放，已有线索直接延续到升级后的追踪目标，不清空。普通随机遭遇也检查化石、传说与幻之宝可梦的进度门槛，不能通过随机刷新越过解锁条件；旧队伍、已排队遭遇和已获得道具保留。

线索事件有 40% 机会拾取探索补给：初始树果，以及所有已解锁章节的道具。赤红阶段的大师球使用额外的四分之一命中门槛，否则改为成长机器；未获得大师球不影响原有冠军成就奖励。背包满时明确提示未拾取，不超额增加。此处解锁的是新的探索获取渠道，原有战斗和成就奖励继续可用。

道具拾取与线索、机会扣除使用同一存档事务，保存失败时全部回滚。本次不扩大存档，也不再次赠送初始机会，继续兼容 V11。新增 `verify_exploration_campaign.py` 验证九阶段、36 个目标组合、36,000 步门槛/道具序列及真实 NVS 失败回滚；`verify_exploration_journal.py` 验证笔记浏览不消耗机会。

## 地图与伙伴成长联动

成功探索（遭遇、线索、目标）同时让当前队首探索值 +1，最高 65535，与体力和机会扣除一并保存。自然进化直接使用该探索值；换队后数值随伙伴保存。原 Wi-Fi 移动累计仍保留，失败或浏览路线不增加探索值。
