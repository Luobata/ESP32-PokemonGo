# P3 战斗数值与出场动画

`firmware/main/battle_presentation.c/.h` 只计算某一帧的显示值。它不读世界状态，不操作定时器，不结算攻击或经验，也不绘图。同一组参数在重绘、截图或交错采样后始终得到相同结果；ESP32 与原生预览都可直接使用这个 C 模块。

三个动画沿用 P3 的 60 ms 定时器，全部使用整数。常量表示**时间间隔数**，所以包含起点和终点时应采样 `0..N`；超出终点仍返回最终状态。

| API | 参数与输出 | 时长 |
|---|---|---|
| `battle_presentation_hp(from_hp, to_hp, missed, frame)` | 命中前、后的 HP → 显示 HP | 6 个间隔，360 ms |
| `battle_presentation_exp(from_total, to_total, cap, frame)` | 累计经验 → `total / level / got / need` | 18 个间隔，1,080 ms |
| `battle_presentation_entry(frame, pet_start_dx, wild_start_dx)` | 起始横移量 → `pet_dx / wild_dx` | 12 个间隔，720 ms |

扣血从命中阶段开始。页面在调用 `battle_session_step()` **之前**记录双方 HP，调用后保留新的真实 HP。前摇继续显示旧值；到命中阶段，用经过的动画帧数分别采样双方 HP。未受伤一方的起止值相同，`missed=true` 时始终显示旧 HP，即使错误传入了更低的目标值也不会播放扣血。更高的目标值也不会让扣血动画变成回血。

`battle_presentation_hit_frame(battle_fx_frames(round))` 对应当前特效的第 6 个创作阶段：先扣除末尾两个清理帧，再取有效帧数的一半并向上取整。12 / 14 / 16 / 18 帧招式的命中起点分别是 5 / 6 / 7 / 8。HP 动画的 `frame=0` 保留起点，下一帧开始变化；所有现有时长都能在下一次攻击前抵达真实 HP。若今后改变特效的阶段划分，应一并更新这个适配函数。

经验奖励应先按既有一次性结算规则提交，再从结算前累计经验动画到实际结算后累计经验。模块复用 `exp.c`，每帧重新推导等级和本级进度，所以跨级时会进入新等级的进度条；它不会把整次奖励错当成同一级的条宽。`cap` 钳制到 1..100，达到上限后输出满条 `got=need=1`，不计算 101 级。中间乘法使用 `uint64_t`，最大 `uint32_t` 累计经验也不会回绕。奖励消息可继续显示本次奖励总额，等级与蓝条使用模块的显示结果。

出场方向参考固定版本 pokecrystal（`7a7881d0d62e0ddbd82dcf10e7116807487ac651`）的 `engine/battle/sliding_intro.asm`：敌方所在上半屏的 SCX 逐帧递减，图像向右进入；下方 player OAM 的 X 逐帧递减，图像向左进入。本项目只采用方向，720 ms 时长与整数线性平移是项目自己的适配，不是原版逐帧仿真。

当前 P3 可传主宠起点 `SCREEN_W - SCENE_P3_PET_BACK_X`，野怪起点 `-(visible.x + visible.w)`，让双方完整可见图形分别从右、左屏幕外进入。模块不会改变源画布、缩放、透明像素或纵坐标。页面应直接叠加入场位移，不能再用战斗受击位移的区域限位将它截断；HUD 的前后绘制顺序和屏幕裁剪仍由页面负责。每次移动须重画所有可能经过的横带，并在末帧绘制零偏移，避免残影。

动画不承担“只播一次”的持久化职责。页面须按遭遇 UID/时间标识记录首次出场，在 P4 或队列返回同一遭遇时使用已提交 HP 与经验，不重新初始化旧端点。切页不撤销攻击、捕获失败后的反击义务或已结算奖励；是否继续自动战斗由实际战斗会话决定。暂停或重绘也不能偷偷递增采样帧数。

验证命令：

```sh
python3 tools/pipeline/verify_battle_presentation.py --negative
```

该测试直接编译生产模块及 `exp.c`，覆盖 4,738 次 C 采样，包括双方受击、miss、命中时点、单点伤害、致死扣血、等级边界、跨级、等级上限、最大整数经验、出场方向、正负偏移极值和倒序重绘。五个能够成功编译的损坏版本必须报错：miss 仍扣血、经验乘法溢出、上限继续画下一级进度、出场末帧偏移残留、前摇提前扣血。这里证明纯模块的数值与时序边界；P3 生命周期、按键与横带重绘另需真实页面流程验证。

## 2026-09-08 技能辨识度复查

近身技能由 12 帧延长为 20 帧，常规属性技能 22–24 帧，重型技能 28 帧，多段技能 24+命中数×2 帧；节拍仍为 90ms。原普通命中阶段 360ms，调整后 540ms。放大冲击、拳脚、切割、针刺、咬合、电光等小素材，电击核心保持 1x、电光为 2x；不改变命中、伤害、随机数或技能学习规则。

野战结算保存失败停留并允许 A 重试，不能先退出跳过奖励；训练家结果页显示实际到账经验，成功结算后明确提示已保存，解锁探索情报按结算前后章节判断。
