# S7 进化

> 2026-09-11：等级与道具进化共用约8.5秒演出，成功后C确认退出；等级进化按实际等级判断。详见 ../../reports/evolution-scene-2026-09-11.md。

2026-09-08：本节已替代旧的“不做进化石、按 biome 驻留进化、提高交换进化亲密门槛”方案。当前项目已有等级、五种进化石、通讯机器和成长机器。自然 LEVEL 进化保留既有免费养成通道，ITEM 与 TRADE 必须消费对应道具。

## 三类进化入口

| 入口 | 适用物种 | 条件与消费 |
|---|---|---|
| P5 自然进化 | `EVO_TRIGGER_LEVEL` 且存在有效目标 | 亲密度 ≥60，探索值 ≥`max(10, evolve_level × 2)`；免费 |
| P10 成长机器 | 同上，且原等级门槛非零 | 实际等级 ≥`evolve_level`；消费 1 台，跳过亲密度和探索条件 |
| P10 进化石 / 通讯机器 | 下表中的明确物种 | 消费对应道具 1 个；不额外要求等级、亲密度、探索或驻留 |

自然通道延续本项目已有规则，不另外检查实际等级。比如妙蛙种子的自然条件是亲密度 60、探索值 32；成长机器则要求 Lv16。两条通道提供不同选择，不能将成长机器理解为强制门票。

P5 与 `world_evolve_leader()` 都只接受 LEVEL，避免页面或旧调用绕过石头/通讯机器。进化在当前主宠上执行；页面显示物种与真实队首不一致、仍有活动战斗、库存为空或条件不足时拒绝操作。

## 进化结果与保存

`world_item_use(expected_species, item_id, out)` 返回前后物种、前后养成值及剩余库存。道具进化把队首物种、养成、图鉴和扣道具放入同一候选存档；`world_evolve_leader()` 对免费自然进化使用相同保存流程。

进化保留等级、EXP、当前 HP、昵称、闪光标记、亲密度和探索值，心情延续既有 +15 奖励并限制在 100。图鉴保留旧形态记录，并将新形态标为已见、已捕获；闪光个体同步新形态的闪光捕获记录。下一段自然门槛从新物种的数据重新计算，不重置养成进度。

NVS 提交成功后才发布新形态和库存。保存失败时旧形态、道具数量和图鉴保持不变，页面可重试；不能先播放成功反馈后丢失道具。库存保存使用 V6，兼容有效 V5 迁移，详细结构见 [S9 保存与事务](S9-items.md#保存与事务)。

## 页面反馈

P5 根据当前 LEVEL 条件显示自然进化入口与进度，沿用已有进化表现。P10 背包显示进化道具说明，A 使用后直接报告新形态名称；无效目标、等级不足、伙伴已更换、道具用完、保存失败等分别反馈。背包里的道具进化没有额外承诺一套独立动画。

## 验证范围

`verify_items.py` 独立解析固定上游物种常量、进化指针和进化表，与实际 `items_apply()` 的 20 条石/通讯结果比较。真实 `world/save` 探针检查所有路线的物种/图鉴/属性保留、成长机器 Lv15 拒绝与 Lv16 成功、免费自然路线、ITEM/TRADE 绕过拒绝，以及保存失败后原状态和道具不变。

详细结果见 [道具核心验收](../../reports/items-core-2026-09-08.md)。旧文档中的 biome 驻留、NFC/BLE 交换和交换高亲密度替代条件均不是当前可用入口。

### 进化声音衔接（2026-09-11）

统一演出先播原形态叫声，再启动进化音乐；揭示新形态时播放进化音序，光球结束播放新形态叫声，最后是成功曲。151只物种叫声采用固定Gold源数据的38组音轨及独立音高、时长参数，单声道重合成，尊重硬件静音与音量。取消会停止当前叫声并恢复页面音乐。
