# S27 · 仓库同类占位导致无法换入

旧仓库按物种编号固定存放一只。队伍换出A、仓库换入B时，如果仓库原有另一只A，旧逻辑直接拒绝，并显示“仓库同类占位 请先换出”。即使仓库有很多空格也无法完成这次交换。

修复后仓库使用151个实际格子，换出的个体进入换入个体刚腾出的格子。交换不会合并、覆盖或放走同类，等级、经验、闪光、亲密度、探索值等完整保留。同物种多个个体以完整快照识别，防止选中闪光却换入另一只。捕获时原有同类择优入库规则保留；本次改变的是换宠的保存方式。

保存格式升级为V12，大小仍为3664字节。V11和更早版本先按旧物种索引规则验证，再原位迁移；V12按格子读取，重启不会合并重复个体。旧固件不支持V12，升级后不要用旧固件继续游戏。NVS提交失败保留原队伍和仓库，可以重试；战斗锁和过期选择检查保留。

验证：

- `verify_world_party.py`：39项实际C/NVS测试，包括满队同类冲突、未满队伍换入、满151格交换、同类个体选择、旧存档迁移、异常旧存档拒绝、保存失败回滚、重启恢复。未调用擦除存档。
- `verify_box_exchange.py`：实际C页面复现、保存失败提示、重试、两个皮卡丘中的闪光选择和局部重绘检查。
- `verify_party.py`：原有捕获入库、队首切换、200次连续捕获与序列化回归。
- `verify_growth_links.py`：经验、养成、体力与仓库交换回归。

结果和截图见 `reports/evidence/box-exchange-2026-09-09`。固件构建通过；真机烧录状态以设备验证记录为准。
