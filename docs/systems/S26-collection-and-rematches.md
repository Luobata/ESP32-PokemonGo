# S26 · 图鉴追踪、队伍联动与道馆重赛

## 图鉴与收集

图鉴网格按A进入详情；B下一只、长B上一只，C回网格。详情显示正面图、原生随机池稀有度、栖息地和直接遇敌的剧情门槛。A追踪已开放物种，会跳到对应地图；已捕获也能追踪，便于闪光收集。再次在同一详情按A取消。

追踪沿用三段线索循环，从零线索开始通常七次探索出现目标。改变目标会清除旧目标路线和新路线的线索，防止挪用完成的线索立刻刷稀有物种。队列中已存在同种目标时保留线索和资源，先处理现有遭遇。目标出现仍需正常投球捕获；捕获失败不清除追踪，可再次完成线索。剧情锁继续生效。

随机遭遇75%的种子分支优先在本次稀有度池中选择已开放、未捕获且未在队列中的物种；没有候选则退回原规则，不跨稀有度升级。原有8次稀有／30次精英保底继续生效。指定目标的稀有度不低于其原生池，以免神兽被当成三星遭遇。

化石、三神鸟、超梦、梦幻分别具有三段主题线索文案，最终接入正常遭遇、捕获、图鉴、经验及成就。这是短线索事件，不是新增大型剧情地图或完整NPC演出。

## 队伍联动

野战胜败、捕获成功时，原有非主宠队员额外获得主奖励的20%，向下取整；刚捕获加入的新成员不分享自己的捕获奖励。训练家战中，原参与者继续平分主奖励，未参与队员各额外获得总奖励的20%。不从主宠或参与者奖励扣除。经验修复等级下限、上限100，并随原来的结算事务保存；重试不重复发放。

地图匹配属性如下：森林草/虫，山洞岩石/地面，海滩水/冰，电站电/毒。每个不同物种的匹配队员贡献10点探索稀有判定加成，最多30点；重复同种不叠加，不消耗技能或PP。页面显示助力数量。这个数不是百分比；它进入既有稀有度公式。原有体力和探索机会消耗不变。

## 通关重赛

战胜冠军后，已通关道馆自动改为六只主题队伍的强化重赛，等级65–74，出场顺序随本次种子轮换。初次挑战不变，联盟连战和赤红保留原有流程。经验根据实际敌方队伍等级计算。

重赛获胜：小刚月之石、小霞水之石、马志士雷之石、莉佳叶之石、阿桔通讯机器、娜姿成长机器、夏伯火之石、坂木通讯机器，各1个，满容量不追加。挑战结果和奖励原子保存，反复确认不重复领奖。
