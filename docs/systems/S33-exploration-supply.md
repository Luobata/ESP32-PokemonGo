# S33 探索补给

待机页原「今日行程」只是累计移动值的封顶显示，没有日切，也没有满格奖励。
现在该位置直接显示 `refresh.hunt_q10` 对应的下一次探索机会，以及
`exploration.energy / 24`。设备与网页都运行同一个待机页渲染器。

## 领取与容量

- 保留原移动判定：每次扫描确认正在移动且存在临时热点，才增加移动进度。
- 每 1024 Q10 移动量转为一次探索机会；余量进入下一轮。一次扫描最多兑换四次移动补给。
- 已完成的进度不再被热点的一小时冷却阻挡。热点冷却继续约束新地点统计与驻留补给，同一热点反复经过不会重复增加新地点奖励。
- 探索机会最多 24 次，满额时最多暂存 4096 Q10（四格）移动进度。消费后，下一次有效扫描即使处于驻留状态，也可补入已经攒好的机会。
- 原有首次补给及每四小时驻留补给保持独立；这类补给不会改变移动条的余量。没有有效 WiFi 扫描或设备关机时不兑现补给。
- 扫描获得的次数与剩余进度一起写入原 NVS 事务。保存失败不发布奖励、不扣掉已保存的进度；重启不会重复兑现。

## 页面

「探索补给」与进度条、`次数/24` 同行，下方显示说明：

- 通常：走动攒满增加1次。
- 次数增加：显示三秒「探索次数+N」。
- 已满：次数已满 先去探索。
- 空位刚释放且有一整格待兑现：补给就绪 等待扫描。

探索入口仍为待机页 B → 菜单 → 探索。体能规则保持不变，地图探索仍需同时消耗探索机会与体能。

存档保持 V14、3664 字节，直接使用已有机会和剩余进度。旧累计行程保留在存档与诊断接口，升级不会把它重新兑换成奖励。
