# S16 训练家挑战：道馆、徽章、联盟与赤红

2026-09-08：首版已接入固件 P13 与同源预览。入口是「菜单 → 挑战」。首次野战胜利解锁小刚，八馆顺序解锁，再到四天王、青绿、赤红；已有 V5/V6 存档保留队伍并开放第一馆。

当前实现：14 位训练家原版人物素材、八枚徽章、最多六对六、四招 PP、30 种支持的状态招式、自动交锋与指定下一招、主动换人/倒下替补、牛奶回复、认输确认。联盟保留 HP/PP/状态；大厅双击 A 补给，不能绕去其他馆刷新队伍。每次行动与结算先原子保存再发布，失败可重试，重启直接续战。首胜固定补给为两瓶牛奶；所有胜利给参战成员平分经验。全灭体能 -20、心情 -15，不扣经验；认输结束连战而不追加这项养成扣减。

操作：A 在本招结束后打开战术，选择招式/换人/牛奶；B 下一项、长 B 上一项；C 打开认输确认。长 C 熄屏，P13 熄屏期间暂停行动，唤醒键不提交战术。

**下面保留的是完整设计目标，不能作为全部已实现的说明。** 首版尚无强化重赛、邀请提示、名人堂快照、2×速度、NPC 主动换人/道具 AI、初始伙伴对应的青绿分支；青绿暂固定喷火龙/暴鲤龙/椰蛋树。联盟间补给目前仅支持牛奶，没有通用背包或更换先发。伤害与异常是明确的项目改编：常规中毒不递增；冰冻每次行动 20% 解冻，睡眠跳过 2–3 次行动；火/电/冰伤害招式使用统一 10% 附加状态概率。蓄力、硬直、优先级、多段次数等逐招规则仍需扩展，现有此类伤害招式按一次直接攻击处理。没有宣称完整复刻原作战斗机制。

实现：`firmware/main/trainer.c` / `play_trainer.c` / `world.c`，存档 V7；来源见 `assets/trainer_sources.json`。验证见 `tools/pipeline/verify_trainer_campaign.py` 和 `verify_trainer_preview.py`。

## 路线与解锁

先利用已有 151 只素材，做「关都八馆 → 石英联盟四天王 → 冠军青绿 → 赤红」。画面采用现在的金银风格，路线组合属于本项目改编。金银的关都馆主阵容和赤红原队伍可查[原作反汇编训练家数据](https://github.com/pret/pokecrystal/blob/master/data/trainers/parties.asm)；原版赤红含太阳伊布，本稿暂以拉普拉斯替代，避免静默引入未覆盖的二代素材。

解锁原则：**胜利推动主线，探索提供发现感，养成帮助备战**。不强制走步数、联网、特定地点或等待真实天数；坐着玩也能打完整条路线。队伍等级只显示建议，不阻止低等级玩家挑战。

| 挑战 | 推荐默认条件 | 准备提示，不作硬门槛 |
|---|---|---|
| 小刚 | 选好初始伙伴并取得首次野战胜利 | 带两只伙伴，准备补给 |
| 第二至第八馆 | 获得上一枚徽章 | 提示馆主属性与建议等级 |
| 石英联盟 | 集齐八枚不同徽章 | 建议六人队伍、回复与解状态道具 |
| 冠军青绿 | 同一次联盟挑战击败四天王 | 保留整趟联盟的 HP、PP 与状态 |
| 赤红 | 首次进入名人堂 | 建议六人高等级队伍 |
| 重赛 | 首胜后永久开放 | 可选普通/强化；不重复发徽章 |

可选的探索版本：第一馆还需累计完成 5 次遭遇，后续每馆增加一次「探索发现」任务；允许任意环境累计，且不因遭遇被 FIFO 顶掉而丢进度。这个版本先不启用。徽章数、野战胜利数、完成遭遇数、图鉴数量、最高队员等级均做独立条件字段，可更换组合；不把门槛写进界面代码。

达标时在待机页显示一次「收到挑战邀请」；菜单增加「挑战」入口，徽章墙和已解锁人物在其中查看。提示不抢占正在进行的战斗、捕获、进化或睡眠画面，唤醒后再显示。训练家不塞进最多 5 条的野生遭遇队列，邀请不会被新遭遇顶掉。

赤红出场保留简短的「……」和明显的角色剪影/立绘停顿，随后展示六颗球，最后一只出场使用更强的转场。音乐遵从全局静音设置，不能由剧情强行打开。

## 对战操作：让交锋密集，也能做决定

默认延续本项目的自动交锋：选「开战」后双方连续出招，血条、状态、伤害、技能特效依次播放。增加「手动战术」选项供需要时使用，不把已有野战强制改成每回合确认。

- 自动模式：A 在当前招式结束后暂停到战术菜单；B 切换 1×/2×播放速度；C 单击打开认输确认（A 确认，B/C 取消）。长按 C 始终只熄屏。结束前这次攻击只结算一次，速度改变只影响画面时钟。
- 手动模式：战术菜单提供招式、换人、道具、认输；A 选中，B 下一项，长 B 上一项，C 返回上层。已经在顶层的 C 打开认输确认。四招以两行或纵向四项显示，标清类型、PP 和当前选择。
- 换人、使用战斗道具占一次行动；自己的宝可梦倒下后选择替补不白送额外一击。对手换人、倒下和派出必须有对应视觉阶段，不能直接替换画面 ID。
- 自动模式中己方倒下时暂停选择替补；可在设置中选「自动派下一只」。队伍全灭才判整场失败，不能把一次倒下当成丢掉整个挑战。
- 训练家战不显示捕获选项，胜利后也不能抓对方宝可梦。C 的野战逃跑概率算法保留给野战，训练家战对应认输。

目标普通道馆约 2–4 分钟、单场天王约 3–5 分钟、赤红约 5–8 分钟；通过实测调节，不靠增加几千点虚假 HP 拉时长。每次招式演出目标 0.45–0.9 秒，强招 0.9–1.3 秒；多段招式连续打击后统一展示汇总，效果提示可合并。2×模式保持最少几帧关键姿势和清晰血量变化。

## 技能、AI 与养成

现在的核心是单对单自动会话，不能直接把 6 个单挑拼起来：那会错误回复血量、重复奖励，并丢失状态/PP。先把伤害及回合逻辑拆成可复用的队伍对战核心。

第一批效果：命中、速度/优先级、物理/特殊伤害、属性相克、会心、能力等级、麻痹/中毒/灼伤/睡眠/冰冻、吸取与回复、多段攻击、蓄力与硬直、反射壁/光墙、寄生与回合末伤害。天气等二代机制作为第二批能力，没实现前不配置到 NPC 招式中。

维持当前 15 属性版本，明确这是初代数据 + 金银画风的规则组合。首次发布前冻结一份规则清单：暴击是否忽略能力变化、冰冻解除、睡眠持续、招式分类等统一由核心决定，不让 NPC 各写一套。

AI 候选评分以公开局面为输入：预估伤害/剩余 HP（击倒加分）、命中可靠性、属性克制、已有状态是否重复、回复收益、强化后还能行动几次、剩余 PP。馆主允许保留少量非最优选择；联盟提高最优候选权重；赤红善用补盲与换人。AI 在双方行动提交后不能偷看玩家这一回合选择再改招。换人设收益阈值和冷却，避免来回互换。每名对手最多使用规定数量的回复道具，屏幕明确显示。

养成在入场时快照：饱食/心情/体能影响既有能力系数，亲密度保持成员所有。不在激战中因后台计时突然降低攻击。败北沿用现有体能、心情损耗，**不扣经验、不降等级、不掉道具**；整场一次，非每只倒下一次。联盟失败的主要成本是重新挑战和实际消耗的补给。提供战后「去照料」入口，避免惩罚叠加到无法恢复。

## 240×320 同构画面

继续用同一套 C 页面、字库、整数像素绘制和分带刷屏，Web 只负责送输入与展示实际帧。

1. 挑战大厅：人物名、属性、建议等级、徽章/首胜状态；A 查看，B/长 B 上下选，C 返回。
2. 挑战确认：对手像与队伍数量、自己六颗球、补给/养成提示；A 开战，C 取消。
3. 角色出场：玩家背影从左进入，对手正面从右进入；文字「馆主小霞前来挑战！」，队伍球列两侧对齐。首次完整播放，重赛可按 A 跳到发球，不跳过状态结算。
4. 派出：人物退场 → 球抛物线 → 开球光点 → 宝可梦原版动作帧 → 血条出现。对手正面左侧血条保持当前布局；我方背面与右侧血条成对。
5. 换人：收球/倒下 → 血条退场 → 下一只出球 → 原版动作；消息框不中途覆写未结束的攻击。
6. 胜利：角色回场及短台词 → 徽章居中展示 → 一次性奖励 → 返回大厅。赤红/冠军增加名人堂六人快照。

训练家正面/玩家背面、徽章与抛球帧必须有来源清单、许可记录、透明索引和调色板测试。素材未导入时以明确占位预览，不把宝可梦图当人物立绘交付。转场参考[Crystal 的波形、散点及场景/等级选择逻辑](https://github.com/pret/pokecrystal/blob/master/engine/battle/battle_transition.asm)，按本设备竖屏比例改编。

## 核心与存档边界

建议新增只读 `trainer_catalog`（稳定人物 ID、等级/四招/AI 参数、首胜奖励、解锁条件），以及与野生遭遇独立的 `trainer_challenge` 会话。

- `battle_side[2]`：各 1–6 个成员、当前槽位、16 位 HP、招式及 PP、状态、能力等级；临时战斗数据与现有 `mon_t.hp` 的 8 位历史字段分离，不强行截断高等级血量。
- `battle_action`：招式/换人/道具/认输；核心验证合法后一次提交。纯核心不读取 LVGL/真实时钟，产生有序 `battle_event`，演出消费事件。
- `challenge_progress`：八位徽章、首次冠军/赤红胜利、邀请已读位、联盟关卡与本次配额。不要复用野怪 `uid`。
- 挑战入场、回合结算、换场、奖励发放采用可恢复检查点；持久化 RNG、双方队伍 HP/PP/状态、已提交动作与奖励事务号。重启后继续已确定事件，不重抽掉落或双领徽章。
- 当前 V6 存档新增版本迁移，保留原队伍、仓库、图鉴、经验、背包、译名和养成。写失败保持旧状态并给重试提示；断电恢复先验校验和，不清档兜底。
- 整场战斗只结算一次胜负、惩罚和首胜奖励。参与过的成员平分基础经验；携带经验分享道具的规则另列，禁止把野怪奖励在每次换人时重新发放。

实现顺序：① 核心 2v2 + PP/状态 + 换人 + 恢复测试；② 小刚/小霞和人物演出；③ 八馆徽章与重赛；④ 联盟连战/名人堂；⑤ 赤红及高阶 AI。每步都能在预览里真实交锋并烧录验证，最后才开放后续人物入口。

验收必须覆盖：双倒下与回合末伤害顺序、全队耗尽、无可用 PP、控制无法行动、换人/道具消耗回合、反复睡醒不改 RNG、每个存档检查点断电、首胜双击/重启不重复奖励、满背包、旧 V6 迁移、屏幕两倍速与正常速度结果一致、六人双方多段大招交锋的内存上限与看门狗稳定性。当前 `BATTLE_MAX_ROUNDS=40` 不足以承载整趟联盟，应改成逐回合有界事件队列，而不是把所有六对六动画预先存到 RAM。
