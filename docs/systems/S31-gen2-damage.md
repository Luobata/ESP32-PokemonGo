# S31 金银能力值与伤害

本次修复对战耗时过长的主要原因：伤害已使用原版除数 50，但 HP 仍来自自定义成长公式。旧 5 级皮卡丘为 81 HP，50 级为 190 HP，明显不匹配原版伤害尺度。

## 数据与公式

151 只的六项种族值来自 [pret/pokecrystal base_stats](https://github.com/pret/pokecrystal/tree/7a7881d0d62e0ddbd82dcf10e7116807487ac651/data/pokemon/base_stats)。`convert_gen2_stats.py` 生成独立的 906 字节只读表，保留每个来源文件的 SHA-256。未改变精灵图像资源格式。

能力值按照 [CalcMonStatC](https://github.com/pret/pokecrystal/blob/7a7881d0d62e0ddbd82dcf10e7116807487ac651/engine/pokemon/move_mon.asm) 的第二世代规则，双方固定 DV=15，能力经验=0，不新增刷个体值或努力值的玩法：

- HP = floor(2 × (种族值 + 15) × 等级 / 100) + 等级 + 10。
- 其他能力 = floor(2 × (种族值 + 15) × 等级 / 100) + 5。
- 特攻与特防独立；沿用第二世代按属性划分物理/特殊招式。
- 例如 5 级皮卡丘 HP=20，50 级 HP=110。

[伤害指令](https://github.com/pret/pokecrystal/blob/7a7881d0d62e0ddbd82dcf10e7116807487ac651/engine/battle/effect_commands.asm) 的正常伤害流程：

1. 从实际攻击/防御或特攻/特防应用能力等级，限制在 1–999；处理灼伤、墙，以及暴击是否忽略这些修正。
2. 任一攻防数值超过 255 时，两者一起整除 4，最低为 1，重复到都不超过 255。大爆炸/自爆再将防御减半。
3. B = floor(floor((floor(2×等级/5)+2) × 威力 × 攻击 / 防御) / 50)。
4. 暴击时 B×2，然后 B 限制至 997，再 +2。
5. 同属性 ×1.5，属性克制，随机整数 217–255 /255；各步整数截断，非免疫伤害至少为 1。

聚气增加 1 个暴击等级，高要害招式增加 2 个，采用 17/32/64/85/128 除以 256 的概率表。瞬间失忆只升特防，暗影球只降特防，原始之力同时提升两项；黑雾和变身也处理两项。

固定伤害、等级伤害、挣扎无属性等既有规则保留。野战、训练家战、网页预览共用 C 实现。养成低心情的 0.6 攻击倍率、自动出招、无 PP 和防僵局疲劳机制继续保留；未加入天气、携带物和勋章的能力/伤害加成，也不复刻联机模式的字节溢出缺陷，因此不是整个原作战斗系统的逐字节模拟。

## 存档

版本升至 V13，结构仍为 3664 字节。V5–V12 读取时将训练家队伍及联盟连续战斗的 HP 换算为新最大 HP 的相同比例，存活者向上取整且至少 1 HP，已倒下者保持 0。替身、记录伤害和疲劳基准同步缩放；旧特殊能力等级迁移为两项。队伍、仓库、经验、徽章、物品不清空。V13 再次读取不重复缩放。非法旧存档先拒绝，不覆盖原始字节。

## 对战长度验证

8 组固定对局各跑 100 个相同种子，完整使用实际 C 自动出招与战斗结算。一个行动指任意一方出招或状态跳过，不代表双方各出一次招。

| 对局 | 原平均行动数 | 新平均行动数 |
| --- | ---: | ---: |
| 5 级皮卡丘 / 小拉达 | 15.38 | 9.41 |
| 10 级小火龙 / 绿毛虫 | 7.65 | 4.35 |
| 20 级皮卡丘 / 小拉达 | 26.08 | 7.78 |
| 20 级妙蛙种子 / 小拳石 | 1.74 | 1.08 |
| 50 级喷火龙 / 水箭龟 | 15.04 | 5.31 |
| 50 级皮卡丘 / 卡比兽 | 3.44 | 3.08 |
| 50 级胡地 / 怪力 | 5.50 | 2.23 |
| 80 级快龙 / 快龙 | 9.97 | 2.84 |

这组样本平均从 10.6 降至 4.5 次行动，减少约 57%；打到 40 次上限仍未分胜负的场次从 25 降至 0。强属性克制和高等级强招可以迅速结束战斗；这是此样本的结果，不代表所有对局都在同样长度内完成。
