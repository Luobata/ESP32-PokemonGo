## 设计要点

### 「今日行程」为什么不标步数

设备**没有 IMU 也没有 GPS**，给不出步数或公里。标了就是承诺做不到的事。

用抽象刻度（进度条），填充源在猎场与基地不同（见 [S1](../systems/S1-encounter.md)）：
移动中靠 `transient_aps` 快涨，驻留时靠时间排程慢涨但永不断流。
玩家能感到「出门更快」，而不需要一个假的数字。

### 三个键为什么这样分

A 照料 / B 图鉴 / C 遭遇 —— **按使用频率排**，不是按重要性。
照料每天要做三次（[S4](../systems/S4-nurture.md) 的衰减率决定），
所以给最顺手的 A。

C 键在有待处理遭遇时显示角标数字并闪烁。角标是 P1 唯一的动态元素
（除了呼吸动效）—— 它承担「掏出设备看一眼」的全部信息量。

### 渲染预算

back sprite 32×32 @scale3 = 96px 居中，呼吸动效只重绘这 96×96 = **18KB**。
状态栏与三条轴是静态的，不参与逐帧重绘。
