# P9 初始伙伴

新游戏看完或跳过 P0 后进入 P9，选择妙蛙种子、小火龙、杰尼龟或皮卡丘。A 确认，B 下一个，C 上一个；B/C 循环切换，C 不再跳过选宠。保存成功后进入 P1，初始等级为 1。

页面使用 `game_ui` 的白底、原版黑色边框和公共页脚。候选正面图保留完整 Crystal 点阵并整数放大 2 倍，按可见轮廓居中；名字、说明与按键提示按字形墨迹居中。

`world_choose_starter` 先写入完整的队伍、图鉴、开场标记快照，再发布主宠。保存失败停留原页，A 重试，B/C 可更换候选；存储不可用时保留原数据并提示重启。已有合法 V5 队伍继续使用原主宠、经验、图鉴和进度，不重新领取。未选择伙伴时，导航会阻止直接进入 P1–P6。

固件同源预览的 P0/P9「载入场景」使用未选伙伴的新游戏测试状态；其它场景使用已有主宠。预览中的存储是测试服务，真实 `world.c/save.c` 的故障与重启覆盖由 `tools/pipeline/verify_starter.py --sanitize` 验证。
