# P11 主菜单

待机 B 打开金银式右侧菜单，保留 A 照料、C 遭遇快捷入口。六项依次为图鉴、队伍、道具、照料、选项、关闭。

| 输入 | 主菜单 | 选项 |
|---|---|---|
| A | 打开所选页面 | 切换译名、立即熄屏或确认返回 |
| B | 下一项 | 下一项 |
| 长 B | 上一项 | 上一项 |
| C | 回待机 | 回主菜单 |

子页返回后保留所选菜单项。选项依次提供“译名”“立即熄屏”“返回菜单”，B/长 B 在三项中正反循环。

译名提供官方/金银民间怀旧两种显示，沿用所有页面共享的名字出口，不改变物种 ID、战斗属性或存档。硬件运行期切换，冷启动仍默认官方；网页保存自己的预览偏好。菜单没有声音或调试控制。

“立即熄屏”按 A 调用统一屏幕空闲服务，保留当前页面和光标；详情提示“60秒无操作自动熄屏”“任意键亮屏”。该提示的秒数来自 `screen_idle_timeout_ms()`，与实际自动熄屏阈值共用来源。熄屏后的第一次按键只亮屏，下一次才执行页面操作，避免按 A 唤醒时立即再次熄屏。选项框 `(8,56,224,120)` 内三行分别位于 y80、112、144，保持原品像素边框。

画面使用白底、黑字、原品 frame-1 与 cursor。右侧菜单框 `(120,40,112,192)`；行 y56 起、间距 28。左侧完整正面图 1x，按可见轮廓居中于 `(8,88,104,96)`。名字、等级、队伍数量和捕获数量独立显示，底部说明选项用途。

实现：`firmware/main/play_menu.c`。返回链由 `nav_open` / `nav_back` 保存，直达预览与正常菜单入口使用同一页面代码。验证见 [菜单/队伍验收](../../reports/menu-party-ui-2026-09-08.md)。

长按 C（1.5 秒）在任意页面熄屏，短按仍执行页面原本的返回/逃跑操作。唤醒手势整组吞掉，长按 C 唤醒不会立即再次熄屏。

## 运行时静音（2026-09-08）

选项现在按「译名、立即熄屏、静音、返回菜单」排列。静音行按 A 切换，右侧显示开/关；B 下一项、长 B 上一项。静音默认开，硬件保存到独立 NVS 键并在重启后恢复；保存失败保留原值并提示重试。

## 2026-09-08 更新

主菜单新增「成就」：图鉴、队伍、道具、照料、挑战、选项、成就、关闭。
选项新增「音量」，进入后 A 加大 / B 减小 / C 完成，范围 0–100%，每次 5%；与静音独立，重启保留。
