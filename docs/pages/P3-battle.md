# P3 遭遇详情 / 战斗

> 基础文案表来自 [`sim/strings.py`](../../sim/strings.py) 与 [`gen_pages.py`](../../tools/pipeline/gen_pages.py)。
> 下方阶段、输入锁和遭遇生命周期按实际 [`play_battle.c`](../../firmware/main/play_battle.c) 维护。

**进入路径**：P2 按 A

**涉及系统**：S3 自动战斗、S8 闪光

## 三键

| 键 | 动作 |
|---|---|
| **A** | 捕获 |
| **B** | 开始连续自动战斗 |
| **C** | 未分胜负时尝试逃跑；结果页返回列表 |

选择阶段底部提示行：`[A]捕获 [B]战斗 [C]逃跑`。

## 文案

- `eff`：
  - `200` → 「效果绝佳」
  - `100` → _（不显示）_
  - `50` → 「效果不好」
  - `0` → 「没有效果」
- `result`：
  - `win` → 「胜」
  - `lose` → 「败」
- `labels` —— 「回合」、「经验」
- `fled` —— 「跑掉了」（48px）
- `weakened` —— 「看起来虚弱了」（96px）
- `phase_hint`：
  - `playing` → 「战斗进行中」
  - `counter` → 「野生宝可梦正在反击」
  - `won` → 「[A]最后投球 [C]返回」
  - `lost` → 「[A]照料 [C]返回」

## 自动战斗与捕获

AI 从物种已学会的伤害招式中选招，属性相克、命中与逐次扣血保持原有规则。
选择阶段为 A 捕获、B 战斗、C 逃跑。只有明确按 B 才开始连续自动战斗。
连续战斗期间 A/B 不改动作，C 可预约逃跑，当前招式播完后判定；
出场、强制反击和经验结算动画期间不接受逃跑或长按离开。

直接捕获失败会回到本场，由野怪反击一次；主宠未战败时，反击结束后重新显示 A/B/C 选择，
不会自动接着打完整场。反击动画结束前不接受新操作。反击可能落空或因属性免疫无效，
但仍会完整执行这一攻击过程。双方 HP、行动顺序和随机状态沿用同一会话。
若反击使主宠 HP 归零，结算失败，不能重新进入捕获或重建满血战斗。

逃跑按双方有效速度与本场重试次数判定，主宠速度不低于野怪时必定成功；慢速主宠每次失败后提高下一次成功率。
成功显示结果后结束活动遭遇、返回列表。失败只触发一次野怪行动；
原先处于选择阶段的恢复 A/B/C，原先由 B 开启的连续战斗继续自动进行。
失败反击也可能命中、落空或免疫，均不能靠按键跳过。

未获胜的终局扣体能 20、心情 15，各轴最低到 0，不扣经验，也不删除伙伴。
结算和经验动画完成后 A 进入照料、C 返回列表；同一场的扣减只执行一次。
任一养成轴低于 25 时，新战斗的主宠攻击/特殊攻击使用 Q10 系数 614；照料恢复后使用 1024。

战胜后保留一次实际投球机会。P4 未投球取消回到 P3 不消耗机会；投球失败后野怪逃跑，
成功则收容并登记图鉴。若从 P3 返回列表，这次遭遇及未使用的机会一并结束。同一遭遇的经验只结算一次。

## 遭遇生命周期

待处理列表最多 5 条，满后无条件顶掉第一条，新遭遇加入末尾。尚未投球、选择战斗或尝试逃跑时，
目标仍属待处理，也可能被后台 FIFO 刷新淘汰。P3 的 C 现在执行逃跑判定，不直接退回并保留目标。

首次投球、按 B 战斗或 C 逃跑先持久化移除待处理记录，再把同一 UID 与时间戳的目标放入独立活动槽。
保存失败不扣球、不开始攻击、不提交逃跑随机结果，可重试。活动目标不占 5 条名额，也不会被后台刷新淘汰。
P3/P4 之间切换保留会话；离开这两个页面的流程就清理活动目标，不能再回到遭遇列表继续打。
活动目标与完整 HP/RNG 仅保留在本次运行；重启也不会恢复已经移除的待处理记录。

## 渲染

每次攻击先提交一份会话状态，再播放招式动画；帧率只影响播放速度。
动作影响的三条舞台横带同步重画，换回合时重画底部消息带。
100% 属性倍率不额外显示效果提示。完整规则与验证见 [S3](../systems/S3-battle.md)。
