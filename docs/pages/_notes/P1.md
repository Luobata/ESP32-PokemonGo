## 设计要点

### 探索补给

设备**没有 IMU 也没有 GPS**，给不出步数或公里。标了就是承诺做不到的事。

进度条对应下一次探索机会，旁边显示当前次数 / 24。走动攒满一格
获得一次机会，余量进入下一格，并显示三秒「探索次数+N」。
次数存满时提示先去探索，最多保留四格暂存进度；腾出空位后，
下一次有效扫描自动补入。原有每四小时驻留补给继续独立运行。
详见 [S33 探索补给](../systems/S33-exploration-supply.md)。

### 三个键为什么这样分

A 照料 / B 菜单 / C 遭遇。图鉴、探索、道具和队伍都从菜单进入。
照料每天要做三次（[S4](../systems/S4-nurture.md) 的衰减率决定），
所以给最顺手的 A。

C 键在有待处理遭遇时显示角标数字并闪烁。角标是 P1 唯一的动态元素
（除了呼吸动效）—— 它承担「掏出设备看一眼」的全部信息量。

### 渲染预算

back sprite 32×32 @scale3 = 96px 居中，呼吸动效只重绘这 96×96 = **18KB**。
状态栏与三条轴是静态的，不参与逐帧重绘。
