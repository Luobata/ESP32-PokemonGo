## 设计要点

### 不做联网排行榜

单机无对手。这里的「排行」是与自己的历史比 ——
Tamagotchi 从来没有排行榜，靠的就是「我养了多久」。

这不是妥协：联网排行榜需要账号、需要服务端、需要玩家基数，
而这台设备是一个人的。

### 纪录只在日切时更新

不实时比对（[S10](../systems/S10-records.md)）。实时不会更准，只会多写 flash。

### 已知问题：首周会刷屏

纪录从 0 起，**第一天必然打破 5 项**，之后连续照料/出门每天都在破。
P1 顶部提示在首周会变成噪音。

需要实测遭遇频率才能定「多大的提升才值得提示」的阈值，
留到 Phase 0 之后。可能的方向：首日不提示、或只提示提升幅度超过某个比例的。
