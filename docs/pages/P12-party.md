# P12 随行队伍

P11 选择“队伍”进入，六个位置一次显示。已有伙伴显示完整姓名、等级、亲密度和 32px 正面缩略图；队首标记“出战”，空位置标记“空位”。在列表长按 A 打开仓库，为当前选中的位置换入伙伴。

| 输入 | 六人列表 | 伙伴详情 |
|---|---|---|
| A | 查看所选伙伴 | 保存后设为队首 |
| 长 A | 打开仓库换入 | 查看技能 |
| B | 下一位 | 队首进入道具；其他成员提示先设为出战 |
| 长 B | 上一位 | 无动作 |
| C | 回来源菜单 | 回列表 |

详情使用完整正面原图 2x，显示亲密、探索、EXP 和闪光标记。首位负责跟随和出战；普通/闪光配色来自该成员自身标记。详情没有把持久化 `mon.hp` 当作战斗实时 HP。保存失败保持当前队首和列表顺序，并提示重试；有未结束的活跃遭遇时不能换首位。

所有成员数据来自 `world_party_snapshot()` 值快照。确认时把完整显示成员传入 `world_set_leader(index, expected, out)`，避免陈旧索引选中另一个同种个体。亲密/探索/EXP 随成员移动，饱食/心情/体能仍是共享养成状态，详见 [S14 队伍](../systems/S14-party.md)。

列表 y36 起、行高 36；正面缩略图 x24、姓名 x64、等级右缘 228。详情正面图可见轮廓居中于 `(64,64,112,112)`。所有缩略图使用完整源画布做最近邻采样后居中，保持原画布比例并避免格子边界裁切。每 500ms 更新快照，退出时停止页面定时器。

实现：`firmware/main/play_party.c`。验证见 [菜单/队伍验收](../../reports/menu-party-ui-2026-09-08.md)。

2026-09-08：只有光标选中的成员播放原版 Crystal 正面动作，并以 ±1px 水平摆动；移动光标重启动作，其余成员静止。详情页也复用选中成员动作。80ms 定时采样，动作结束后休息两秒循环。页面退出释放计时器，熄屏停止装饰动画采样；这些动作不标记屏幕繁忙，不阻止 60 秒自动熄屏。

仓库中 B 下一只、长按 B 上一只，A 确认交换，C 返回。交换保留两只伙伴的等级、经验、闪光、亲密和探索数据；保存失败不交换，战斗未结束时禁止交换。仓库每种宝可梦只有一个位置，若换出的物种已有另一只占位，会提示先换出，避免覆盖伙伴。
