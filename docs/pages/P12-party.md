# P12 随行队伍与仓库

菜单选择「队伍」进入，六个队伍位置一次显示。A/B 上下选择，C 查看详情，长按 B 返回。详情可选择出战、道具、技能或换入；选择「换入」打开仓库，再查看所选仓库伙伴的详情并确认换入。

队伍和仓库详情使用正面图，显示等级、亲密、探索、经验和闪光标记。选中的伙伴播放正面动作，熄屏停止装饰动画采样。仓库列表每屏显示五只，闪光伙伴带星标；容量为 151 个仓库位置，另有 6 个队伍位置。

## 仓库筛选与排序

列表长按 A 打开「仓库选项」，所有选项仍用 A/B 选择、C 确认、长按 B 返回。

- 范围：全部、闪光、可进化。
- 属性：不限，或一种金银属性；双属性伙伴任一属性匹配即可，可与范围筛选叠加。
- 排序：图鉴编号从小到大，或等级从高到低；同等级按编号排序，同种同级保留原位置顺序。
- 快速翻页：进入后 A 上一屏、B 下一屏，首尾循环；C 或长按 B 恢复逐只选择，再按 C 才打开详情。
- 清除筛选：恢复全部、属性不限，保留排序方式。
- 返回仓库。

不显示页码。列表上方显示当前筛选和排序，空结果仍能长按 A 调整。可进化指已经达到自然进化等级，或已有适用的进化石／机器；仅检查资格，不消耗道具，仍需换入队首后进入照料或道具完成进化。筛选和排序在本次运行中保留，不增加存档字段。

筛选与排序只生成展示位置索引，不重排仓库的真实位置，不修改伙伴数据。变更显示方式时尽可能保持原来选中的个体；该个体不匹配新条件时选中第一只结果。详情和交换都使用实际个体快照，保留等级、经验、闪光、亲密和探索数值；保存失败时可重试。

## 秘境中的换入

未结束的秘境会锁定队伍。仓库换入时可在二次确认页选择「取消」或「结束并换入」；默认取消，长按 B 也取消。确认后先处理待保存的秘境奖励、结束本局，再完成原换入动作。已得经验和道具保留，入场体能不退还；任一保存失败都能重试。普通未结束对战仍禁止交换。
