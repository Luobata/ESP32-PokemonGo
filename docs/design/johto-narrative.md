# 城都叙事改造：从博士来信到传说调查

状态：2026-10-24，已实施开发版。下文保留最初设计背景与目标；实际交付以 [实现与验证记录](../../reports/johto-narrative-2026-10-24.md) 为准。已接入 25 段对话、博士/馆主与场景演出、两处推理、三兽追踪选择、直接活动入口、暂停回看和 V31 存档迁移。网页使用生产 C 绘制；本轮未烧录或发布。它补充 [城都玩法方案](johto-activities.md)。

实际边界：开篇以 C 确认推进，长按 B 可暂缓，未另加一套“启程/稍后”按钮；捕虫结算说明采用固定观察线索，不引用随机捕获虫种。三兽分支已追加下述伙伴协作现场，净水试炼沿用原交互；不新增门卫战或重复付费玩法。空木终战已支持“六节点捕虫证据 + 首组遗迹 + 一次救助”的新路径，原先达标的旧档保留资格。

## 补充：伙伴协作调查（2026-10-24）

关键传说调查从普通探索中独立出来。三兽 8 个现场（另保留水君净水试炼）、银羽 3 个、虹光 3 个和时空森林 3 个，共 17 个现场。它们使用已有剧情线索步数，不扩展存档布局。旧版已完成的步数和定位资格保留，只对尚未完成的步骤应用新玩法。

流程：读环境线索 → 推断三个分支中的调查地点 → 从当前六人队伍选择协助者 → 成功演出与调查记录 → 下一站。现场提供免费提示和队伍入口；提示说明能力类别与可寻找伙伴的路线。按物种的主/副属性判断，不限定一只宝可梦、等级、稀有度或某个技能，也不受自动出招开关影响。

| 线索类别 | 伙伴能力 | 调查变化 |
| --- | --- | --- |
| 雷击、电光、深海光点 | 电 | 回应残留电光，辨认方向 |
| 泥土震动、岩壁回声 | 地面；岩壁也接受岩石 | 确认脚印延伸的方向 |
| 灰烬、暖风、火焰刻纹 | 火 | 唤起余温或照亮壁画 |
| 逆流、浅滩与风浪 | 水；泉眼接受草，风浪接受飞行 | 找到水源与海渊入口 |
| 暗影、迟到的树影 | 超能或幽灵 | 识别异常回声与时间变化 |
| 塔顶虹光 | 飞行 | 沿风接近高处线索 |
| 年轮与重叠嫩芽 | 草 | 让森林回应 |

猜错地点、伙伴不合适、取消、查看提示和管理队伍都不扣资源。只有正确准备后的出发才消耗原有 5 点体能，并在同一事务内推进证据、研究次数和孵蛋；不另生成随机遭遇，也不要求为主线刷随机掉落。保存失败不推进、不收费，可原地重试。重复点击已经完成的现场不会再次推进或收费。

普通探索继续提供野生伙伴、补给、普通追踪目标、研究奖励进度与孵蛋步数，但不再累加传说证据。路线页出现当前调查卡片；从“继续调查”直达线索现场，完成后回调查册。初次若叶调查、捕虫、遗迹解谜、救助、湖区与远征继续使用原有交互，伙伴协作条件不强加到每一次普通探索。

这是本作的原创环境解谜，并非金银原作的秘传技能门槛。表现沿用生产 C 渲染与已有伙伴素材，动作使用真实经过时间并在熄屏时暂停。测试与实际交付范围见 [本轮记录](../../reports/johto-fieldwork-2026-10-24.md)。

问题不是缺少玩法入口，而是缺少可感知的前因后果。此次不增加每日任务、剧情币或一组新的刷次数要求。故事应当解释已有活动，并让玩家的选择产生可见结果。

## 2. 故事主轴：伙伴为何离开原来的栖息地

大木收到空木来信：城都出现了异常迁徙，森林中的虫类、遗迹里的未知图腾和海上的潮汐似乎都有变化。空木需要有旅行经验的训练家帮忙记录，玩家带自己的队伍进入城都。

前半程调查日常生态，逐渐发现遗迹记录着传说伙伴活动的规律。烧焦塔事件将这条线引向三兽；中段愤怒之湖的人工干扰是一条需要玩家排除的线索，不把所有异常都归为一个反派。停止电波后，远海的呼唤依然存在，才进入双塔与海渊调查。

空木负责连接证据；阿笔、松叶、阿蜜各自解释本地现象。大木只负责开篇引荐及关都回访，避免每个地点都由同一人远程讲解。终章空木的挑战检验一路学到的配队与判断；胜利后留下一段尚未解释的森林回声，引出时拉比。

这是借用金银水晶人物、场景与意象的本作原创事件链，不声称复刻原作完整剧情。

## 3. 章节与玩家参与

以下是建议的剧情顺序，不把普通路线和已开放活动全部改成强制线性关卡。玩家可自由练级、收集和暂时去关都；笔记负责提醒下一步。

| 章节 | 人物与现场 | 玩家实际做什么 | 完成后的变化 |
| --- | --- | --- | --- |
| 序章：远方来信 | 大木转交邀请；短暂旅途镜头；空木在研究所接待 | 选择现在启程或稍后；选择城都初始伙伴，完成一次若叶调查 | 得到明确的第一条调查记录，提示挑战阿速；以后进入城都立即显示当前目标 |
| 林地异闻 | 首徽章后空木交付神秘蛋；两徽章后阿笔邀请参加捕虫调查 | 在已有六节点活动中观察草丛、树干、花丛，自己决定保留哪只；不要求夺冠或抓到稀有虫 | 结算时阿笔指出不同虫群都避开同一条小径，并提供遗迹符号的观察记录 |
| 遗迹回声 | 三徽章后研究员对照林地记录与墙面；未知图腾逐一出现 | 完成第一组短谜题，选择对应的遗迹方向；观察一次未知图腾出现，不强制捕获 | 墙面显出塔与三道身影；四徽章的松叶对话解释调查风险，引导去烧焦塔 |
| 三道踪迹 | 松叶带领调查烧焦塔；三兽离去，留下不同迹象 | 玩家自己选先追雷鸣、焦痕还是清澈水流；雷公追踪方向、炎帝绕行、净水试炼采用不同的现场交互 | 每条线都有中途相遇、最后定位及直接进入遭遇；调查记录显示已发生的故事和下一地点 |
| 湖上的红影 | 五徽章后空木收到求助，玩家来到愤怒之湖 | 沿用设施守卫战、关闭电波、安抚暴鲤龙的实际流程 | 固定红色暴鲤龙成为伙伴；电波已停止而海上异象仍在，阿蜜给出漩涡列岛调查方向 |
| 海渊与塔顶 | 六徽章后阿蜜协助海上调查；八徽章后三兽记录回应塔顶的壁画 | 带自己的三只伙伴完成漩涡远征，选择带回或深入，取得银色之羽；凭三兽研究前往铃铛塔 | 洛奇亚和凤王以现场出现、叫声和正式遭遇收尾；首次调查与后续重复追踪分开 |
| 最后一项研究 | 空木回顾玩家救助、观察和战斗的记录，提出最终考验 | 满足关都与城都条件后挑战已有空木阵容；战中台词呼应真实经历 | 研究纪念奖励、旅程回顾；桧皮林地出现新的回声，开启时拉比后日谈 |

### 捕虫与遗迹怎样真正联动

第一次剧情捕虫调查在固定观察节点提供林地异象，不靠抽到某个物种、金奖或闪光才能推进。比赛评分继续影响原有物资，故事证据与名次无关。

比赛中保留三种栖息地选择，阿笔在结算时引用玩家实际记录的一种虫类。已有有效完成记录的旧档允许直接领取这段说明，不要求重赛。若采用“完成六节点即可取得故事线索”，须新增独立事件完成凭据；不能直接把当前要求六节点且观察至少三种的 `bug_completed` 当作新规则已实现。

遗迹第一组解谜只要求读懂一段记录，不要求集齐 26 个字母。剩下三组遗迹与字母收藏作为进一步研究，给专属回顾、现有成就或定向奖励。不要在打开三兽调查前要求反复抓满一套未知图腾。

### 战斗放在有原因的位置

- 松叶馆战已有属性与增益规则，将战前、战后对话接到烧焦塔调查资格；不在打赢道馆之后再追加一场几乎相同的门卫战。
- 愤怒之湖保留已有两场不同目的的战斗：击败设施守卫、让暴鲤龙恢复平静；结算后直接回到现场剧情。
- 漩涡列岛沿用当前远征战斗、营地与中继选择，深层事件解释银色之羽的来源，不再凭空多收费开一轮相同副本。
- 传说第一次现身走独立的揭示镜头，随后允许战斗、捕获或暂缓；剧情以完成调查/相遇为条件，不以一次捕获成功为硬门槛。
- 空木继续作为本篇最终对手，保留自动判断赤红进度的等级与增益档位。剧情镜头不改双方 HP、自动选招及战斗节奏。

### 可选支线与终章门槛

神秘蛋随调查一起成长，孵化时空木有回访对话，但不要求先孵化才能调查三兽。伙伴救助可作为空木委托，首次救助给前期的实际帮助与角色联系；另外一只御三家、幼年伙伴及重复救助仍自由收集。

建议终章以主线调查里程碑为条件：城都八徽章、已有的关都八徽章及赤红记录、捕虫观察、首组遗迹、一次救助、三兽调查、双塔/海渊研究。26 字母、全部遗迹、第二次救助、全部传说捕获和闪光收集保留为额外目标。

这会调整当前“必须两次救助、四组遗迹”的门槛，属于待实施的规则改动；不能只改页面文案，仍用旧条件阻挡玩家。已解锁终战的玩家始终保留资格，不能因新增捕虫前置被锁回去。尚未战胜赤红的玩家在笔记中明确看到返回关都的目标，不以空木一句“条件不足”结束。

## 4. 一段实际的开场脚本

单页使用现有 240×320 金银风格：上半屏人物或场景，下半屏最多四行中文对话。以下示例每行不超过 12 个汉字，最终仍以生产字体测宽与截图验收。

**大木博士 · 转交邀请**

> 空木博士寄来了一封信。
> 城都的伙伴们，
> 正往同一个方向迁徙。

**大木博士 · 交代缘由**

> 他想请有经验的训练家，
> 帮忙找到迁徙的原因。
> 你愿意去看看吗？

选择：`前往城都` / `稍后出发`。确认启程后持久化，再播放短旅途镜头；中断后可以从抵达研究所继续。

**空木博士 · 抵达**

> 你终于来了！
> 不只是森林里的伙伴，
> 遗迹也传来了奇怪声音。

**空木博士 · 初始伙伴**

> 先选一位同行的伙伴吧。
> 它会带你熟悉这片土地。
> 第一站是若叶郊野。

转入现有城都御三家选择。成功保存伙伴后，展示简短出场动作，再给第一条目标；仓库满或保存失败不假装已经领到伙伴。

**捕虫调查结算 · 阿笔**

> 它们没有往花多的地方去。
> 虫群都绕开了那条小径。
> 你看，树上还有这种符号。

画面展示符号；下一屏研究员把符号与遗迹墙面对照，给出 `前往缘朱遗迹` / `稍后调查`。若尚未三徽章，显示阿笔的后续建议与下一馆，不提供会失败的传送入口。

## 5. 交互怎样避免变成另一张任务清单

城都首页保留自由入口，顶部增加一张“当前调查”卡片，只有三件事：发生了什么、去哪儿、做什么。例如：

```text
当前调查：虫群为何绕路
阿笔发现小径上的符号。
下一站：缘朱遗迹
目标：观察第一面石壁

继续调查    自由探索
```

“继续调查”直接到对应现场/活动准备页，仍须明确确认付费或开战；不要求从城都 → 活动 → 笔记 → 子菜单多次查找。来自剧情的对战和捕获结束后回同一现场，再由人物给下一步。

第一次触发显示 2～4 页短对话与一个关键动作；后续进入不重放开场、不阻塞正常按键。C 完成当前文字/翻页，A/B 只在有选项时上下选择，长按 B 暂停剧情并返回。读过的场景可在笔记回看，回看不发奖、不扣体能、不重新生成遭遇。

不规定强制阅读总时长。场景淡入淡出以 250～400 ms 为调参起点，玩家确认后再继续，不把长黑屏当成剧情。背景音乐在场景边界切换，不每句话重开一次；首次神兽揭示有短音效、叫声和现有出场动作。

主线提示只在菜单、路线结算及活动结算等安全节点展示。战斗、捕获、进化、导入和待领取伙伴处理中不插播。自由探索、跨区旅行、关机不会丢掉已接任务；正在进行的活动优先显示“继续当前活动”，避免跳到另一个任务后只能收到忙碌提示。

所有线索记入调查册，不新增背包物品、兑换货币或第二条体力。对话、看记录、解谜、回访免费；普通探索和活动沿用现有收费。首次剧情借用正常行动推进，不要求完成后为看下一句再付同一笔入场费用。

## 6. 旧档接入与事件持久化

| 玩家已有进度 | 新版接入行为 |
| --- | --- |
| 关都不足四徽章 | 仍在第四枚徽章后收到邀请；不在当前剧情中提前泄露神兽名单 |
| 关都四徽章以上、尚未去城都 | 正常播放来信与抵达；不重打旧道馆 |
| 城都已领伙伴/已打部分道馆 | 空木给简短回顾，选择继续调查或回看开场；不重复发初始伙伴 |
| 已完成捕虫、救助、遗迹、海渊 | 按保存记录认可对应的实际成果，补人物解释；不要求重刷，也不凭未验证信息发奖励 |
| 已定位传说或已满足空木条件 | 保留既有访问权限；新增故事可回看，不反向锁住内容 |
| 已击败空木 | 从研究回访/后日谈继续，旧首胜奖励和成就领取状态保持 |

“活动完成”“剧情已读”“一次性奖励已领”分别记录，不能用一个位互相代替。不得因为旧档有一只传说或闪光，就判定所有相关新故事已完成；也不能因为玩家跳过对话就删除已完成的调查。

新增持久记录预计需要下一个明确的世界存档版本（当前为 V30，实施时核对实际最新版本）。保存事件完成位、已读位、活动中断点、旧权限保留状态，以及确实新增的奖励凭据。台词不存入存档；徽章和已有计数不复制一份。旧 V5～V30 布局和固定样本保持原字节，不借 `reserved` 或填充字节存新含义。

调查完成、体能、锁定的遭遇/伙伴、奖励和事件阶段在同一事务中提交。演出从事务完成之后开始；保存失败不标记任务完成，重启不重抽奖励、不重复发初始伙伴或红色暴鲤龙。待领取伙伴和当前剧情对应的遭遇必须有稳定身份与恢复入口，不能被五格普通遭遇队列顶掉后形成永久任务死路。

完整叙事改造涉及新事件状态，不能以“都是 UI”跳过存档、满仓和断电测试。在线/离线导入工具是否需要变化取决于最终容器和真实支持版本，不能预先承诺只刷新网页即可。

## 7. 资源、实现顺序与验收

资源方案以静态脚本表、现有人物/伙伴素材和少量地图图块为主，不引入大地图移动引擎、整段视频或新的全屏缓冲。现有大木开场可提供对话框和素材参考；城都 NPC 需单独核对可用立绘，不能把现有行走小人说成已经有完整战斗立绘。

当前已验证应用为 3,162,896 字节，应用分区 3,407,872 字节，余量 244,976 字节。此为本轮设计前的构建基线，不能当作实现后的容量保证。脚本文字、中文字体增量、人物素材与声音均需重新编译测量，分区不因剧情扩容而移动。参考 [舒缓节奏构建记录](../../reports/comfort-motion-2026-10-24.md)。

所有新有限动画按真实经过时间采样，使用现有场景时钟，熄屏暂停；继续保持已选择的 75% 战斗动作速度，不借降低刷新率延长演出。采用可见区域裁剪和局部刷新，保持 20 行条带、16 KiB LVGL 堆及原 RTC 编解码预算。

| 实施批次 | 可实际体验的闭环 | 主要验收 |
| --- | --- | --- |
| 一：开场与第一条调查 | 来信 → 抵达 → 伙伴选择 → 当前目标 → 捕虫现场 → 阿笔解读 → 遗迹第一幕 | 新档/已有城都档不同入口；按钮可暂停；已读不反复弹；活动回到剧情；没有随机稀有掉落门槛 |
| 二：中段冒险 | 遗迹 → 松叶 → 烧焦塔 → 三兽分线；愤怒之湖接入主线提示 | 分支可自由选；免费交互不扣体能；已有调查认可；战败/捕获失败可续；故事不依赖抓齐三兽 |
| 三：传说与结局 | 海渊/塔顶现场揭示 → 空木回访与终战 → 森林后日谈 | 神兽与奖励稳定身份；不被普通队列顶掉；旧权限保留；首次/重复流程分离；已有终章档可接续 |

每批都应有真实共享 C 渲染的后台场景：逐页查看台词、从任一保存阶段进入、成功/失败/暂缓后续、检查局部与全帧一致。不能仅做一个独立网页故事样机后声称设备已具备同样流程。

固件交付前执行 AGENTS.md 存档及性能全套检查，补充故事状态转移、旧档投影、原有权限、满仓/奖励满额、失败重试及重启恢复用例。真机覆盖对话切页、音乐切换、剧情 → 战斗 → 剧情 → 捕获完整过程；保档烧录、USB 导出/有设置变化的恢复、运行时堆和栈余量分别验收。当前另有一次 USB 导出缺块的待定位记录，不将该风险随新剧情发布一并默认为已解决。

## 8. 调查提示与攻略边界（2026-10-24）

17 处伙伴协作调查采用“环境观察 → 能力联想 → 选择路线与同行伙伴”。游戏里的免费提示、选错伙伴的反馈都不直接点名宝可梦，也不列获取地点；例如电光现场提示“能储存电的伙伴可以回应”，保留玩家自行推理的空间。所需属性、可用伙伴示例及具体分支放在官网 `guide/#fieldwork`，默认折叠，只有主动展开才显示答案。

任一匹配属性的现有队员都可以协助，双属性有效，不要求指定物种或招式。选错不扣资源，正确完成才扣 5 体能、推进既有线索。攻略由生产现场表与遇敌池导出，示例通过实际属性校验验证；当前标记为城都开发预览，随对应版本发布，不将未发布章节混入正式版说明。
