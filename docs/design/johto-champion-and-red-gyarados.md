# 城都冠军道馆与红色暴鲤龙剧情

2026-10-18：已实现并完成宿主、原生 UI、隔离真实 NVS 和 ESP32 构建检查；本轮未烧录、未发布。验证范围见 [验证记录](../../reports/johto-champion-2026-10-18.md)。下述机制为本作设计，不宣称是金银原版规则。

## 自动难度与旧进度

没有手动选档。开始城都挑战时读取关都赤红的通关记录：未击败赤红沿用普通城都等级与规则，击败后自动使用冠军阵容、等级与专属增益。等级固定，不继续跟随玩家队伍抬升。旧档已有八枚城都徽章仍保留，之后可重打八馆，取得独立冠军首胜记录；旧徽章不直接兑换冠军成就。

开始战斗后锁定实际阵容和规则；旧 V29 存档中正在进行的普通对战继续按原快照打完，即使已经拥有赤红记录，也不会中途增加增益或误记冠军首胜。新的冠军记录与奖励、剧情进度均可保存和导入恢复。

## 八馆机制与破解

| 机制 | 实际效果 | 破解方法 |
| --- | --- | --- |
| 暴风领域 | 速度 +50%；比对手快时飞行伤害 +70%，其他攻击 +40%；非克制攻击受到的伤害减免 55% | 麻痹或降速成功后压制风场，覆盖接下来三个完整回合；克制伤害可绕过风壁 |
| 虫巢协同 | 初始两层，每次虫系攻击实际命中再加一层，上限三层；每层伤害 +25%、承伤减免 20% | 火或飞行攻击实际命中拆两层；层数整队共享，换宠不能重置 |
| 应援阵容 | 每只第一次跌破半血且存活，恢复最大 HP 的 30%、物防 +1；前四只仍有存活者时，后两只伤害 +25% | 中毒或灼伤阻止恢复并消耗这次触发机会；也可用爆发直接击倒或特殊输出应对 |
| 双相幻幕 | 敌人按出场槽交替使用物理/特殊幕，对应类别减伤 70%，另一类别减伤 30%；未破幕时伤害 +40% | 另一类别实际命中即永久破幕，并覆盖接下来三个完整回合的承伤 +25% 窗口 |
| 蓄势重拳 | 首次出场两回合减伤 60%，未破除时普通攻势 +30%；蓄势完成后的第一发格斗攻击伤害翻倍，未命中也消耗 | 降攻、麻痹或睡眠成功解除该个体增益；幽灵免疫和抗格斗换宠同样有效；重新出场不刷新 |
| 钢铁阵列 | 物理减伤 70%、特殊减伤 40% | 两次火/水特殊攻击实际命中永久拆甲，接下来三个完整回合承伤 +25% |
| 寒潮推进 | 初始一层，每两个完整回合加一层，上限三层；每层使我方速度 -15%、敌方冰伤 +25%、其他伤害 +10%、非火承伤减免 15% | 火系实际命中拆两层，并暂停后续两个完整回合的叠层 |
| 龙阵接力 | 每只首次出场三回合内减伤 50%、伤害 +30% | 两名不同伙伴用不同属性实际命中立即破阵，后续两个完整回合承伤 +30%；仅剩一只时也可等待龙鳞自然结束 |

伤害加成统一接入实际伤害计算和 AI 评分；固定伤害、反伤保留原规则。实际命中必须造成 HP 或替身伤害；免疫、未命中、跳过行动不触发，多段攻击按一次招式事件处理。规则计数依战斗回合推进，不依动画帧推进。

自动选招会考虑破解收益，仍遵守玩家禁用的技能。馆主根据玩家已经使用的招式与公开 HP 情况有限换宠，每场最多两次，间隔至少三回合，消耗行动。不会读取尚未选择的玩家操作。局内增益、触发次数和冷却使用实际槽位持久化，换宠和重启不刷新。

增加 11 项成就：八馆冠军首胜、冠军八馆巡礼、空木传说试炼、红色羁绊。总数由 32 增至 43；领取凭据独立于旧成就位图，稀有奖励满堆时保留领取资格。重复挑战不重发成就奖励。

阶段切换有台词停顿。敌方主动换宠仅限当前两只，不提前跳到下一阶段。不会复活、不增加第七只、不重置 HP，也不超过 100 级。现有终章前置仍包含赤红、八枚城都徽章和调查条件；因此新玩家最终进入的是冠军等级。普通值只服务未满足赤红条件的兼容情况。已完成终章的旧进度不取消，时拉比剧情不重新锁住。

## 红色暴鲤龙：愤怒之湖

城都五枚徽章后，在「冒险笔记 → 愤怒之湖」出现固定支线；冰雪之径提示该入口。已有高进度的旧档同样可参加，已自然捕获闪光暴鲤龙也不排除。

1. 调查湖边传闻，初次出发消耗 10 点体能；此时按赤红记录自动锁定剧情等级为 65 或 85，后续不会重抽或中途升档。
2. 调查异常电波，挑战旧设施守卫，队伍等级为锁定等级减 5、减 3、减 1。
3. 根据提示关闭电源，解除干扰。错误选择可重试，不重复收费。
4. 挑战闪光红色暴鲤龙：狂怒减伤 50%、水系伤害 +30%；降攻、麻痹或睡眠可平息狂怒。首次低于半血时预告怒涛，下一回合起的首次水系攻击再加 50 个百分点。
5. 胜利后进入剧情投球，三次晃动、成功星光与捕获 BGM；固定成功，不扣背包球。确认接回与剧情完成在同一存档事务提交。
6. 获得同等级闪光暴鲤龙、五枚树果（满堆封顶），解锁「红色的羁绊」成就。

各阶段独立保存。失败可从当前阶段重试，守卫完成后不能重复刷其奖励；重试不再收取入场体能，但战败仍有现有养成代价。离开、重启不删除剧情伙伴，不占普通遭遇队列，也不改变探索连携。

753 格仓库满时，待领取个体持续保存；玩家可整理仓库或选择一个仓位，经二次确认替换。取消和保存失败保留原仓位与待领取状态，不能自动合并同种伙伴。领取后不可再次生成剧情个体。回忆战暂未开放。

## 验证与调参边界

已验证全部规则、旧档迁移、事务失败回滚、满仓领取、原生 UI 导航及渲染；详细数据在验证记录中。平衡脚本以九场战斗、七种配置、每种 60 个种子进行 3,780 次生产逻辑模拟，覆盖强力混合队、针对队顺序变化及技能筛选、有限药品、单核、等级 +5/+10。

这是探索性模拟，不代表真实玩家胜率，也不等于验证了每馆三套不同组成的针对队。现阶段前段强力属性覆盖队较容易、后段与空木明显更难。设计中曾提出的「混合队 20%～40%、针对队 60%～80%」不是已达成指标；仍需真机体验检验战斗时长与换宠节奏。

存档新增 V30 的 96 字节尾部，保留 V5～V29 解码迁移；世界记录 39,912 字节，使用既有 72 KiB 备份格式 4 和原双银行分区。不会挪动或擦除现有分区，不支持新档倒灌旧固件。运行时 Wi-Fi 后的堆余量及实际导入覆盖测试仍需本版真机验收。
