## 老玩家接入与城都八枚新徽章

篇章资格按持久化进度计算，不能只在“刚获得第四枚徽章”的回调里触发。旧档升级、旧备份导入、新玩家正常通关使用同一资格判断。满足条件后，在回到菜单等安全节点显示大木博士转交的邀请；进行中战斗、捕获、秘境和待领结算完成前不强制跳转。邀请可稍后处理，入口长期保留。

| 已有进度 | 进入新篇章的安排 |
| --- | --- |
| 关都不足四枚徽章 | 第四枚徽章后开放邀请 |
| 关都四至七枚徽章 | 更新后直接具有邀请资格，完成简短引导进入城都 |
| 关都八枚徽章 | 不重打关都道馆；保留全部进度，完成引导后挑战新的城都道馆 |
| 已战胜冠军或赤红 | 保留旧主线通关资格；新调查仍需体验，后期挑战不要求重打旧联盟 |

承认旧条件与完成新事件分别记录。不能因已有八枚关都徽章就赠送八枚城都徽章，也不能要求已通关玩家重新触发旧胜利事件。前一轮讨论中“按徽章逐步开放”在进入城都后指城都徽章；若某个事件还要求关都冠军资格，页面明确写出地区与条件。

拟定节奏：

| 城都进度 | 内容与正向反馈 |
| --- | --- |
| 收到邀请、抵达城都 | 简短新物种发现演出、选择城都初始伙伴、开放初始路线；未选两只可从后续研究获得 |
| 第一枚徽章 | 引出波克比神秘蛋委托；获得稳定补给和新探索方向 |
| 第二枚徽章 | 开放捕虫调查、首个主题试炼和跨世代进化道具来源 |
| 第四枚徽章 | 烧焦塔事件、三兽调查，开放一组新的探索分支 |
| 第六枚徽章 | 漩涡列岛深层、银色之羽调查与洛奇亚挑战；具体前置研究单独展示 |
| 第八枚徽章 | 虹色之羽/塔顶挑战的徽章资格、城都大师挑战；三兽调查等剧情条件仍需完成 |

第三、第五、第七枚同样各自解锁路线分支、主题挑战或进化道具研究，不做只有数字增长的徽章。八馆保留战前对话、馆主/伙伴出场、战后授徽章和道具演出；重复挑战给稳定补给，首次奖励只发一次。徽章册分“关都 8 枚 / 城都 8 枚”，总计 16 枚；旧关都活动继续只检查关都条件。

道馆等级与地区具有明确难度区间，不照搬原作开局低等级，也不让所有敌人始终等于当前主宠等级。高等级玩家可以用原队伍通过早期内容，后续以强化重赛和大师挑战提供压力；不强制压低玩家永久等级或要求重新培养一队。精确等级、队伍及消耗待模拟和真机体验后确定，沿用现有统一体力体系。

新八馆使用独立的版本化进度字段，不能将现有 `trainer.defeated` 的四天王、冠军、赤红位重新解释为城都徽章。新剧情步骤、首次奖励和待领结果分别持久化；新字段初始化为未体验/未领取，旧条件从历史记录推导。升级或导入不得凭空完成新剧情、重复发放旧奖励。

## 新最终对手：空木博士的最终考验

新篇章需要独立的结束演出与最终挑战。采用空木博士的全力六人队：邀请玩家调查城都的研究者，在旅程结束时亲自检验成果。这是本作原创支线设定，不声称空木博士是金银水晶原作的最终 Boss。角色、六人阵容和实际战斗已经接入；共用自动选招、换宠、对话及经验结算。当前空木使用原作行走小人作为展示图；专属战斗立绘、终战演出及选择奖励仍待完成。

### 伏笔与解锁

前期通过交付初始伙伴、神秘蛋委托和两三次研究回访建立联系；对话偶尔提及他也在与伙伴训练，终局挑战有前期铺垫。首次达到条件后收到“最后一项研究”的邀请，进入独立战前演出：

> “这次，轮到我和伙伴们向你请教了。”

拟定条件为关都八徽章、城都八徽章、已有赤红胜利记录，以及完成城都主线调查收尾。旧档中的赤红胜利直接计入，无需重打。主线收尾用明确的事件列表判断，不把模糊的“研究完成度”作为隐藏条件；不要求集齐 251 只、捕获全部传说或获得闪光。时拉比等可选长期调查不阻塞最终战。

### 战斗主题与候选阵容

定位为“运用城都伙伴成长成果的完整队伍”，首战固定阵容与等级范围，难度目标高于现有赤红；具体数值通过双方合法配队实测确定。玩家携带自己的六名伙伴，继续采用已有自动出招、技能开关与手动换宠。

| 伙伴 | 战术主题 |
| --- | --- |
| 大竺葵 | 防护与队伍支援，展示养成后的初始伙伴 |
| 火暴兽 | 火系压制，制造需要换宠应对的攻势 |
| 大力鳄 | 水系与覆盖招式，减少单一属性通关 |
| 太阳伊布 | 高速特殊攻击，与亲密进化主题呼应 |
| 巨钳螳螂 | 强化与物理进攻，体现跨世代进化 |
| 班基拉斯 | 最后的强力压轴，独立出场演出与音乐变化 |

这些是候选角色定位，实际选招必须通过已实现的第二世代招式、物理/特殊分类和 AI 验证。AI 能根据可见场面进行合理换宠和强化，但不能偷看玩家尚未作出的选择。挑战来自配队、攻防转换和招式协同，不通过隐藏倍增 HP、无限回复或额外作弊行动拖长战斗。首战不随机抽取克制玩家全队的阵容。

沿用正常六对六战斗；中段短对话和压轴出场只作演出，不重置双方 HP、不追加第七只。新旧伙伴都能参与，不强制限定只能使用城都宝可梦，也不压低玩家持久化等级。后续重赛可提供明确展示的主题变体；第一次胜利仍保留清晰且可学习的配置。

### 结局、奖励与记录

首胜播放双方队伍回顾、城都调查完成对话和结束画面，记录“城都研究大师”纪念章，另给一次进化道具选择奖励。纪念章属于成就，不是第十七枚道馆徽章。重复挑战继续给予合理经验、补给和挑战记录，不重复发首胜奖励。此前发现的新地图、传说追踪与蛋委托保持开放，结局后仍可继续收集。

最终战胜利、演出阶段和待领奖励用新版本字段记录，独立于赤红位。中断可恢复到正确结算阶段，关闭页面或重播结局不重复发奖。按旧档已过赤红但未做城都、城都接近收尾、战斗中断、首胜待领和已完成重赛覆盖迁移与存读档验收。

## 传说调查的独立获取过程

第一世代原有路径及已获个体保留。第二世代首次传说遭遇不进入普通高星随机池，完成专属调查后保证一次遭遇资格，捕获结果仍走本作捕获流程。以下借用原作意象，属于本作事件设计：

| 目标 | 获取过程 |
| --- | --- |
| 雷公、炎帝 | 烧焦塔事件后跨区域游走；雷鸣、焦痕提示方向，有效调查累积定位进度 |
| 水君 | 数次有演出的相遇逐步引向净水试炼，最后开放正式对战 |
| 洛奇亚 | 银色之羽调查串联漩涡列岛分层远征，到海渊深处挑战 |

## 进化要从单目标改为规则表

现有 `species_t` 只有一个 `evolve_to`，进化触发类型只覆盖等级/道具/交换；无法完整表达多分支、亲密度和昼夜条件。使用声明式进化列表，一个物种可对应多个条件和目标，界面展示具体要求与可选结果。原作确有亲密度、时段和攻防关系分支。[进化/学习规则表](https://github.com/pret/pokecrystal/blob/7a7881d0d62e0ddbd82dcf10e7116807487ac651/data/pokemon/evos_attacks.asm)

本作适配如下，属于设计选择，不冒充原作机制：

- 亲密进化接入当前每只伙伴保存的亲密度，照料和参战均可推进；满足后提示，暂缓不丢资格。
- 太阳/月亮伊布优先使用可信时钟的晨日/夜晚条件；未校时显示时间不可用，并提供研究解锁的明确进化方向替代，不能永远卡住离线玩家。
- 太阳之石、金属膜、王者之证、龙之鳞片、升级数据直接作为消耗式进化道具。图鉴指明来源，在相关地图研究或副本首通给稳定获得机会；无需装备或真实通信。
- 旧进化路径保留：例如蚊香君、呆呆兽、臭臭花、伊布存在不同结果，满足多个条件时先选择再确认，消耗道具与进化原子保存。
- 无畏小子的攻防分支不能照搬当前固定 DV、无能力培养的数值：它可能永远只走同一个结果。采用格斗训练事件选择培养方向，或有明确来源的进化训练选项；不是临时按当前强化状态随机决定。
- 用一张可达性表检查每条新进化边，包括前置伙伴、道具/亲密要求、开放章节与取消恢复。玩家不必查攻略猜为什么不能进化。

## 波克比专属剧情蛋

波克比只通过神秘蛋孵化获得，不加入野外随机池、图鉴直接追踪、秘境出口伙伴池或直接赠宠池。波克基古由波克比亲密进化获得，让孵化和现有照料系统形成联系。其他幼年伙伴通过探索、研究或救助事件获得；另外两只城都初始伙伴通过后续研究获得，均不依赖蛋。

首次委托为“收到神秘蛋 → 带着探索 → 裂纹与摇晃提示 → 孵化 → 回访研究员”。蛋使用独立剧情槽，同时最多一枚，不占战斗队伍或仓位。仅已成功保存、实际消耗探索体力的有效行动推进；打开菜单、取消、重复回调、读档及单纯等待不推进。没有额外孵化体力、配种、孵化器或每日喂养要求。照料页显示状态并允许查看，孵化不要求指定时间上线，关机保留进度。

首次孵化后可再次通过可重复的研究委托获得同种蛋，继续支持闪光和不同个体收集，不成为绝版单只。每枚蛋的个体与闪光结果在领取时一次确定并持久保存，重启或重播动画不能重抽；具体孵化步数、重复委托间隔与闪光率待调参，不能默认套用秘境概率。首次剧情奖励不随重复委托再次发放。

成熟后提供完整孵化演出；满仓库可保留待孵化状态，待整理空间或明确确认替换后再领取。蛋状态变更、新个体收纳、图鉴和奖励在同一事务提交。失败、取消、重启不能丢蛋或复制伙伴；即使最后一只波克比被放生，重复委托仍可用。

性别不用于首版配种，但招式若依赖性别就不能忽略这个维度。迷人等招式需要保存正确的性别/无性别状态及相应判定，或者明确延后开放该招式并保证学习表仍有可用招式；不能给它一个始终无效的占位实现。新增个体字段须版本化，旧伙伴采用稳定的迁移默认规则，重启不能重新随机。

## 战斗、自动选招和动画

当前招式集合为初代 165 招加选定的 26 招，共 191 招；最大调度 ID 为 250。原作招式编号还包括 251（围攻），因此既要检查数量上限，也要检查 ID 范围，不能只添加新物种记录。[原作招式编号](https://github.com/pret/pokecrystal/blob/7a7881d0d62e0ddbd82dcf10e7116807487ac651/constants/move_constants.asm)

优先补能改变配队的机制：雨天/晴天/沙暴、守住/看穿、撒菱/高速旋转、接棒、诅咒、预知未来、反射类招式、锁定与延迟结算。天气属于战斗场地，不能只在招式动画里画雨；对野生、训练家和秘境必须使用相同结算。沙暴等效果要核对该世代规则，不能默认套用后续世代效果。

按“数据 → 战斗效果 → AI 能理解 → 动画/音效 → 可验收场景”一起开放。对于减 PP 等与本作无 PP 规则冲突的招式，单列适配规则；没有实际意义的效果不能装作已经支持，自动 AI 也不能反复选择空效果。经典 TM/HM 招式继续通过等级/成长资格自动加入，不增加主动学习流程。

新增物种最少要覆盖三个特殊验收组：

| 伙伴 | 直接套现有系统的问题 | 需要增加 |
| --- | --- | --- |
| 未知图腾 | 主要依赖觉醒力量；当前不保存原作 DV，无法直接得到完整原作变化 | 明确并持久保存本作的觉醒属性规则、招式效果、原作 A～Z 形态；保留单物种图鉴口径 |
| 图图犬 | 不能仅按物种/等级重新算通用学习表 | 写生记录属于个体，按允许规则自动学习实际观察到的招式，持久保存去重集合，不重新引入四格遗忘 |
| 果然翁 | 反击型招式不适用普通“优先选高伤害”评分 | 根据已发生的战局与可见信息选择反击，不偷看下一招；镜像/免疫/回复循环有明确结束保障 |

这些学习表特例可在原始数据中核对；不能将它们当作“会挣扎就算可玩”。自动 AI 回归同时覆盖反击、连续保护、无限回复、免疫和双方没有直接攻击的局面。[特例学习表](https://github.com/pret/pokecrystal/blob/7a7881d0d62e0ddbd82dcf10e7116807487ac651/data/pokemon/evos_attacks.asm#L2569)

第一世代原有技能资格不能在更换到 Crystal 数据时被悄悄删除。新增物种以固定 Crystal 学习表为基准；旧 151 的已经开放资格保留并核查原有金银适配策略。所有实际开放技能均进入后台验收页，覆盖双方施放、命中/落空/免疫、HUD 叠加、原速和音效。

新进化道具会扩大库存。库存嵌在多代存档和奖励凭据中，不能直接增大 `ITEM_COUNT` 后让历史类型也跟着改变。先冻结历史库存类型，再为新格式定义长度/版本与默认值；迁移后原有道具数量及待领凭据保持。

仍执行根目录 `AGENTS.md` 全部发布检查；V5～V23 历史样本不变，本次追加 V24/V25 固定样本。新增 251 边界、152/251 物种、未知图腾形态、图图犬记录、满仓库、进行中秘境和新道具待领奖样本。在线/离线导入均复用设备真实解码与迁移；同设备、布局、CRC/SHA、覆盖前备份和 ACK 保护不能放宽。

接入专项覆盖旧档 0/4/8 徽章、冠军、赤红，以及曾触发邀请后又升级的存档；旧档直接导入新版与在设备上原位升级必须得到一致的新篇章资格。验收各阶段蛋、满仓孵化、城都徽章及剧情奖励的断电/重试。关都 151 收集成就只统计 1～151，城都 100 与全国 251 成就另行追加，不能扩大旧统计口径或重新发奖。

## 设备资源的实际约束

第二阶段实测构建约 2.86 MiB，3.25 MiB 的 factory 分区还剩约 400 KiB；分区表未改。先以无损图块去重回收约 393 KiB，再加入城都素材。V25 世界记录 22,400 字节，双银行的步幅仍为 32 KiB，记录预算从 20 KiB 扩为 28 KiB；不挪动已有银行。备份容器追加 v3，载荷 56 KiB（24 KiB NVS + 32 KiB 引用银行），v1/v2 仍可导入。以下旧版本数字作为比较基线；扩展版运行堆余量、Wi-Fi 后 USB 导入必须另外真机验收。

2026-10-12 已验证应用为 3,192,496 字节，factory 分区 3,407,872 字节，剩 215,376 字节，约 210 KiB，见 [453 格发布记录](../../reports/warehouse-453-2026-10-12.md)。151 只正背面资源约 177,722 字节，出场动画图集约 86,583 字节；按均值线性估算，新增 100 只仅这两类内容约 171 KiB，未计入新地图、声音、招式、文字和额外形态，不能称为完整 251 只已装得下。

先做完整数据打包试验，检查图块去重、名称/脚本复用、压缩与解码开销；保持逐只取用的小缓冲，不将全部素材解压到 RAM。NPC、地图也共用图块，关闭调试信息不能代替实际资源预算。

当前 NVS 为 24 KiB，V23 完整世界存档已迁入独立 `pokewalk_store` 双银行，NVS 保存校验引用；不能沿用早期“世界数据全部写 NVS”的预算。当前 459 个个体各有 24 字节技能策略，若每只扩为 32 字节，仅此就新增 3,672 字节，世界记录约达 22,304 字节，超过现有单记录 20 KiB 预算。必须重新设计并验证版本化编码/银行封装，不能直接扩大结构体写入现有记录。

当前分区间有 `0x3a0000..0x700000` 共 3.375 MiB 未分配空间，可作为资源布局方案的候选，尚未授权或实现新的分区变更；此前仓库分区例外不能直接套用于素材分区。8 MiB 总量、应用分区、存档银行和运行内存分别验算。仓库版 Wi-Fi 运行后已观测历史最低堆 21,216 字节、最大连续块低至 20,480 字节，这不等于扩展版仍有相同余量；新增解码、特例个体记录和事件状态必须重新做运行时测量。

优先保持现有分区位置和布局，继续支持当前只写应用的保档更新包。若压缩后仍必须改分区，这是单独的存储升级项目：完整备份、可回滚迁移、恢复工具和安装路径验证完成后才能发布，不能让现有更新 ZIP 绕过布局检查，也不能声称 8 MB Flash 的空白区域可以随意覆盖。

## 分阶段交付

1. **基础与容量**：冻结旧格式，建立 251 目录、资源清单、进化规则表和获取路径审计；打包完整资源验证容量，但不把未完成机制的物种投放给玩家。
2. **新篇章与城都早期内容**：基于已扩展的地图框架，接入旧档邀请、城都御三家、首批路线和道馆，以及波克比专属剧情蛋；加入咩利羊/乌波等常规进化线和旧宠新进化。优先解决 40 级玩家能立刻体验的目标。
3. **八馆与机制收集**：完成城都八徽章推进、昼夜适配、天气和新自动 AI；逐批完成剩余伙伴、地图与动画，明确展示当前已开放的物种范围，不虚称已经可收齐 251。
4. **特殊伙伴与长期挑战**：未知图腾、图图犬、果然翁先通过专门测试，再投放；完成三兽/塔顶/海渊等传说调查、时拉比事件、新最终对手与结局、强化重赛和远征高难度。按已确认的空木博士阵容实现。
5. **全图鉴完成门槛**：在无需联机交换、外部活动码或可靠联网时钟的条件下，证明每只已承诺开放的物种都有可达路径；完整 251 只及相应技能、正背面、普通/闪光颜色、出场动作和备份恢复全部通过后，才发布“251 只完整支持”。

优先级：先把新地图和稀有收集的回报做出来，再用第二世代扩展目标。携带装备、复杂繁殖、额外体力、强制每日任务都不是这次扩展成立的前提。

## 2026-10-18 路线探索交互更新

普通进入城都菜单取消 16 帧淡入和按键等待。路线列表只选择目的地，进入详情后展示野生等级、体能、当前追踪目标和线索；确认分支才消耗 5 点体能。八张地图各有三条分支，每条展示四种常规伙伴，分支影响本次随机遭遇池。

前三次探索各推进一条线索，同时约 60% 产生分支遭遇、40% 找到足迹与补给；第三条线索集齐后，下一次直接发现当前追踪目标，再轮换新目标。目标从各地图的四种追踪伙伴轮换，界面提前说明本次追踪会覆盖分支随机池。补给包含树果、牛奶、超级球与开心饼干，满堆沿用普通探索的补给替换规则，全部满额时明确提示，线索仍保留。特殊传说、未知图腾与波克比沿用各自专属流程。

发现伙伴后可直接“查看”进入这一只的遭遇，也可以“继续”选下一分支；对战、捕获或逃跑结束后返回原路线。路线的活动入口可到研究奖励、特色活动和冒险笔记。刷新页面、取消分支或退出菜单不扣体能，不推进线索。

本轮不增加持久化字段；调查次数继续表示实际付费探索次数，线索与目标由已有计数确定。关机和离开页面不会重新抽目标，旧计数保留。65535 次的历史计数达到上限后使用已有总探索数推导轮换，避免追踪永久卡住；该极限下其他路线的探索也会推进已饱和路线的轮换。研究奖励、孵蛋、故事线索和探索连携继续联动，所有结果与体能在同一存档事务提交，失败时不改变玩家进度。验证见 [路线改造记录](../../reports/johto-routes-2026-10-18.md)。
