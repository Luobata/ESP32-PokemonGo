October 7: Shiny entrances and nostalgic move names

Shiny Pokémon now finish their entrance with a brief palette flash, an eight-direction sparkle and the existing shiny sound. Wild, trainer and dungeon battles share the effect. Only the side sending out a Pokémon plays it; two shinies appear in sequence. Mute is respected.

Menu > Options > Names > Nostalgic now switches both species and move names. All 191 implemented moves have historical Chinese Gold/Silver fan-translation names. Battle text, learned-move lists and level-up notifications follow the same selection, which can be switched back to official names. The table is compiled from historical references, not a byte-for-byte verified translation ROM. Move mechanics, power, learning rules and move animations are unchanged.

The move preview supports both name styles and searches by official name, nostalgic name or ID. The original Pikachu-versus-Gyarados cover is retained.

Save format remains V20. V5–V19 migration, V20 export/import and dungeon V3→V4 compatibility remain supported. Original .pksave files need no editing. Newer saves cannot be imported into old firmware that does not understand them.

Update device firmware for these features; refreshing the website alone is insufficient. Back up first at https://luobata.github.io/ESP32-PokemonGo/. Existing devices with matching partitions can use PokeWalk-update.zip from GitHub Releases over USB. A full community installation overwrites the save area: back up before installation and import afterwards. The save-tool protocol is unchanged; current tools do not require replacement for compatibility. Refresh the website or download a new offline ZIP for the updated guide. Older tools should still be updated.

Complete guide: https://luobata.github.io/ESP32-PokemonGo/guide/
