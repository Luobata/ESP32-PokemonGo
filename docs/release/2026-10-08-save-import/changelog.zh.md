10 月 8 日：存档导入稳定性修复

修复导入校验时额外占用内存、内存不足后被提示为“存档内容不兼容或暂存失败”的问题。减少校验期间的内存需求，保留原有存档内容和安全校验。

导入失败提示现在会区分内存不足、暂存读写、内容校验、当前进度保存和恢复日志等阶段，方便继续排查。未完成导入不会显示成功，请保留原来的 .pksave 文件，不要手动修改版本号或校验值。

本次不改变存档格式，仍为 V21，支持 V5～V21 来源；V5～V20 按原规则迁移，旧伙伴默认启用全部招式。固定历史样例与隔离真实存档导入/回滚检查通过。不支持将新格式倒灌到不支持它的旧固件，也不承诺尚未实现的未来版本兼容。

这个修复需要更新设备固件；仅刷新网页不能修复旧固件的内存分配问题。请同时刷新在线存档工具，离线用户重新下载工具 ZIP，才能看到细分提示。原备份无需转换。
存档工具：https://luobata.github.io/ESP32-PokemonGo/

更新前先备份。现有分区匹配设备可使用 GitHub Release 的 PokeWalk-update.zip，通过 USB 仅更新应用；社区完整安装仍会覆盖存档区域，需要先备份、安装后导入恢复。

社区截图本身不能确定每一次失败的原因；若更新后仍报错，请保留完整错误提示和原备份继续排查，勿公开上传私人存档。
