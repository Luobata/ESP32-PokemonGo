2026.10.26 · 捕虫调查投球修复与流畅度优化

投球更跟手，判定跟着看见的位置走
选中「投球」后，按下 C 就开始投球，不再等松手。命中使用最后显示的指针位置，避免看见在蓝区内、处理按键时却已移出。一次按键只投一次，保存失败后不会因为松手再自动扣球重试。

捕获条与普通捕获统一
捕虫调查采用与普通捕获相同的边框、箭头和蓝区绘制。切换候选、换球或返回页面会按当前目标重建显示；蓝区变窄时清除外侧旧颜色。显示目标与投球目标一起锁定，防止对错伙伴结算。

减少捕获页面顿挫
指针移动只刷新捕获条，投球演出只刷新变化区域。真机本次连续采样约 24.8 帧/秒；指针往复仍为 1.2 秒，捕获公式、球种加成与动作播放时长不变。存档提交放在球飞出后的静止姿态，完成后继续吸入、弹跳、摇球，不跳过动作。

投球次数更清楚
显示「本局余 N 球」：整局六个观察点合计最多投球 3 次，并非每只候选 3 次。整局机会用尽或当前球种不足时，不再显示可投蓝区，也不会播放无效投球。仍可换球、继续观察或提前结算；完整六点记录不要求成功捕获。

升级与验证范围
需要升级固件，单独刷新网页不会修复设备。存档仍为 V32，支持同设备 V5–V32，分区与备份容器不变；旧备份无需编辑。本次未更改存档工具协议，在线网页刷新可看新说明，已支持格式 4 的离线工具仍可用。
