September 19 update: Brightness controls, Wi-Fi setup and save backups

1. Options > Brightness now offers 10%–100% in 10% steps. Press C to edit, A to increase, B to decrease and C to finish. Your choice survives restart and screen wake. A failed save leaves the previous setting intact and asks you to retry.

2. Fixed Wi-Fi Time setup rejecting a phone connected to the device hotspot with “Setup is not active” at 192.168.4.1.

3. Fixed the website and offline save tool rejecting current saves as an unsupported version. REV-0815 users can refresh the updated website to back up without reflashing. Offline users should download the updated tool once.

4. The save tool no longer uses a per-game-version allowlist. Future game versions using the same backup format and layout work without another tool update. Import still requires the same device and exact firmware build; this does not enable arbitrary cross-version restores.

Save manager: https://luobata.github.io/ESP32-PokemonGo/

Brightness and Wi-Fi fixes require the new game firmware. A full installation may overwrite saves. Back up first and keep the matching old installer.
