10 月 7 日：招式设置与仓库管理

每只伙伴都能选择自动战斗使用的招式。队伍或仓库详情进入「技能」，默认全部启用，可反选不想使用的大副作用招式，也可一键全部启用。至少保留 1 个已学招式；新学技能默认启用。设置跟随个体，换位、入库和进化后保留，野生、训练家及秘境对战共用。正在对战或秘境中时只可查看，结束后再修改。

仓库可以直接放生，不必先换入队伍。确认页显示名字、等级，闪光另有提醒，默认选择取消。保存成功才移除这只伙伴，图鉴和成就历史保留。新增「等级从低到高」排序，方便找低等级伙伴；不提供批量放生。

修复经历多次升级后，旧秘境记录仍占用空间、可能导致存档保存失败的问题。只有当前秘境进度完整校验通过，或新记录成功提交后，才清理已被取代的旧记录。

存档升级到 V21：支持 V5～V20 迁移，旧伙伴默认全部启用招式；V21 可导出后再导入。保留队伍、仓库、闪光、图鉴、养成、道具、挑战、秘境与设置。固定历史样例和隔离真实 NVS 导入/回滚检查通过；真机已验证 V20→V21 启动保档、连续保存和再次重启，未覆盖导入玩家唯一存档。不支持将 V21 倒灌到不认识该格式的旧固件。

新功能需更新设备固件。更新前先备份：https://luobata.github.io/ESP32-PokemonGo/
分区匹配的现有设备可用 GitHub Release 的 PokeWalk-update.zip 通过 USB 更新；社区完整安装会覆盖存档区域，必须先备份、安装后导入。当前在线和离线存档协议不变；刷新网页或重新下载离线 ZIP 可获得新版攻略，更早的存档工具仍应更新。原 .pksave 不用修改。
