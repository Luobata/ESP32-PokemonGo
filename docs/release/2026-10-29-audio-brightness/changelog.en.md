Sound and brightness settings

- New installs with no saved audio preference start with music and sound effects at 55% volume. Existing mute and volume choices stay unchanged. To enable sound after previously muting it, open Menu > Options > Mute and press C.
- Brightness now has its own screen with a gauge and percentage. A increases and B decreases it in 10% steps, from 10% to 100%. Changes save immediately; C finishes and holding B returns.
- Brightness survives restart and screen-off/wake. If saving fails, the previous brightness is retained and a retry message appears.

Update the firmware to use these changes. Save format is unchanged; same-device V5–V32 backups remain supported. Offline tools supporting format 4 still work. Refresh the guide for new instructions. Existing players should use the USB save-preserving update; a full community installation may erase progress, so back up first and restore afterwards.
