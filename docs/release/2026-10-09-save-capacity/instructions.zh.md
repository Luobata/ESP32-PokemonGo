本次修复部分设备更新后因存储空间不足而保存失败的问题。必须更新固件，只刷新网页不能修复。支持同设备 V5–V22 备份，旧备份无需手工转换；V22 不能导入尚不支持它的旧固件。当前网页和离线工具的备份协议不变。

更新前保留原 .pksave。若旧版已经无法导出，请使用分区匹配的 PokeWalk-update.zip，通过 USB 只更新应用区，工具会先备份并核对数据分区。不要直接完整安装覆盖唯一存档。社区完整安装可能清档，安装后需导入原备份。

招式设置与仓库放生
队伍 → 伙伴详情 → 技能，或仓库 → 个体详情 → 技能：A/B 选择，C 启停，长按 B 返回；末尾可全部启用。至少保留 1 招，新学招式默认启用。个体设置随换位、入库、进化保存。对战或秘境中只能查看。
队伍详情的「仓库」进入列表，选中个体 → 放生，无需先换入。确认默认取消，核对名字、等级和闪光提醒后再确认；不能撤销。保存失败保留伙伴，图鉴与成就不受影响。仓库长按 A 打开筛选/排序，可按等级从低到高查找。对战或秘境中不能放生。

开始冒险
首次开机听完大木博士介绍，按画面提示从妙蛙种子、小火龙、杰尼龟或皮卡丘中选择伙伴。已有存档会继续原进度。游戏可离线游玩，不需要先配网。

按键
A 上一项，B 下一项，C 确认；长按 B 返回，长按 C 熄屏。无操作约 60 秒自动熄屏，按任意功能键唤醒，唤醒的第一下不会触发页面操作。捕获时 A/B 切换球，C 在合适时机投球；部分页面操作以屏幕提示为准。

从哪里开始
主页用 A/B 选择照料、菜单或遭遇，再按 C。菜单可以进入图鉴、队伍、道具、照料、挑战、选项、成就、探索与秘境。建议先去「探索」选择路线寻找伙伴，获得遭遇后选择捕获或战斗。战斗自动从已学招式出招，无需管理 PP。玩耍需要至少 5 点体能；体能不足仍可用树果喂食。成长到进化条件后，设为队首并到「照料 → 进化」确认。

体能与挑战
体能上限 100，约 1 小时恢复满。普通探索与路线训练家切磋消耗 5 点；道馆、强化重赛和赤红消耗 10 点；四天王与冠军整轮消耗 20 点。森林秘境选择自己的 1～3 只伙伴，新开局消耗 20 点，继续旅程不重复收费；场间保留局内 HP 和异常，已结算奖励不会因失败或结束丢失。

电量显示
菜单和照料页的宝可梦名字右侧显示电量，20% 及以下变红。在「菜单 → 选项 → 电量显示」按 C 开关，重启后保留选择。

成就与秘境伙伴
背包道具已满仍可领取成就，奖励补到上限，超出部分不增加。森林秘境最终首领通关结算后，会把一只可捕获伙伴放入「遭遇」；返回遭遇列表选择它，再正常投球捕获。列表最多五只，满时替换最早一只。

声音与亮度
「菜单 → 选项」可切换静音、调整音量和亮度。音量或亮度按 C 进入调整，A 加、B 减，C 完成；亮度范围 10%–100%。设置重启后保留。调音量不会自动解除静音。

Wi-Fi 校时与关机体能
进入「菜单 → 选项 → Wi-Fi校时」，按 C 开启配网。手机连接设备画面显示的 PW- 开头临时热点，密码也显示在设备上；保持连接，即使手机提示此热点无法上网。浏览器打开 http://192.168.4.1，填写可用的 2.4GHz 家庭 Wi-Fi 或另一台设备提供的热点名称和密码，点击「连接并保存」。回到设备查看状态，显示「时间已同步」即成功。
配网热点约 5 分钟自动关闭；C 可关闭或重新开启，长按 B 返回也会关闭。连接失败检查名称、密码和网络，再重新开启配网；非配网画面按 A 重试联网校时。成功联网后保存网络，下次开机自动连接。首次校时建立时间基准，之后开机校时才能补回关机期间的体能；断网仍可游玩。

备份与导入
桌面 Chrome / Edge 打开 https://luobata.github.io/ESP32-PokemonGo/，选择私人备份目录，用 USB 数据线连接设备并授权串口，关闭占用串口的日志工具。设备进入「菜单 → 选项 → 备份存档」，按 C；等网页文件保存、设备提示完成。文件保存在自己的电脑，不上传。
导入时先在设备打开「选项 → 导入存档」，网页选择 .pksave 文件并请求导入。设备默认取消，需选择确认覆盖并按 C；系统先备份当前进度，再导入并重启，重新连接网页核对结果。导入要求同一设备，且当前固件支持备份的存档格式。本版可读取 V5～V22 来源存档，不再要求固件构建完全相同；不支持将较新的存档导入不认识该格式的旧固件。旧 .pksave 文件无需转换或修改。
离线使用可在网页下载工具 ZIP，解压后用 Python 3.8 或以上运行 python3 server.py（Windows 可用 py -3 server.py），再打开 http://localhost:8767/。跨版本导入请先更新设备固件，并刷新网页；离线用户请重新下载工具 ZIP。只有更新网页、设备仍用旧固件时，仍可能提示不兼容。开发命令行 restore.py 仍限同一构建，跨版本请用网页或离线网页工具。

牛奶回复
训练家、道馆与联盟对战的「战术 → 牛奶回复」现在回复最大 HP 的一半（向上取整），至少 50 HP，不超过满血，并解除异常状态。使用占一回合，倒下的伙伴不能使用；照料时仍是饱食 +20、心情 +10。

更新前请先备份。社区完整安装可能覆盖存档，请保留原备份文件；导入兼容以当前固件能读取的存档格式为准。

更新与恢复
更新前请先保存 .pksave。社区完整安装会覆盖原存档区域，安装新版后用备份恢复。已安装 PokeWalk 且布局一致的设备，也可从 https://github.com/Luobata/ESP32-PokemonGo/releases/latest 下载 PokeWalk-update.zip，按包内 README 用 USB 更新；该工具先备份再更新，不可作为社区安装固件上传。
网页只有在本次文件与重启后的结果一致时才确认导入完成；如果仍在等待或报错，请保留原备份并核对设备进度。新地图及 V22 迁移需要升级设备固件，单独刷新网页不能获得游戏新内容。

新地区与主题秘境
探索 → 路线中只列出已经开放的地区：彩虹徽章开放双子海岛和野生原野；粉红徽章开放幽灵高塔；金色徽章开放磁轨矿坑；深红徽章开放火山遗迹；绿色徽章开放龙息山谷。战胜冠军开放无人研究所，再完成一份新地区研究开放白银雪岭。完成八份新地区研究后开放冠军远征。
进入新地图选择「探索」，再选一条方向，消耗 5 点体能。发现五种当地伙伴后，在「活动」切换深层调查；深层同样消耗 5 点。研究要求发现五种、捕获三种、完成一次目标追踪并通关当地秘境；已有图鉴计入，可在活动页查看和领取一次性奖励。
从「活动」进入当地秘境，或在「秘境 → 选择主题」切换。新开局选自己的 1～3 只伙伴，消耗 20 点体能；继续不重复扣费。当地首通后可选挑战档。通关后选择寻找伙伴的方向，再回「遭遇」捕获。新主题奖励遇到满遭遇或满背包会暂存，不替换旧遭遇；在秘境入口领取，或经过二次确认后放弃，再开始下一局。旧森林的奖励规则保持。
本次使用 V22 存档，并迁移旧秘境记录；当前网页及 10 月 5 日修复后的离线工具可直接处理，无需手改备份。更早工具仍需刷新或重新下载。

探索方向与等级
新地区共有 24 条栖息地路线，方向页显示代表伙伴和常规/深层的实际等级范围。例如双子海岛分为贝壳滩、冰洞口、深海潮道，三处伙伴池不同；全地区共享追踪线索，追踪目标或保底可能跨越所选方向。普通探索等级：双子海岛 35–45、幽灵高塔 42–55、野生原野 38–50、磁轨矿坑 45–58、火山遗迹 48–60、龙息山谷 50–65、无人研究所 60–75、白银雪岭 65–85。深层调查使用对应区间的较高一半。
这些新地图的遭遇等级不再跟随首发等级，生成后固定，换首发或重启不会重抽。原四条路线仍按伙伴等级适配；已存在的遭遇保留原等级。选择光标或取消不扣体能，确认方向后才消耗 5 点。


轮换、照料与连携
探索分支页显示两种当前访客，同一地区每探索 12 次轮换。照料页选择「养成效果」可查经验、特殊发现与捕获加成。地图或徽章活动的野生胜利累计连携；确认捕获或探索战败清零，其他模式不影响。有连携时捕获默认取消，用 A/B 选择后 C 确认。菜单和照料名字附近显示累计亮屏游戏时长。

译名与闪光出场
在「菜单 → 选项 → 译名」按 C 切换官方／怀旧。「肥大」怀旧版现在也显示对应招式旧译；切换只改变名字，不改变战斗效果。闪光伙伴真正出场时会播放星光特效，静音时不发声。
