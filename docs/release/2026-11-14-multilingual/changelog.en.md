This update

- Adds Simplified Chinese, Traditional Chinese and English across menus, dialogue, Pokémon, moves and Wi-Fi setup. English uses pixel lettering and word wrapping. Language is saved across restarts and restored with backups.
- Adds a star to every shiny party member so they are easy to identify while browsing or switching partners.
- Improves Wi-Fi setup: background scanning pauses, up to two clients can connect, and the device shows the connection count. The webpage acknowledges submission before the hotspot closes. Network-not-found, authentication, connection and hotspot startup failures are distinguished; credentials are saved only after a successful connection.
- Corrects the challenge screen's stamina description to about one hour for a full refill; recovery speed is unchanged.

Install the firmware to use these features; refreshing the guide alone does not update the device. Save V32, partition layout and backup format are unchanged. Same-device V5–V32 backups migrate automatically; offline tools supporting format 4 remain compatible. Backups without a language preference default to Simplified Chinese.
Existing players should prefer the USB save-preserving update package. Back up before a community full installation and restore afterwards as needed. Keep a readable backup before updating.
