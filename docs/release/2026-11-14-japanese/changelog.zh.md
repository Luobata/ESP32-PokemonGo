# 日本語追加

现在可以用日语游玩 PokeWalk。在「菜单 → 选项 → 语言」按 C，循环切换简体中文、繁體中文、English 和日本語。

- 菜单、剧情、调查提示、道具、战斗提示和配网页支持日语；251 只宝可梦与招式使用日文名称。
- 日语对话使用专用字形和换行规则，标点、小假名与前文衔接；照料页为较长的日语标签留出空间，招式说明完整展示。
- 语言选择立即保存，重启保留，也随存档备份恢复。中文官方／怀旧译名偏好独立保留。
- 保持现有战斗、捕获和进化节奏，游戏规则不变。

需要升级这次固件；仅刷新网页不会增加设备的日语选项。同设备 V5～V32 备份继续支持，原文件无需修改，世界存档和备份格式不变。已经更新过上一版存档网页／离线工具的玩家可以继续使用。

更新前请先备份。已有游戏优先用 USB 保档更新包；社区完整安装可能清除存档，需安装后导入备份恢复。不保证新格式备份可导入不支持它的旧固件。
