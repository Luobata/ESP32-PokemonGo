# Japanese language support

Play PokeWalk in Japanese. Open Menu → Settings → Language and press C to cycle through Simplified Chinese, Traditional Chinese, English and 日本語.

- Japanese menus, story dialogue, investigation clues, items, battle messages and Wi-Fi setup. All 251 Pokémon and move names have Japanese entries.
- Dedicated Japanese glyphs and line wrapping keep punctuation and small kana with the preceding text. Care labels have more room, and move descriptions remain readable.
- Your language choice is saved, survives a restart and is included in save backups. Chinese official and nostalgic name preferences remain independent.
- Existing battle, capture and evolution pacing and game rules are unchanged.

Install this firmware to enable Japanese; refreshing the website alone does not add it to the device. Same-device V5–V32 backups remain supported without editing the original files. The save and backup formats are unchanged, and the backup tools updated with the previous release still work.

Back up before updating. Existing players should use the USB save-preserving update package. A full community installation may erase progress; import your backup afterwards. New-format backups are not guaranteed to work on older unsupported firmware.
