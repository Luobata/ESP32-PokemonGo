# 稀有与闪光搜寻：道具及活动设计 v2

状态：完整设计稿，待实现。2026-09-15。本文替换此前五道具草案的获取表和使用细节；不是把多轮草案的奖励累加。以下新增功能均未加入已烧录固件。

用户范围：完善全部十种候选道具及稀有搜寻事件；不设计携带装备。延续自动战斗、统一体能、最多五条遭遇、已解锁物种范围和金银像素画风。

## 1. 体验目标

让一次出门探索有清楚的选择和结果：想补图鉴就用寻新香，想找龙系就选属性诱饵，想追闪光就用星光香；遇到目标后可暂时保留，再用合适的球与一种捕获辅助增加把握。

日常只需理解“一种探索准备 + 一个球”。地图立即生效，标记对已有遭遇生效，不形成另一套长期增益。捕获辅助可选，正常捕获不依赖它。无新货币、合成、装备、PP或可消费探索点数；体能仍靠时间恢复。

### 寻新香为何不再写“权重乘三”

当前普通探索已经有“四次抽取中三次优先未捕获”的规则，简单再乘权重容易几乎感受不到。寻新香明确保证“同星级存在合格未捕获物种时选未捕获”，但不自动把低星抽取换成尚未捕获的五星。属性诱饵采用当前普通选择规则的候选权重形式：保留现有 75% 优先未捕获分支，在该分支选出的候选集内对命中属性乘 3；不同时启用寻新香。

属性诱饵只有一种库存物品，不拆成十几种道具。选择属性后绑定当前路线；切路线暂停，回到原路线继续。属性来自本项目物种数据，不硬编码原作之外的物种。只显示当前路线已解锁物种具有的属性；无候选时不能使用，且不扣物品。

## 3. 生效范围与抽取顺序

“合格候选”必须同时满足当前路线／活动范围、物种解锁、星级以及不与待处理遭遇重复。屏幕上的星级采用该遭遇最终保存的星级。

| 场景 | 稀有香 | 寻新香 | 属性诱饵 | 星光香 |
|---|---|---|---|---|
| 主动普通探索的随机伙伴 | 是 | 是 | 绑定路线时 | 是 |
| 主动普通探索的指定／随机追踪目标 | 否 | 否 | 否 | 是 |
| 仅获得线索 | 不扣次数 | 不扣次数 | 不扣次数 | 不扣次数 |
| 徽章活动的固定主题伙伴 | 否 | 否 | 否 | 否；活动末段有独立闪光加成 |
| 后台 Wi-Fi 自动发现 | 否 | 否 | 否 | 否 |
| 训练家、道馆、秘境敌方队伍 | 否 | 否 | 否 | 否 |

随机探索顺序：

1. 根据当前游戏规则计算养成、队伍、探索进度对应的星级分布。
2. 稀有香仅将四、五星权重各乘 2 并归一化，再抽取星级。原有四星／五星保底按原逻辑兜底，不能被任何道具降低。
3. 从该星级合格候选中选物种。寻新香与属性诱饵在这一阶段作用；不跨星级制造未解锁稀有物种。
4. 已确定物种和星级后独立判定闪光。星光香只修改本次闪光阈值，不重复判定物种。
5. 分配遭遇标识，将物种、等级、星级、闪光、队列变化与道具剩余次数原子保存，再呈现和提示。

稀有香在五星保底已必出五星的这一抽不扣次数；其余有效随机抽取消耗一次，即使最终没出四星。寻新香在候选没有未捕获物种时不扣；属性诱饵在实际候选集内既没有所选属性、或候选全部已是该属性而无法改变选择时不扣。星光香在任意允许场景成功生成伙伴时扣一次，不以“是否闪光”为条件。

如果没有合格候选、队列无法插入、存储失败，本次不消耗体能或准备次数，不推进随机状态；不能通过失败重试刷新种子。已有伙伴的闪光身份不受后续使用道具影响。

### 闪光概率的可理解性

普通探索目前是 1/512，五星普通探索是 1/256；星光香分别提高到 1/128 和 1/64。十次都是普通伙伴时，至少见到一只闪光约 7.5%；十次都是五星时约 14.6%。这是独立抽取的概率说明，不是保底，实际路线混合结果不同。

香按次数生效并存档，关机不消耗。准备栏只允许稀有香、星光香、寻新香、属性诱饵中的一种。不可叠加；允许主动结束剩余效果，但需显示“放弃剩余 N 次？”并二次确认，确认默认选择取消，结束不返还库存物品。随后可使用新准备，避免被不适用的香长期卡住。

## 4. 地图和标记的完整规则

### 线索地图：立即获得进展

在背包使用后列出四条路线，显示各自目标与“线索 1/3”。仅当前存在有效目标、线索不足 3、且本轮尚未用过地图的路线可确认使用；不可用项显示具体原因，不靠置灰让用户猜。

提交成功后增加一条线索，展示一次短足迹演出和“线索 1→2”；库存随之减一。已经三条、目标未开放或保存失败都不消耗。它不是免费遭遇，也不退还体能。手动更换目标、追踪完成及轮次变化要和现有追踪进度规则保持一致；每路线每轮最多一张，切目标、切路线不能清除本轮已用标记来反复堆线索。完成并推进到下一轮后才重置地图资格。

### 追踪标记：五个槽内保护一个

背包使用时选择待处理遭遇，以唯一遭遇标识绑定，而不是列表下标。显示“保留 拉普拉斯？”及星级／闪光图标，确认并保存才扣一个。

- 被标记的伙伴仍占五条中的一条，显示“保留”图标和列表文字；展示闪光标志不被它覆盖。
- 新遭遇到来时，淘汰最早且未被保留、未被正在进行的交互占用的记录；绝不移动或重抽被保留伙伴的属性。
- 若没有可淘汰记录，主动探索提示“请先处理遭遇”，不扣体能和物品；后台发现跳过插入，不删除已有记录。
- 进入战斗或捕获时保留身份可随同一个遭遇保存到结束，但不允许从列表新标记已进入处理流程的伙伴。战胜／战败／捕获成功／主动逃跑／对方逃跑后，按照原有规则完成或移除遭遇，保护同时结束，不能凭标记复活遭遇。
- 已有一个标记时，给另一条加标记需确认“替换保留对象？”，保存成功后再扣一个新标记，原标记解除但原遭遇不立即消失。
- 允许免费解除保留，需确认，不返还已用物品。普通浏览、退出页面、重启不解除，也无现实时间到期。
- 即将被顶掉的未标记闪光伙伴，可在遭遇列表显示提示；本轮不设计自动付费保留、自动消耗标记或扩大队列。

## 5. 捕获辅助：提前准备，投球时保持简单

背包使用喷雾／守候果，只能提前准备一种；选择后显示“待用于下一场捕获”，不立即扣库存。也能在背包免费取消未用准备。不能覆盖另一种待用辅助；更换先取消即可，不需要损失物品的确认框。

首次进入一条遭遇的捕获流程时绑定该遭遇。若无法适用，不显示已生效；结束该遭遇或取消捕获返回主选择时撤销尚未使用的绑定和准备，不扣物品。已经生效的道具不退回；每条遭遇最多生效一种辅助、且一次，防止来回菜单反复使用。

喷雾在实际投出非大师球时才消耗，降低这一投的指针速度；预览中直接体现减速。若更换为大师球则不消耗，按大师球必捕规则执行。

守候果只在“捕获失败 → 对方一次反击”确实将造成正直接伤害时消耗，先将本次反击所有直接命中伤害合并减半，正伤害最低 1，再扣血；多段招式仍只消耗一个。没有伤害、招式落空或只施加状态时不消耗；若仍在同一捕获流程中等待，保留到下一次符合条件的失败反击。一般战斗、持续状态伤害、自伤／反冲不触发。

战胜后的最后一次捕获没有反击，守候果不适用、不消耗。守候果不会阻止原本会发生的逃跑，也不会让战败后还能继续投球。

珍藏球和闪耀球的倍率都相对普通球计算，仅替代球类倍率；不能和高级球、彼此叠加。捕获窗口仍受现有上限限制。道具不增加战胜后的单次捕获机会，失败后果保持当前规则。

反馈：球选择行显示“稀有 ×3”“闪光 ×4”或“普通效果”；辅助行显示“喷雾待用”“守候果待用”。喷雾用淡粉波纹，守候果用一次青色护罩和“守候果保护了伙伴”短提示。战斗自动出招节奏不变。

### 每次三段，不增加操作步骤

1. 读取一段主题线索，按现有规则付 5 体能寻找第一只伙伴；战胜或捕获推进一次。
2. 第二段对白推进调查，再付 5 体能寻找；失败或逃跑不推进，已完成段数保留。
3. 第三段出现特别踪迹，再付 5 体能寻找末段伙伴。首次新搜寻周期末段从合格四、五星主题候选中抽取；重复周期末段按二星／三星／四五星合计 30／50／20 权重抽取，四五星桶内按合格物种基础权重选择。空桶剔除后归一化；首次四五星桶完全无候选时提示先处理同物种遭遇或当前尚未开放，不扣费用，不降级冒充稀有。
4. 同一只先战胜再捕获只推进一次；第三段完成后领取现有奖励和新增奖励，回到同一活动列表。

活动保留现有固定推荐等级，不能通过更换队首临时降低难度。活动不消耗香。只有末段伙伴独立享受 1/128 闪光率（当前活动为 1/512），所有星级一致，不与星光香相乘。通过淡淡星屑踪迹表达“闪光机会提高”，不要在结果揭晓前展示闪光伙伴专属标记，以免误导必中。

首次三段全成功最低消耗 15 体能；战斗或捕获失败需要重新寻找，可能更高。活动的稀有机会由额外完成战斗、固定难度和体能共同约束，不添加冷却点数；所有已解锁活动可选择重复挑战。

旧玩家可补领新增首次补给，但不重新发原来的进化石等首次奖励。正在进行的旧活动本轮沿用原池和流程，下一个完整周期才启用新末段规则；“新增补给已领”和“新搜寻首次稀有周期已用”分别保存，避免补领礼物把稀有机会一起跳过。

## 8. 界面和视觉验收

### 背包

分类沿用现有列表，扩展为“球类／搜寻／捕获辅助／进化／照料”。只显示拥有或已有待用状态的物品，避免大量空项。列表显示数量，详情两行说明加“使用”即可；大于三项继续用 A/B 上下、C 确认，长按 B 返回，长按 C 仍熄屏。

使用香显示效果、次数和是否适用当前路线；属性诱饵先选属性再确认，取消不扣。地图选择路线，标记选择遭遇，其他道具没有装备选择页。

### 探索和遭遇

探索准备摘要示例：“星光香 · 余 8 次”“水系诱饵 · 海边 4 次”。只展示一个准备状态；不叠多个横幅挤占现有信息。暂停的诱饵明确写“仅海边生效”。

遭遇行：名字、等级、星级、已捕获球标、闪光标记和保留标记分别留固定位置；空间不足时次要信息移到详情，不能覆盖名字或血条。保留标记用书签形，不用闪光星形。

### 演出

新道具沿用现有像素网格、黑描边、每图 3–4 个主色。所有道具触发短演出约 0.4–0.8 秒，不额外强制弹窗。稀有发现用足迹与金点，闪光发现沿用真正闪光演出；“概率增益生效”和“实际出现闪光”必须视觉区分。

遵守静音与音量设置，熄屏时不主动点亮；新的实际稀有／闪光遭遇仍使用用户允许的提醒规则。

## 9. 三段完整体验例子

- 补图鉴：背包使用寻新香 → 森林探索 → 同星级有未收录物种时出现新伙伴 → 选择球捕获 → 图鉴增长，香余 4 次。
- 找闪光：四徽章领取星光香与闪耀球 → 使用星光香 → 普通探索实际发现闪光 → 用追踪标记保留 → 准备喷雾 → 回来选择闪耀球投球。没有出现闪光也能看到剩余次数，奖励进度继续积累。
- 对付强敌：提前准备守候果 → 遭遇高等级稀有伙伴 → 选择珍藏球直接捕获 → 失败时本次反击减半 → 回到捕获／战斗／逃跑选择，玩家决定继续冒险还是离开。果实不是无限保护。

## 10. 开发拆分与交付门槛

本次全部完善设计，实施顺序不等于移除后续范围：

1. 基础与第一轮体验：存档兼容、容量优化、十种道具定义／背包展示；稀有香、星光香、寻新香、两种球、首批成就奖励。
2. 选择与容错：属性诱饵、地图、标记、喷雾、守候果及所有待用／解绑／队列事务。
3. 内容与平衡：八活动故事和末段机会、重复奖励、旧玩家补领、秘境来源、后台验收场景及完整实机验证。

技术约束：

- 旧球 ID 0–7、道具 ID 0–18 不移动；新球采用显式映射，不能插入旧枚举导致进化石变成球。
- 冻结 V17 和更早库存类型。库存嵌在存档、秘境及待领奖凭据中，新增数据用版本化扩展迁移，不移动旧字段偏移；真实旧存档保留图鉴、队伍、体能、Wi-Fi 校时基准、活动与秘境。
- 按现有 world/save 事务同时写库存、准备、遭遇、次数和奖励收据。绑定使用唯一遭遇标识及追踪轮次，不用可变列表索引。进度重复回调要幂等。
- 最新已烧录应用约 3,137,808 字节，3 MiB 应用分区仅余 7,920 字节。先评估压缩／裁减可替代资源与代码体积，不能无审查扩大分区覆盖 cardid、存档恢复或 Wi-Fi 配置；社区安装包约束也要核对。
- UI 和战斗／捕获效果走现有 C 同源渲染，网页不能单独实现一套效果。设计完成不等于概率、时序、内存和掉电恢复已经实测通过。
