# 亮度设置与 REV-0815 用户反馈修复

## 变化

- 菜单 → 选项增加亮度。按 C 进入调整，A 增加、B 减少，C 完成，长按 B 返回；范围 10%–100%，步长 10%。设置写入 NVS 后即时应用，保存失败保持原亮度并提示重试。重启、熄屏唤醒和睡眠失败恢复都使用所选亮度。正常亮度不提供 0%，熄屏仍独立关闭背光与面板。
- 修复手机连接配网热点后访问 `192.168.4.1` 被误报为 `Setup is not active`。本项目启用 IPv6，ESP-IDF HTTP 服务创建双栈监听套接字；原实现仅接收 `sockaddr_in`。现在兼容 IPv4 和 `::ffff:192.168.4.1` 映射地址，保留配网状态、接口地址、表单令牌和 Origin 检查。
- 存档管理网页及离线工具按备份格式和分区布局校验，取消逐个游戏存档版本的白名单。存档版本作为 uint16 正整数元数据原样保留，后续沿用现有协议和布局的版本无需同步更新工具。修复当前 V17 固件备份时报“设备或存档版本不支持”，以及 CLI 预恢复备份错误标记为 V15。导入仍要求同一设备和相同固件构建，不代表支持跨构建导入。
- Pages 发布前用当前固件版本生成真实 C 协议数据，验证网页接收和导入；覆盖模拟未来版本 V18、V99、V65535；后续如破坏备份协议或布局兼容性，会在发布前失败。

## 验证

- `verify_display_settings.py`：生产 C 设置实现，覆盖缺省值、边界、重启读取、NVS 各阶段失败、熄屏期间调整不点亮。
- `verify_display_settings_preview.py`：69 次实际菜单输入和分带一致性检查，覆盖调整、保存失败、唤醒、返回以及 Wi-Fi 入口；截图已检查。
- `verify_screen_idle_input.py`：42 项按键/熄屏用例及 9 个负向对照，新增低亮度唤醒和睡眠失败恢复。
- `verify_wifi_time.py`：模拟双栈套接字，旧实现可复现误拒绝；新实现通过 IPv4、映射地址、非热点地址拒绝、表单校验、配网超时、联网及校时重试。
- `verify_usb_backup.py` / `verify_usb_import.py`：当前固件版本真实 C 协议与 JS 解码联测，覆盖当前和模拟未来版本、非法版本字段拒绝、校验错误、设备确认、备份 ACK，以及导入暂存/应用阶段各 I/O 边界断电恢复。
- `verify_usb_backup_checkpoint.py` / `verify_save_manager_distribution.py` / `verify_display_sleep.py`：导出前存档落盘、网页及离线工具分发、PWM 关闭及面板睡眠顺序通过。
- ESP-IDF 固件构建及发布包分区检查通过；游戏程序仍在原 factory 分区内，未改变存档分区和存档结构。

## 交付边界

本次为本地实现和验证，尚未提交、部署网页、发布社区固件或烧录设备。网络测试使用系统调用边界模拟，尚未用真实手机完成配网和 NTP 校时，也未实测不同亮度的观感和功耗。

备份修复发布到 GitHub Pages 后，REV-0815 用户刷新网页即可使用，无需重新烧录；亮度和 Wi-Fi 修复需要新版固件。仍应使用保留存档的烧录方式，完整社区镜像安装可能重置存档。
