# 日本語追加与容量、存档回归

本批在三语言公开版 REV-5609 / `bc64403` 上新增日语。游戏实现提交 `65c836159c67677266f9216d3cf6fb57bcef304b`，指南单独更新。官方／怀旧中文译名独立保留；日语不是替换中文名称表，也没有新增战斗规则。

## 实现与素材

- 设置顺序固定为简体 0、繁体 1、英文 2、日文 3。日文目录覆盖 2,262 条菜单、剧情、活动、道具、战斗和配网文案；251 物种和 251 招式名称有对应日文条目，实际可用招式仍为 194，未把名称覆盖当作新增招式机制。
- 名称来自固定 [PokeAPI 数据提交](https://github.com/PokeAPI/pokeapi/tree/8a92bfa7dab2f12b84b5d151562f9857c133ff30)，CSV 摘要保存在 `japanese_names.json`。界面对白为本项目翻译，不宣称是金银原版日语剧本。
- 日文使用 949 个 16×16 位图字形；记录 Hiragino Sans W3 源摘要与产物摘要，ASCII 沿用 Gold 像素字形。生成文件随源码提供，检查模式无需本机字体。语言选项中的简体“简”复用原字形。
- 有限缓冲格式化保留完整 UTF-8；日语按字符换行，标点和小假名不单独放到行首。推理提示可用两行，照料页缩短进度条给日语标签留出空间。所有招式短说明检查在 208 px 内，不遮挡下方提示。

## 空间与性能基线

原应用剩余 26,672 B，直接叠加日文目录与字形会超过应用分区。此次只压缩不可变的 Gold OAM 对象表：共享完全相同的子序列，再对相邻对象对去重。没有更改轨迹、时钟、位置、颜色或绘制顺序；运行时只多一次固定表查询，不用解压堆缓存。

按原始 7,773 个 span 还原后仍为 106,223 个对象，固定 SHA-256 为 `0afdd7838747b9d224678a97987bf1a99f1579010e32415bbd0f0948155efd6d`。相对于上一版已经做过形状共享的 436,394 B，对象表变为 318,770 B，节省 117,624 B；不能把它与未压缩结构的大小混淆。

最终应用 **3,388,448 B**，factory 剩余 **19,424 B**；完整包 **3,453,984 B**。原 8 MiB 布局和所有分区不变。应用 SHA-256 `9d39054f679d3d892db12343aa4976c19d3d8f2f81f9a69db96ff7580d3fa0b9`，完整包 `daeaf82e3fc9b5701f8da31a2e48452154f3c3ace724613304762882848edf8f`。

目标编译检查：RTC 7,864 B，保留 328 B；IRAM 79,360 B。formatter 最大单函数栈 160 B、language 48 B、game_ui 592 B。首次检查发现 move settings 为 608 B；按实际名称上限将临时标签从 80 B 缩至 64 B 后回到预算，并验证所有日文招式名长度。没有扩大任务栈或导入工作区。

## 兼容边界

世界仍为 V32 / 39,976 B，队伍 6 + 仓库 753，格式 4 备份 72 KiB；原有 V5～V32 迁移继续支持。仅现有 NVS 显示偏好新增合法值 3，缺少语言键的旧备份仍默认简体。网页和离线容器未改协议，之前更新的工具仍可用；官网只补充语言入口与发布记录。CLI 仍不承诺跨构建/扩展仓库直接恢复。

日语需要升级固件，刷新网页本身不会改变设备。完整安装仍可能覆盖进度，应先备份、装后恢复；已有玩家优先 USB 保档更新包。devbox 沿用用户此前“先完成 GitHub 和社区”的部署范围，未在这次绕过已过期的公司凭据。

满仓、故障注入与所有招式逐帧检查是宿主/隔离真实 NVS；不能当作用户设备满仓实测。真机全程静音，未做扬声器实听或社区 BLE 完整安装，不把静音通过写成音乐切换实听通过。社区 BLE 安装和全部短动画三轮重复未测；此次战斗对照为同场战斗内三段连续采样，不是三场独立战斗。


## 存档覆盖和完整战斗补测

真机先导出「日语、亮度 100%」，再通过正常菜单改成「简体、亮度 40%」并重新导出确认落盘；开关真实 AP 后，在同一次启动中导入原备份。72 KiB 上传 92.64 秒，匹配暂存/重启回执，实际设置恢复到日语及 100%；随后生产解码比对伙伴、仓库、技能策略、等级/经验、图鉴、待处理遭遇、背包、关都/城都、活动、地图等进度一致。接收时 minimum 8,040 B、largest 16,384 B；dbg / timer / LVGL 栈余量为 1,752 / 3,544 / 4,972 B。AP 开启时 largest 8,704 B，与导入阶段分别记录。

日语捕获指针实际 265 帧 / 10.600 秒，P95 48 ms，最大单帧绘制 9.251 ms。整段投球（包括保存、动画和结果转场）247 帧 / 10.347 秒，P95 48 ms，最大间隔 344.813 ms；不能把设计停留和提交保存排除后声称全流程恒定 25 FPS。

首次日语战斗包含一次约 504 ms 的处理耗时，因此另用原应用 `e99ecc75…` 和本次 `9d39054f…`，分别恢复同一份测试前备份、使用相同输入与简体设置作真机对照。招式采样顺序 9 → 57 → 128、初始与最终 HP 一致；中间快照取到的 HP 动画位置略不同，原值保留在证据中。

三段连续采样 P95 都为 **64 / 72 / 64 ms**；单次最大处理成本，旧版 **86.401 / 73.757 / 494.735 ms**，新版 **85.854 / 73.597 / 498.097 ms**。结算约 0.5 秒的成本在旧版同样出现，未观察到这次对象表去重造成的明显退化。约 0.88 秒的最大帧间隔包括既有反馈静止阶段，不改动画时钟掩盖它。[对照数据](evidence/japanese-release-2026-11-14/battle-comparison.json)。

一次额外导出在 offset 25,216 丢失整块 DATA，下一块为 25,344；校验器拒绝文件，没有生成可导入备份，也没有覆盖进度。只有串口应用层日志，未定位丢失发生在设备驱动、USB 链路还是宿主接收端；不能宣称它是日语引入或已经修复。此次保留原失败记录，恢复测试前进度并切回最终固件后，两次独立导出均完整收到 72 KiB，SHA-256/CRC 与生产解码比对通过；不把失败尝试改记为首次成功。

最终交付设备再次通过严格应用更新与保护区回读，保留原分区；随后两次独立导出均核对伙伴、技能策略、等级/经验、图鉴、背包、遭遇、城都及各活动进度一致。设备恢复简体、亮度 100%、静音与音量 55%。[最终设备记录](evidence/japanese-release-2026-11-14/device-final.json)。
