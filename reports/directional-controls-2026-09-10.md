# 三键统一操作与电源键实测 · 2026-09-10

## 操作变化

三个功能键依次为「上」「下」「确认」。短按上/下选择，长按下 600 ms 返回；长按结束后不再补发下一项。确认键短按执行，保留长按 1.5 秒熄屏和 60 秒无操作熄屏；唤醒时整个手势只用于亮屏。

主页的照料、菜单、遭遇改为可选操作。队伍详情提供出战、道具、技能、换入；仓库先确认查看详情，再选择换入或技能。探索页通过可见的活动入口进入切磋、研究和冒险笔记；联盟补给也有可见菜单项。宝可梦译名仍在菜单 → 选项切换。

野生遭遇先选择捕获、战斗或逃跑。捕获页面上/下换球，确认按下时立即锁定投球时机。野战长按下打开逃跑确认；训练家战长按下预约本招结束后的认输确认，默认都是继续。不会通过返回绕过反击、结算或存档。训练家战按确认可预约战术菜单。

Web 预览使用相同的 C 页面和导航，支持 ↑ / ↓ / Enter，也兼容 A / B / C。浏览器、HTTP 与 native 三层均支持 PRESS / RELEASE / CLICK / DOUBLE / LONG / END 六种事件；取消指针、失焦或长按后不会补发短按。

## 电源键调查

官方公开的 [issue #41 回复](https://github.com/FoloToy/ai-passport/issues/41#issuecomment-5534888297) 于 2026-09-04 表示电源键不能编程。用户获得的最新官方说法不同，因此不能把该回复当作所有板卡版本的最终结论。当前 BSP 只定义 GPIO0 ADC 的三枚功能键，尚无独立电源键输入定义。

新增串口 `h` 命令开启 30 秒观测：读取现有按键 ADC 电压、GPIO 输入寄存器及三键库事件；不改变引脚方向、上拉、复用，也不猜测并驱动未知引脚。观测期间屏蔽功能键对游戏的操作，已开始的手势在观测结束后仍清理至 END。`g` 可注入下键长按；`q` 读取页面/存档摘要。

首次观测用户按错，保留记录但不用于结论。第二轮由用户依次短按上、下、确认、电源，并回复已按。三键均捕获完整 PRESS/RELEASE/CLICK/END；ADC 分别约 6/305/600 mV，松开为 2894 mV。电源键未产生同一按键库事件。GPIO 输入变化涉及已有屏幕引脚，其中 GPIO21 出现一次低电平；因为它也是背光 PWM，单次变化不足以确认与电源键相关。

读取不到新的事件，只能说明当前已配置的输入路径未识别它。未启用数字输入的引脚可能恒定读零；短于采样间隔的脉冲也可能漏采。因此不能据此断言电源键在硬件上不可编程。若官方确认支持，需要对应板卡版本的 GPIO、有效电平，或电源芯片型号及短按中断/状态寄存器说明。

电源单独复测窗口取得 477 个采样，ADC 始终 2894 mV，没有三键事件，也没有 GPIO21 低电平；变化仅见 LCD 的 GPIO1/8/9 和 I2C 的 GPIO10。用户随后回复“已按”，确认完成该轮仅短按电源键三次的操作。此次观测仍未发现能稳定对应电源键的输入信号；受当前输入配置和采样间隔限制，这不是硬件不可编程的确定性证明。两轮汇总见 [power-key-summary.json](evidence/directional-controls-2026-09-10/power-key-summary.json)。
