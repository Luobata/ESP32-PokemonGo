# 金银菜单与六人队伍页

本轮新增实际固件 P11 菜单、P12 队伍，待机 B 改为菜单；A 照料、C 遭遇继续可用。菜单中的图鉴、队伍、道具、照料均可按原路返回。所有画面由 `play_*.c → render.c → screen.c` 绘制，同源预览直接执行这些文件。

## 页面和输入

P11 参考 [pret/pokecrystal 的 StartMenu](https://raw.githubusercontent.com/pret/pokecrystal/master/engine/menus/start_menu.asm) 右侧边框与分级返回结构，使用项目已有的原品 frame-1 和 cursor 图块。右框为 `(120,40,112,192)`，六项文字从 `(156,56)` 开始，行距 28：图鉴、队伍、道具、照料、选项、关闭。左侧主宠完整正面原图以 1x、按非透明轮廓居中于 `(8,88,104,96)`，名称与等级独立成行。

选项在 P11 内部切换，明确提供官方/金银民间怀旧译名；设置影响共享名称出口，本机运行期有效。没有调试入口或声音开关，也没有新增音效。B 下一项、长 B 上一项、A 选择、C 关闭；从子页回来保留原菜单光标。

P12 六个位置始终可见，列表从 y36 开始，行高 36。正面图在 x24，以 32px 最近邻缩略图显示，姓名 x64、等级右缘 228；第二行显示该成员的亲密度，队首显示蓝色“出战”。空位置显示“空位”。底部显示仓库已占用物种槽数量，本轮不提供仓库交换。

列表 A 打开详情、B 下一成员、长 B 上一成员、C 返回。详情显示完整正面原图 2x，按真实轮廓居中于 `(64,64,112,112)`，并显示等级、亲密、探索、经验与闪光标记。详情 A 明确设为出战伙伴；B 对当前队首进入道具，非队首先提示“先按A设为出战”，不会隐式更换；C 返回列表。道具 C 回到该成员详情。列表没有把 `mon.hp` 当作当前战斗残血展示。

## 返回和保存契约

- `nav_open()` 保存来源页，`nav_back()` 恢复来源页；固定深度 6，实际最深链路仅待机→菜单→队伍→道具。`nav_go()` 开始新的链路，退出当前页面时清空返回记录。
- 菜单、队伍、照料通过 `nav_is_returning()` 保留原光标。照料自然进化完成后也回来源页。直达测试场景没有返回记录时，图鉴/照料回待机、道具回照料、队伍回菜单。
- P12 传递屏幕所显示的完整 `mon_t` 给 `world_set_leader()`；核心先保存再发布。保存失败、存储不可用、忙碌或陈旧快照均显示反馈，并停留在队伍页面。
- P12 的 500ms 定时器只刷新世界快照；退出时先删定时器。跨 80px 横带的列表/精灵均整页重绘。没有新建 LVGL 全帧缓冲。

## 验证

实际原生构建：`06fd9c5e4007d1153b88`。

`python3 tools/pipeline/verify_menu_party_layout.py --negative` 通过：

- 151 种 × 两套译名/普通与闪光配色，共 302 场景。
- 独立读取 FRNT/GEN1/PALS 原资产，906 次逐 RGB565 像素比较覆盖 P11 原图、P12 缩略图与详情完整原图；不调用 C 居中帮助函数生成期望。
- 302 次完整名字字形比较，覆盖六个列表位置。最大名字墨迹宽 79px，距 `Lv100` 最少 45px。
- 906 次当前画面/完整重绘一致性检查，差异均为 0；118 个新增 UI 文案字形存在且非空。
- 私有源码负例恢复错误的 80px thumbnail 放大调用，确实令 P11 主宠空白，并被同一像素比较拒绝。生产代码使用原图 1x，不扩大缩略图 API 的语义。
