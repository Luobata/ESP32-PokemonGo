# 存档导入结果与安装清档排查（2026-10-05）

## 反馈与确认范围

社区截图反馈「导入提示成功但进度未变」和「安装新版后存档消失」。无法联系反馈用户，未取得其备份、版本号或串口日志，不能断言其个案的具体触发路径已被复现。

已确认两项缺陷/风险：

- 旧网页收到任何 `RESTORED` 回执都会显示「导入完成」，即使当前标签页没有发起导入。设备会在同一次启动的后续 HELLO 中重发历史回执。新增测试对旧网页源码稳定失败：没有本次导入仍显示成功。读循环还会把结果不匹配错误覆盖成「设备正在重启」。
- 社区 `full.bin` 是从 0x0 开始的连续镜像，0x9000～0xefff 存档区域为 0xFF 填充。将完整镜像按地址连续写入会清空这段数据；保护分区边界或保持存档版本不变，不能防止这一点。上游 README 也说明 merged flash 可能重置数据：https://github.com/FoloToy/ai-passport 。未对社区蓝牙安装器做实机测试，不能推定其有额外保档处理。

## 改动

- 网页只接受本标签页已暂存文件的设备身份与 CRC 对应回执，忽略历史回执；同一标签页刷新保留待核对元数据，不存储备份内容。取消核对不会显示成功。结果不匹配、USB 异常、回滚分别保留真实提示。
- 设备接受新导入请求时废弃旧回执。启动时没有成功解码并采纳有效存档，即使原始 Flash 写入校验通过，也返回独立的读档失败结果，网页不会显示完成。
- 新增 `PokeWalk-update.zip`：只写应用 0x10000；校验当前应用为 PokeWalk、分区表完全匹配、没有待处理恢复日志；写入前将数据分区保存到私人目录并回读，写入后验证应用并逐字节核对数据不变。失败不主动重启，不自动覆盖存档。原始备份不是网页可导入的 .pksave。
- 完整安装包依然用于首次安装，不能假称它保档；打包清单和网页明确说明先备份、安装后恢复。更新包不能传给社区的 flash-at-zero 安装入口。
- 新增真实 ESP-IDF NVS 与生产 save/device/journal 的 RAM Flash 集成测试，并纳入固件 CI；更新包测试和上述测试纳入 AGENTS.md 发布检查。

## 存档兼容与用户操作

存档结构、版本号、编号、NVS 键和分区布局均未修改；当前支持 V5～V17，未知较新格式仍拒绝。同设备、布局、文件长度、CRC/SHA、实际存档版本、启动解码和迁移检查保留；来源构建哈希不再作为网页跨版本导入限制，恢复日志的目标构建约束保留。开发 restore.py 仍限同设备同构建。

网页回执修复：在线用户发布后刷新网页，离线用户重新下载工具。游戏实际读档确认：还需更新固件。完整安装清档无法靠刷新网页修复，需先备份再安装并导入；分区匹配的现有玩家可使用 USB 更新 ZIP。若此前实际被擦除且没有任何备份，本次改动不能凭空恢复已丢失进度。

本记录初次完成时仅进行了本地修复与候选包构建，尚未烧录或发布。后续用户授权提交代码并更新网页；部署完成情况另附交付记录，固件和社区版本不随本次网页更新发布。发布固件前仍需按最终提交重新构建、重验并完成测试设备验收。

## 验证

通过：

- `verify_usb_backup.py`：C 导出、浏览器解析、CLI 身份与校验保护。
- `verify_usb_import.py`：388 个准备 / 483 个应用 I/O 边界断电注入、回滚、目标构建绑定、设备确认、预备份 ACK、超时、损坏、新请求清理历史回执。
- `verify_save_import_compatibility.py`：现有合成 V5～V17 迁移用例、未知/损坏拒绝，启动读档标记。
- `verify_usb_import_device.py`：暂存隔离、实际版本、验证失败、读档失败回执；Flash/NVS 接口为 mock。
- `verify_save_import_web.mjs`：生产网页预备份 ACK、历史回执、错误设备/CRC、回滚、读档失败、同标签页刷新重连；DOM/文件系统为模拟。
- `verify_usb_backup_checkpoint.py`、`verify_save_manager_distribution.py`：快照事务、在线和解压离线分发一致性及访问边界。
- `verify_firmware_update.py`：隔离 Flash/传输模拟，应用地址限定、写入前备份、分区不同/其他游戏/待恢复日志/损坏包/备份失败拒绝、写入或回读失败不重启。
- `verify_nvs_restore_roundtrip.py`：ESP-IDF v5.5.3 真实 NVS 源码、生产存档与恢复代码。两份不同的模拟存档（皮卡丘 Lv32 / 妙蛙种子 Lv7，包含闪光仓库伙伴、图鉴、体能、挑战、秘境和设置），暂存不改当前数据，重启切换到目标存档，所有 save_t 字节及声音/亮度键核对，第二次启动保留，损坏暂存回滚；错误声明版本不覆盖。Flash/CRC/锁与世界快照触发为主机适配，无真实 USB 或设备写入。
- `tools/device/fw.sh build`、发布包保护检查及 `verify_release_partition_protection.py`。应用 3145840 / 3407872 字节。IDF 同时提示 Recovery 槽放不下游戏应用；打包检查确认游戏仅位于 factory，不覆盖 Recovery。
- ZIP 中的应用和更新脚本与构建及源码逐字节一致；实际完整镜像的 NVS 区域确认为空白填充。
