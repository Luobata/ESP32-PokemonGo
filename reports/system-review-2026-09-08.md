# 技能辨识度与系统联动复查

## 发现与修复

1. **技能命中太短、素材过小。** 近身技能总长 12×90ms、命中仅 360ms；若注意力在技能文字/血条，容易错过。改为至少 20 帧、命中 540ms，并放大小型冲击/拳脚/电光/切割/针刺/咬合等素材。重型技能 28 帧，不统一成同一动作。保护 HUD 和文本的裁剪仍保留，命中、未命中、自身状态、蓄力和恢复继续由真实战斗结果驱动。
2. **地图探索未推动自然进化。** 原本仅 Wi-Fi 移动增加伙伴探索值，消费体力探索地图不增加。成功遭遇/线索/目标现在给队首探索值 +1，与消耗和结果同事务保存；失败不增加、满值不溢出、换队后随个体保留。
3. **训练家结果反馈与到账脱节。** 原页结算后重新按养成状态计算经验，战败心情扣除会让文字与实际到账不一致，且提示“按 A 结算”时已经保存。现在显示实际队伍经验增量，按成功/失败提示状态；分摊余数分给参战者，避免少发 1–5 点。
4. **新探索解锁提示漏触发。** 原先在已结算后才取“解锁前”章节，永远比不出变化。现在结算前后比较并保留到返回大厅。
5. **成就奖励不易被发现。** 菜单成就入口新增可领取标记，选中显示可领奖数量，返回菜单重新计算；领取仍由玩家主动操作，背包满时不吞奖励。
6. **野战结算失败提前离开。** 改为保留结果页、A 重试，不能通过 C 或菜单跳过。重复重试不重复发经验，捕获与战败流程保留。

7. **闪光伙伴在训练家对战失去配色。** P13 原本固定读取普通调色板；现在从当前出战队伍槽读取闪光标记，切换伙伴也随之刷新。不修改对手设定或存档。

| 战胜 → 随机掉落/首胜记录 → 首个道馆 | 已接通，即使无道具掉落也增加胜利记录 |
| 道馆/四天王/冠军/赤红 → 稀有目标/地图掉落/成就 | 已接通，解锁通知修复；未解锁物种不会通过随机普通池越级出现 |
| 牛奶 → 联盟连战回复 → 持续战斗 | 已接通；对战 HP 与养成体力是不同数值，牛奶不恢复探索体力 |
| 页面/战斗事件 → 音乐/技能音效 → 静音/音量 | 同一混音与设置边界；本次保持设备静音，不以播放声音验收 |

## 仍需后续体验设计的边界

- 部分同属性技能共用一类动画；“165 个招式均有可见效果”不代表 165 套独立动画。可以继续按技能身份细分，但本轮先解决看不见/太短。
- 队伍后排在野战中不分经验，只在训练家战斗实际参战后获得经验；暂无全队经验分享或路线专长加成。这是可扩展方向，不偷偷改变当前奖励规则。
- 关机时间不补体力，需可靠 RTC/持久时钟后再做离线恢复；不能把主机运行时间当关机经过时间。
- Wi-Fi 机会和体力是双重探索条件；页面分别显示。后续可根据实机走路数据调整机会补给速度，不能从模拟测试推断真实步数与续航。

## 验证

- `verify_combat_fx.py`：165 招式、双方出招及不同体型，共29344帧；自身目标、HUD保护、收尾清理通过。8种小型技能双向测量：对比背景至少100像素的阶段最短540ms，峰值最少336像素。
- `verify_system_links.py`：11项，真实 C/NVS 失败注入；地图→进化→图鉴→成就→道具完整链路，训练家奖励分摊守恒与重复结算保护。
- `verify_trainer_campaign.py`：1299动作、20次替换、4场景，ASan/UBSan通过。
- `verify_combat_preview.py`：10名训练家完整战斗（9胜1负）、3439次局部/全量重绘一致。
- `verify_battle_readability.py`：139项，实际电击/破坏光线页面、野战结算失败/重试/禁止提前退出；[预览证据](evidence/system-review-2026-09-08/preview.json)。
- `verify_capture_animation.py`：1675帧，捕获成功、失败反击、保存失败与最后捕获机会回归通过。
- 原旧版 `verify_battle_fx.py` 独立驱动未链接现有 combat_move，无法运行；本轮使用链接真实战斗模块、覆盖全部165招式的 `verify_combat_fx.py` 完成验证，不将旧驱动列为通过。

本报告中的玩法验证使用隔离存档，不通过游戏按键改动用户实机进度。最终固件已烧录 ESP32-C3，esptool 校验通过；启动 Display/Button/Audio/Battery/World 全部就绪，静音=1、音量80。读回 V11/3664字节，队伍/仓库/队列/图鉴/道具/挑战/成就/探索/队首经验逐字段一致。队首鲤鱼王 Lv8、EXP1088，图鉴10种，队伍6只，总伙伴11只。未在真实存档上触发测试战斗。
