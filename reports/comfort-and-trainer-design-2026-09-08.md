# 熄屏、伙伴动作、遇敌转场与训练家设计

本轮完成并烧录：60 秒自动熄屏；长按 C 1.5 秒手动熄屏；队伍选中成员摆动和原版动作；照料页原版动作循环；八种遇敌转场变体。训练家系统只完成[设计稿](../docs/systems/S16-trainer-campaign.md)，尚未开放道馆/联盟入口。

## 操作与表现

- 熄屏保留当前页面，世界扫描继续。任意键首次操作只唤醒，整组物理唤醒手势不传给页面；长按 C 不返回调试菜单，也不触发逃跑。自动战斗/进化等有限演出延后自动熄屏，装饰循环动画不延后。
- 队伍仅光标选中者水平摆动 ±1 像素并播放物种动作；详情也可动。照料成功后重启动作，进化优先。页面退出删除定时器，熄屏暂停装饰动作采样。
- 同一份生产 C 动画代码用于硬件与预览，每页一份 784 字节解码缓存。原版 Crystal 动作结束后休息两秒循环，80ms 更新；绘制横带只读缓存，不推进动画。
- 遇敌按编号、环境、等级差选波浪、旋入、散点、横条、收缩、旋出、竖条、分割，不消耗战斗 RNG。前八个旧转场 ID 保持兼容；波浪/散点追加为新 ID，按竖屏改编。

查看实际 C 帧生成的[队伍动图](evidence/comfort-2026-09-08/party.gif)与[照料动图](evidence/comfort-2026-09-08/care.gif)。
