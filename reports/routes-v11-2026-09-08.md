# V11 路线探索交付

实现虚拟路线、外出积累探索机会、分路线线索追踪。入口为菜单 → 探索。首批常青森林、月见山洞、海边浅滩、废弃电站覆盖全部 151 种，线索目标依次为皮卡丘、大岩蛇、拉普拉斯、电击兽。

机会最多 24 次，初次启用赠送三次。每两次探索取得一条线索，三条线索后的下一次探索找到目标。机会、线索、保底和遭遇以同一个存档事务提交。原有五格 FIFO 遭遇、直接捕捉失败一次反击、主动自动战斗、逃跑继续共用，结束回到探索页。

扫描间隔和感知算法沿用 V10，本次改为累积机会而非自动塞入遭遇。没有新增计步、GPS、诱饵或队伍探索加成。

## 验证结果

- 生产 C + ASan/UBSan：29 组规则/事务/迁移检查，20,000 步探索，全 151 种可达。
- 真实最新 V10 存档迁移至 V11：旧字段字节保留，独立开场已读键按原设计合并，新探索状态一次初始化。
- 原生共享绘制：460 次完整帧/横带重绘及交互检查，包含捕获成功、失败一次反击和逃跑返回 P15。
- 既有回归：队伍存档、活动遭遇生命周期、165 个技能战斗系统、306 组捕捉时机、熄屏输入及负向检查通过。
- 旧刷新规则：2,000 次保底序列与 V9 迁移回归通过；真实世界接口已改为积累机会。
- 本地 HTTP 预览：P15 返回 153,600 字节 RGB565 画面，原生版本 `45279b98a35df412419e`。已有浏览器标签页需刷新以加载新增选项。

## 硬件升级

ESP32-C3 固件构建、应用分区烧录和 esptool 哈希校验通过，随后读取启动日志和 NVS 验证。没有注入实际游戏按键或修改玩家道具。

应用大小 1,834,656 字节，SHA-256：`2a70e5f828383e4415d3e64cd48e3cb932be34d0b1efc8a0830ab3875bc627a1`。现有 recovery 分区为 1 MiB，构建仍提示该分区容量不足；本次仅烧录容量足够的常规应用分区，未改 recovery。

设备存档由 V10（3648 字节）迁移为 V11（3664 字节）。读回确认队伍、图鉴、道具、挑战、成就、刷新状态和队首字段逐字节保留。队伍六只，队首鲤鱼王 Lv8 / EXP1040。静音为开，音量 80；探索机会三次，四条路线线索均为零。
