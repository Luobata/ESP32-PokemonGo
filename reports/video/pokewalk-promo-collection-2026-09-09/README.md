# PokeWalk 收集与通关玩法宣传片

- `pokewalk-promo.mp4`：2分17秒，720×1280，30fps，带标题字幕与原生游戏音轨。
- `pokewalk-gameplay-clean.mp4`：相同流程与音轨，480×640 纯游戏画面。
- `pokewalk-cover.jpg`：宣传封面。
- `manifest.json`：渲染构建指纹、章节时间、音乐编号及结尾游戏状态。

从全新存档的大木博士开场到选择初始伙伴；后续章节使用标注的成长演示存档。梦幻章节连续完成图鉴追踪、七次探索、三段线索、目标出现、一次大师球成功捕获，随后展示获得分享经验的原队员。大师球来自演示存档，不代表普通精灵球必定捕获。强化道馆镜头实际进入冠军通关后的六只队伍；奖励规则通过字幕说明，不伪造胜利结算。

还保留自动战斗、技能学习、照料、进化、道具、成就、道馆、联盟、赤红及设置。音轨逐帧取自游戏音乐和音效混音器，不播放电脑或设备扬声器，不读取玩家设备存档。帧率为视频采样率，不代表硬件实测帧率。

复现：`python3 tools/video/record_promo.py`。只检查流程：加 `--check-only`（请用 `--out` 指向临时目录，避免覆盖成片清单）。录制断言覆盖全新开场、初始伙伴、梦幻目标出现与成功捕获、储备队员经验增加、进化、强化道馆六只队伍；每秒检查局部重绘与完整画面一致。
