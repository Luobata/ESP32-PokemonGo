# PokeWalk 故事版试剪

1分59秒，六幕：初遇 → 出发 → 成长 → 挑战 → 新旅程 → 未完待续。

- `pokewalk-story.mp4`：720×1280、30fps、中文字幕与原生游戏音乐。
- `pokewalk-story-clean.mp4`：480×640、同一剪辑与音轨的纯游戏画面。
- 保留上一版功能宣传片，供对比选择；本版为叙事试剪，不自动替换社区发布素材。

## 连续故事

从全新存档的大木博士开场，使用游戏自带跳过按钮结束介绍，选择皮卡丘。第一次探索实际发现尼多娜，普通精灵球一次成功捕获；同一存档继续展示新伙伴入队和照料。

“许多次冒险之后”明确切换成长演示存档，仍为皮卡丘和尼多娜。查看成长招式后，在队伍页面实际将尼多娜设为队首。小刚战斗完整运行至真实胜利，保留前9秒和最后9秒，画面标注“道馆战斗节选”；没有修改对手HP或直接设置胜利。结果页保留5秒，展示徽章、经验及奖励保存；未参战皮卡丘获得分享经验。

同一胜利存档直接打开新章节情报，图鉴追踪飞天螳螂，并连续完成7次探索使目标出现。尾声以“成为冠军之后”标注第二次时间跳跃，展示通关后的强化道馆，两位伙伴仍保留。

## 剪辑与音轨

六幕标签代替逐功能页码，字幕交代每一步的动机和结果。切镜使用9帧轻溶解；游戏动作保持实际速度。相同音乐的连续片段保留播放进度；跨音乐或战斗省略点做100ms短音量坡度。捕获和道馆胜利音乐随真实结算触发。全片进行响度处理和末尾淡出。

`manifest.json`记录源画面时长、战斗剪辑位置、每段队伍前后状态、徽章与探索进度、音乐编号、音频强度及渲染指纹。所有画面来自共享C渲染器；软件帧率不代表硬件实测帧率。录制不读取设备存档、不播放扬声器。

复现：`python3 tools/video/record_story.py`；流程预检：`python3 tools/video/record_story.py --check-only --out /tmp/pokewalk-story-check`。
