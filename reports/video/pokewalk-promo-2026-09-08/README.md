# PokeWalk 游戏内画面宣传片

- `pokewalk-promo.mp4`：42 秒，1080×1920，30 fps，H.264/AAC；字幕包装＋满金市 BGM。
- `pokewalk-gameplay-clean.mp4`：同一组镜头，720×960，30 fps，无字幕边框、无音轨，方便重新剪辑。
- `poster.jpg`：封面。
- `manifest.json`：渲染构建、镜头时间段、结果与剪辑处理。

画面通过项目同源 C 固件渲染器逐帧录制，不是 AI 生成的游戏画面，也不是实物屏幕拍摄。采用预览测试场景安排等级、队伍、闪光遭遇和挑战解锁；捕获及进化结果由游戏逻辑产生，没有修改玩家的硬件或真实存档。

时间线：0–4 秒待机；4–8 秒选择伙伴；8–16 秒战斗；16–21 秒捕获；21–25 秒队伍；25–28 秒照料；28–33 秒进化；33–39 秒赤红出场；39–42 秒结尾。

捕获成功画面在自动退出前定格，便于阅读；进化段采用 0.4 倍速度。其余画面正常速度。游戏窗口按 4 倍最近邻放大，未裁剪。RGB565 大端像素使用与项目截图相同的转换。

配乐由生产音乐合成器输出当前满金市曲目，再做响度调整和首尾淡入淡出；本片未保留各页面的原始切换 BGM 或交互音效。没有配音、硬件镜头或外部下载视频素材。片内标注“非官方同人项目 / 开发中版本”。

复现：在项目根目录运行 `python3 tools/video/record_promo.py`。需要本机 ffmpeg、Pillow、macOS PingFang 字体及当前原生预览编译环境。
