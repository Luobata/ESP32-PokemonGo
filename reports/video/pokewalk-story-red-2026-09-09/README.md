# 故事版 V3：赤红片尾彩蛋

- [完整宣传片](pokewalk-story-v3.mp4)
- [单独查看赤红片段](red-epilogue.mp4)

保留 V2 的完整故事和博士转场，在末尾追加「而在旅程的更远处……赤红，正在等你」章节卡，以及游戏实际渲染的挑战列表、赤红出场、双方出宠和部分交锋。第八次行动开始前结束实录，再淡入结束卡，不宣称已经战胜赤红。

赤红段使用独立的通关演示存档（喷火龙 Lv90，解锁道馆与联盟进度），并在画面上标明「通关后挑战演示」。不读取或修改设备存档。音轨来自游戏混音器，与录制画面同步采样；剪辑衔接处淡入淡出。

复现：`python3 tools/video/append_red_epilogue.py`。依赖 FFmpeg、Pillow、macOS PingFang 字体与项目原生渲染器。验证包括赤红 trainer_id=13、六只对手宝可梦、人物出场与出宠状态、逐秒脏区/全量渲染一致性、音频非静音、最终帧数和全片解码。详细状态见 manifest.json。
