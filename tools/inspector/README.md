# tools/inspector — 验收页面

**整页渲染验收使用「固件同源预览」页签**，或直接打开 `/firmware.html`。它直接编译并运行固件 P0–P6、P9 的绘制代码，浏览器只呈现真实 RGB565BE 帧；支持按键、步进、场景条件和原始 PNG。P7/P8 尚无固件实现。架构及边界见 [固件同源预览](../../docs/12-firmware-preview.md)。

`serve.sh` 现在启动带原生渲染接口的 `server.py`，并检查构建新鲜度与服务就绪。已有普通 `http.server` 时请使用其他端口，例如 `./tools/inspector/serve.sh --port 8766`。

在浏览器里看 151 只 sprite 与动效。

**为什么需要它**：sprite 和动效用终端 ASCII 看不出好坏。呼吸浮动方向、
体型对比、四阶灰层次这些只能在真实像素下判断 —— 而这几样恰好是
「初代情怀」成不成立的关键。

**页面从 `gen1.bin` / `gen1_front.bin` / `gen1_back.bin` 直接解码**，
读的是固件真实产物，不是另画一份，否则验收就没意义。
页面里的 JS 解码逻辑（2bpp 解包、分段寻址）就是固件侧那份逻辑的对照参考。

## 用法

```bash
./tools/inspector/serve.sh              # 起服务并打开浏览器
./tools/inspector/serve.sh --rebuild    # 资产变了，重新打包
./tools/inspector/serve.sh --port 9000
```

停止：`pkill -f 'server.py --port 8766'`

首次使用需先有数据：

```bash
python3 tools/pipeline/fetch_gen1.py --out /tmp/gen1
./tools/inspector/serve.sh --rebuild
```

## 文件

| 文件 | 说明 |
|---|---|
| `template.html` | 页面模板，含 `ASSETS_JSON` 占位符 |
| `build.py` | 解码 .bin → JSON → 内嵌进模板，输出 `index.html` |
| `serve.sh` | 构建分析面板并启动本地 `server.py`（包含固件渲染接口） |
| `index.html` | 产物，**不入库**（217 KB，含内嵌资产） |

改页面改 `template.html`，然后 `--rebuild`。

## 面板

> **「UI 页面原型」tab 已删除（2026-09-06）**：它是固件落地前的静态示意图，
> 物种/星级/血条全是写死的假数据，P3 构图与固件左右相反（用户在真机上看出违和后曝光），
> 且没有任何门禁守护。**「🎮 页面模拟器」现在仅作 JS 参考稿与美术设计稿** —— 数值全部
> `sim/` 现算，由 `verify_sim_pages.py` 核对剧本数据与构建新鲜度；它不再用于证明整页与固件一致。

| tab | 内容 |
|---|---|
| **固件同源预览** | 默认入口；直接运行 P0–P6、P9 的固件 C 代码，包含金银 HUD、技能图元、三键、横带重绘检查与 PNG 导出 |
| **图鉴 / 动效** | 151 只网格（官方配色）+ 设备屏动效预览，含**逐帧步进**（暂停/单帧前后/调帧率）与闪光开关 |
| **感知层回放** | 读 `data/raw/*.ndjson`，**窗口 1 vs 4 的对比直接验收 [2.4.1](../../docs/02-sensing.md) 那个修复** —— 距离曲线、状态时间轴、AP 出现率柱状图 |
| **2bpp 像素** | 4~16× 放大、8×8 tile 网格、四阶分布直方图、配色 hex |
| **系统与预算** | flash/SRAM 预算、**初代相克表热力图**（高亮 4 条初代差异）、存档布局、10 个系统清单 |
| **🎮 页面模拟器** | 九页按键驱动 + 逐帧步进 + 美术方向切换（见下） |

以下美术方向、布局契约与旧验收限制仅描述**历史 JS 参考稿**。当前固件 P3 的白底、整数 2 倍 HP/消息框、像素传递与横带验收以 [固件同源预览说明](../../docs/12-firmware-preview.md) 为准。

旧设计工具可在同一页面上**切换美术方向**对比 ——
`base JS 参考稿` / `A 守四色`（DMG 绿四档用足层次：C_LIGHT 扩展到分隔/底纹/次级信息）
/ `B 双层彩色`（底仍 DMG 绿、sprite 官方彩，UI 框架层加红绿蓝金 4 色，用户倾向）
/ `C 原机版式`（pokered 双线框/反白签/▸/纯色留白，配色守 DMG 绿）
/ `G 金银`（浅底 + 彩框 + HP 三段变色 + GSC 圆角框；**底色 #ffff84 与 HP 四色
是 test 探源实值**（RGB565 0xF6AF/0x05E0/0xFD60/0xF800），红蓝框色仍占位；
sprite 暂用初代官方彩，GSC sprite 等 test 取源）。
**sprite 全方向保持官方彩**（palettes.bin 着色，「四阶灰」是 2bpp 数据格式）。
覆盖 P1/P3/P6；P3 另有**骨架开关**（通用七页骨架 ↔ pokered 战斗构图）
与**主宠尺寸开关**（G 专属：48px @1x 不碰 80px 横带 ↔ 96px @2x 需跨带渲染 ——
用户定夺体量与架构代价的取舍，模拟器无横带约束、两种都如实画出）。
「📐 量化当前画面」按钮在页面内直接量**单色最大占比**与用色分布。

约束：方向只改**呈现**（颜色/坐标/层次），数值仍全部来自 build 时
`sim/` 现算导出的 payload（`verify_sim_pages.py` 门禁对照）。
色板一律取 **RGB565 量化精确值**（如 #9bbc0f 上屏变 #9cbe08）。
深链：`#sim=P3&d=G&z=48`（页 & 方向 & P3 骨架 `k=alt` & 主宠尺寸 `z=48/96`）。

## 五个验收要点

页面底部列了详细说明，摘要：

1. **front 尺寸必须是三档** —— 格子右上角标着原生尺寸。
   对比超梦（#150，56）与妙蛙种子（#1，40），体型差异应当明显
2. **数值是初代原版** —— 抽查吉利蛋（#113）的 Special 应为 **105**，
   现代特攻只有 35
3. **属性只有初代 15 种** —— 用属性筛选器确认妖精不在列表里
4. **待机呼吸只向上浮动** —— 图应整体上移再回落，底部不能被切
5. **动效零素材成本** —— 缩放/闪白/抖动/进化都是对静态图做变换

## 本模拟器验不了的五类（与页面模拟器 tab 内同一张表）

**门禁全绿 ≠ 全部验过。** 以下五类是浏览器原理上测不到的，
各有替代守护 —— 别因为 web 绿了就跳过真机验收：

| 验不了的 | 为什么 web 验不了 | 由什么守护 |
|---|---|---|
| ① 音频时序 / 爆音 | 真机 I2S/DMA 时序；爆音判据是**麦克风回采 RMS**，不是欠载计数 | verify_audio.py 逐样本对账 + 真机回采 RMS |
| ② 横带分块刷新同步 | web 一次画整屏，BUG-1 类**跨带撕裂**原理上验不出（画布虚线只是示意） | verify_layout.py + 固件 SCREEN_ASSERT_WITHIN_BAND |
| ③ 堆 / DMA 余量与碎片 | MALLOC_CAP_DMA 的**最大连续块**比总量重要，浏览器无从测 | 真机内存水位采集与连续块断言 |
| ④ NVS 掉电持久化 | 断电原子性 / 磨损只有真机能验 | 固件侧 写入→断电→重读 测试 |
| ⑤ 真实 WiFi 扫描产出遭遇 | 页面模拟器的 P2 队列是**确定性生成样本**（种子固定），非实机扫描 | 真机走链路 + verify_encounter.py 对 roll_encounter 逐值对账 |
