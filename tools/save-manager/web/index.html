USB 连接设备，在设备上选择备份。文件直接保存到这台电脑。

从内网入口开始

内网 HTTP 地址用于下载工具。浏览器要求 USB 操作在 HTTPS 或 localhost 页面进行，因此请先在自己的电脑启动：

下载本地存档工具 ZIP（需 Python 3.8 或以上，无需安装额外依赖）

  1. 解压，在解压后的文件夹打开终端。
  2. macOS / Linux：python3 server.py；Windows：py -3 server.py。
  3. 用桌面 Chrome / Edge 打开 http://localhost:8767/，保持终端运行，再按下方步骤操作。

文件保存在你的电脑，不需要开发机 SSH 权限。端口被占用时，命令追加 --port 8768 并打开 localhost:8768。

01　选择保存目录

每次生成独立文件，保留已有备份。

尚未选择

02　连接设备

选择 PokeWalk 的 USB JTAG/serial 接口。先关闭占用串口的日志工具。

尚未连接

03　在设备上备份

菜单 → 选项 → 备份存档 → C 确认

选择目录并连接设备后开始。

    04　导入已有存档

    先在设备打开「选项 → 导入存档」，再选择文件。设备确认覆盖后，会先将当前存档保存到上面选择的目录。

    尚未选择文件

    设备默认选中取消。确认覆盖后请保持供电，完成时设备会重启；重新连接可核对结果。

    关于这份备份

    包含伙伴、仓库、图鉴、道具、养成、挑战、探索、秘境，以及已保存的声音与亮度设置。支持后续游戏版本沿用现有备份格式的存档，无需每次更新工具。导入要求同一台设备、同一固件构建；临时战斗画面和未保存的页面状态不在恢复范围内。

    这是开发工具。备份包含设备 NVS 数据，请保存在私人目录，不要提交到源码或公开分享。页面不上传存档；关闭网页会断开连接。

    也可使用仓库中的 tools/save-manager/restore.py 进行开发恢复。网页导入有设备确认和断电恢复暂存机制。

    需要桌面 Chrome / Edge。从内网入口下载工具后在本机启动，也可通过 HTTPS 或 SSH 转发使用。
